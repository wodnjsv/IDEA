# ISS-014: API 예산 상한·비용 게이트 — "캐시=공짜"는 절반만 참이다

- **상태**: DECIDED
- **유형**: 사업 | 코드
- **심각도**: P1
- **발견**: 2026-07-18, 적대적 감사(엔지니어링 F1·F7 — 비용 직접 계산)
- **관련**: 구현계획_v1 예산 절, AGENTS.md 규칙

## 문제
계획 전체에 API 비용 추정이 없었다. 감사 계산(gpt-4o-mini $0.15/$0.60 per 1M, 호출 600in+250out≈$0.00024): 풀런 1조건(1만×5)=$12, 어블레이션 8암+프레이밍 2×2+백테스트 3선거+광명 6조건+트리아지+vanilla 대조군 = **정가 ~$470, Batch ~$235**, 마진 포함 **~$350**. 단 k=20 채택 시 ×4(**~$1,150+**), 트리아지 전인구 실행 시 +$720 등 통제 없는 갈림길 존재. 그리고 "디바이어스 반복 $0" 주장은 **사후 재가중에만 참** — 프롬프트·옵션·모델·k 변경은 전부 캐시 무효화(재생성)다. 이 과장이 비용 통제 부재와 결합하면 어블레이션 폭발을 정당화한다. 부가: Tier 1(200k TPM)이면 풀런 1회 ~3.5시간.

## 결정 (2026-07-18, 대표 승인)
1. **예산 상한 $500/학기** (AGENTS.md 명기).
2. **풀런 발주 전 EXP 카드에 예상 비용 기입 필수** — T10 비용 추정기가 자동 산출.
3. **대량 런은 Batch API**, 어블레이션·트리아지는 1-2천 명 서브샘플 기본, 1만 명은 최종 채점 런 전용. 어블레이션은 요인설계 금지(one-at-a-time + 최종 조합).
4. T1 스펙에 **2열 분류표**(캐시 내 반복 vs 캐시 무효화 변경) 명시 — 후자는 EXP 카드+비용 기입 없이 실행 금지.
5. W3 전 Tier 확인(필요 시 Tier 2 확보).
