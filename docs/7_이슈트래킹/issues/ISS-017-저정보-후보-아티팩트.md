# ISS-017 — 저정보 후보 아티팩트 (군소후보 과대·순서 의존)

- **유형**: 방법론·프롬프트 · **P**: P1 · **상태**: ANALYZED (EXP-004 실증)
- **관련**: ISS-003(x/P(y) 경계) · ISS-007(제3후보) · T10(A/B 슬롯) · 오차축소 A4·B6

## 문제
위생판(B·C암)에서 무소속 송진호가 6.2~7.6% (실제 0.1%). 원인 실증: ① 모델 컷오프(2023-10)가 2025 후보를 몰라 인지도 정보가 0 → 선택지 텍스트만으로 판단, ② 순서 효과(1번 위치 12.7~15.3% vs 5번 1.3~1.8%), ③ '중도' 카드의 도피처 휴리스틱("무소속=중립"). 힌트 제거(ISS-003)가 정당한 정보(후보 인지도·샐리언스)까지 제거한 부작용. 이준석 과소(4.8 vs 8.3)도 동일 계열.

## 옵션
1. **후보 중립 프로필 제공** — 공보물 수준의 객관 사실(소속·주요 경력)을 전 후보 동일 분량으로. 쟁점: 이것은 x(사실)인가 P(y) 힌트인가 — "주요 후보" 표기 없이 사실만이면 x로 판정 가능 [제안]. 검증: T10 A/B (±프로필) + 델타 불변성
2. B6 짝비교 디코딩 (오차축소 카드 — 샐리언스 문제의 구조적 처방)
3. 방치 + E1 보정 전담 — 군소후보 축은 보정 불가능(0.1%를 6%로 뽑는 건 가법 보정 밖) [기각 제안]

## 검증 계획
T10 어블레이션: B암 ± 후보 프로필, 판정지표 = 송진호 오차·이준석 재현율·이재명/김문수 불변성. 서브샘플 500, ~$0.5.
