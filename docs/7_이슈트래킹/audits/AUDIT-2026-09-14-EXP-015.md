# AUDIT — EXP-015 부부 가사 분담, 모두 주40시간 조건

- 날짜: 2026-09-14
- 독립 검토자: design_audit
- 상태: **최종 로컬 캐시·집계·보고서 검증 통과 — 인간 응답 정확도 검증은 아님**
- 관련: EXP-015, ISS-028, ISS-003, ISS-011, ISS-014
- 범위: `민심테스트/scripts/minsim_luna_run.py`, `data/minsim/questions_six_v1.json`, EXP-015 설정, 실행 초기 로컬 캐시
- 이 감사는 LLM/API 호출 없이 수행했다. 원자료 개인별 내용은 출력하지 않았고 생성 캐시는 변경하지 않았다.

## 1. 착수 전 설계 감사

부모지원 문항에 사용한 동일 1,200명 상세 프로필을 가사분담 문항에도 입력하되, 새로운 독립 세션과 별도 캐시로 실행하는 계획을 검토했다. 처음 제안된 B 조건(50/30시간)은 사용자가 호출 전 **조건 A, 두 사람 모두 주40시간**으로 명시 변경했다. 이 감사의 실행 검증 대상은 A 조건이다.

필수 요구 사항은 다음과 같다.

1. 문항 options로 keys·schema·validator·cache hash를 함께 구성하고, 부모지원 기본 호출의 프롬프트·선택지 순서·캐시 호환성을 보존한다. 별도 raw/lock/environment/launch/보고서 경로를 사용한다.
2. P0/P25/P50/P75/P100/U 여섯 선택지 확률을 그대로 평균한다. A가 맡는 가사 비율과 해당 선택지를 고를 확률을 구분한다. 찬반 합산이나 U를 0% 가사 비율로 간주한 평균을 만들지 않는다.
3. EXP-015에 확정 조건과 구독 실행 설정을 먼저 기록하고, 첫 세션부터 반환 모델/provider를 보존한다. 제한·인증·모델 변경 오류의 중단과 최초 유효 응답 보존 규칙을 유지한다.

단일 조건이므로 paired 차분/MDE는 비해당이다. 원설문의 관련 가치관은 예측 입력이며 이 신규 상황의 실측 정답으로 채점하지 않는다. 현재 국민 대표성이나 인간 응답 정확도 주장은 하지 않는다.

## 3. 현재 판정과 남은 확인

조건 A 변경과 문항별 키·캐시 분리에 실행을 차단할 오류는 발견하지 못했다. 기존 부모지원 캐시 호환성도 보존됐다. EXP-015의 사전 설정은 사용자 확정 조건 A와 일치한다.

현재 64건의 초기 캐시만 확인했으므로 전체 1,200명 완료나 최종 집계 정확도를 아직 판정하지 않는다. 집계 코드 추가 후 여섯 분포·집단 분모·불완전 캐시 거부·보고서 수치와 표시를 독립 확인해야 한다. EXP 및 인덱스의 '사전 준비/미실행' 상태도 실제 완료 후 결과와 함께 갱신해야 한다. 불변 모델 스냅샷 미확보, 전역 AGENTS 포함, 단회·단일 조건 및 실측 정답 부재는 최종 보고서에도 유지한다.

## 4. 집계 코드 추가 후 합성 입력 검사

`민심테스트/scripts/minsim_housework_report.py`의 main 함수를 AST로 추출하여 SDK 초기화 없이 검사했다. 4개 연도·2개 성별·5개 연령 구분을 갖춘 가상 인물 1,200명과 서로 다른 확률 벡터를 만들었으며, 출력은 임시 디렉터리에만 생성했다. 아래 수치는 테스트용 합성 값이고 실제 실험 결과가 아니다.

| 검사 | 실행 증거 | 판정 |
|---|---|---|
| 6키 확률 평균 | P50=0.2/0.6, U=0.45/0.05인 두 벡터를 각각 600개 입력; 집계 P50=0.4, U=0.25 | 통과 |
| 집단 분모 | 전체 n=1,200, 연도·성별·연령 각 구분의 n 합계=1,200 | 통과 |
