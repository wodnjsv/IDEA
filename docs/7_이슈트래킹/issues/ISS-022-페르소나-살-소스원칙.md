# ISS-022 — 페르소나 '살(flesh)' 소스 원칙: LLM 생성 속성 기각, 실측 마이크로데이터 모듈만

- **유형**: 방법론·페르소나·데이터 · **P**: P2 · **상태**: **DECIDED** (2026-08-07)
- **발견**: 2026-08-07, 뱅크 일반화 논의(세션 대화) — "Nemotron-Personas식 골격+LLM 살 채우기로 도메인 일반성을 올리자"는 제안의 설계 갈림길
- **관련**: ISS-010(라벨러 순환 — 동형 논리) · ISS-018(라벨 지배 휴리스틱 — 동형 위험) · ISS-001 · 오차축소 §A2(백스토리)·§A5(인구통계-only 부정)

## 문제
페르소나 뱅크는 선거 외 도메인(정책·소비 등)으로 재사용될 예정이다. "속성이 풍부할수록 일반성이 오른다"는 직관에서, NVIDIA Nemotron-Personas처럼 **인구 골격 위에 LLM으로 개인 속성(성격·취미·미디어 이용 등)을 생성해 붙이는** 경로가 제안됐다. 살의 **소스**(LLM 생성 vs 실측)가 미정의 상태였다.

## 검토한 옵션
1. **Nemotron-Personas 데이터셋 직접 도입** — [기각] 미국(이후 일본·인도판) 인구 기반, 한국판 미확인(2026-01 지식 기준 — 도입 재론 시 실재 재확인 필요). 용도가 학습데이터 다양성(SDG)이지 여론 분포 재현으로 검증된 바 없음. 골격 품질도 현행 MDIS 2% 실레코드(결합분포 공짜)가 우위.
2. **자체 골격 + LLM 속성 발명** (성격유형·취미·미디어 등) — [기각] 근거 4:
   - ① **순환성**: 살 생성 LLM의 고정관념이 인구에 주입되고, 응답 LLM과 같은 편향 계열이라 오차가 상쇄 아닌 **합성**됨 — ISS-010(라벨러 순환)에서 기각한 구조와 동형 [강: 자체 결정 선례]
   - ② **검증 불가능**: 발명 속성의 결합분포는 실측 정답이 세상에 없어 반증 불가 — "정확도 리포트" 브랜드와 정면충돌 (KGSS 도너 복사는 실측 대비 검증 가능) [강: 구조 논증]
   - ③ **새 지배 라벨 위험**: "성격: 성실성 높음" 류 눈에 띄는 범주 라벨은 이념 딱지(ISS-018)와 동일한 지름길 병리를 재생산할 수 있음 — 신호는 약하게·사실로·다축으로 [중: ISS-018 실증의 일반화]
   - ④ **실증 이득 부재**: 성격 조건화가 여론 재현을 개선한다는 근거는 코퍼스에 없음. 실측 자기보고 시딩 82~83% vs 인구통계-only 74%(Park et al. 2411.10109 [중]) — 이득의 실증은 전부 **실측** 살에서 나옴. chat 모델 생성 백스토리는 동질화 보고(Anthology [중]).
3. **실측 모듈 원칙 (채택)** — 살은 **실측 마이크로데이터 도너 복사**(현행 KGSS 핫덱 방식)로만 붙인다. 도메인이 실제로 열릴 때 해당 도메인의 실측 모듈만 **lazy 확장**: 미디어 이용=한국미디어패널조사(KISDI), 생활·시간=통계청 생활시간조사, 여가·소비=국민여가활동조사·가계동향 등 [후보 — 개별 사용성(접근·라이선스·셀 충분성)은 확장 시점에 확인]. 태도 축은 KGSS 주제 모듈 교체.
4. **백스토리 문장화 (Anthology 경로)** — [조건부 보류] 실측 사실을 자연스러운 서사로 **렌더링**(새 정보 0)은 현행대로 허용. 속성을 **발명**하는 백스토리 생성은 base(비정렬) 모델 확보 + 동질화·진보쏠림 감사 + 2×2 델타 게이트 통과 전 금지. 중기 재론.

- **구속 규칙**: 페르소나 뱅크에 새 속성을 추가할 때 그 소스는 실측 마이크로데이터(도너 복사 또는 조건부 추첨)여야 하며, LLM이 속성 값을 발명하는 경로는 금지. 렌더링(문장화)은 사실 불변 조건에서만 허용.
- **일반성의 공식** (결정 배경): 일반성 = 골격(공통) + 도메인별 실측 살(모듈 교체) + 도메인별 검증(G8·앵커). LLM 살이 사는 것은 '그럴듯함'이지 '검증된 일반성'이 아니다. 검증 없는 질문-응답 모드는 "탐색 도구" 라벨로만 제공(G8 통과 전 마케팅 금지 원칙과 동일 계열).
- **재론 조건**: (a) 실측 모듈로 채울 수 없는 속성이 특정되고, (b) base 모델 인프라가 확보되면 — 옵션 4 경로로 EXP 사전등록 후 A/B.
