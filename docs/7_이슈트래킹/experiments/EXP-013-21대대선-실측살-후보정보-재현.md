- 정당 매핑 규칙 P: 더불어민주당 → 이재명 / 국민의힘 → 김문수 / 정의당·진보당 → 권영국(권영국 = 민주노동당 후보, `phase0/data/ground_truth_2025.json`) / 그 밖의 정당·무소속·'없음'·모름·무응답·결측 → 미분류.
- **BL-b (주, F-BL 판정용 — K-POL-b 대응)** 우선순위 표(위에서부터 처음 맞는 행):

  | # | VOTE22 | VOTE221 | 출력 |
  |---|---|---|---|
  | 1 | 투표하지 않음 | 비해당·결측 | 기권 1.0 |
  | 2 | 투표하지 않음 | 유효 정당값 | 미분류(응답 불일치 — 건수 보고) |
  | 3 | 투표함 또는 결측·모름 | P로 후보 매핑됨 | 해당 후보 1.0(정당 응답을 투표 함축으로 본다) |
  | 4 | 투표함 | P로 미분류 | 미분류 투표자 |
  | 5 | 결측·모름 | P로 미분류·결측 | 미분류(투표 여부 불명) |

- **BL-a (보조 — K-POL-a·K-PID 대응)** 우선순위 표:

  | # | PRTYID23 | PRTYPR23 | 출력 |
  |---|---|---|---|
  | 1 | P로 후보 매핑됨 | (쓰지 않음) | 해당 후보 1.0 |
  | 2 | 지지 정당 없음 | P로 후보 매핑됨 | 해당 후보 1.0 |
  | 3 | 지지 정당 없음 | 그 외·결측 | 미분류 |
  | 4 | 그 밖의 정당·모름·무응답·결측 | (쓰지 않음 — PRTYPR23은 '없음'일 때만) | 미분류 |

  투표 여부 정보가 없으므로 BL-a의 기권은 0이다.
- **분모**: 유효표 점유 = 후보로 매핑된 인물의 가중 질량만(미분류·기권 제외 — 매핑된 사람의 분포로 대체하는 것과 같다, 무작위 결측 가정). BL-b 기권율 = 기권 / 투표 여부가 정해진 인물(행 1·3·4 — 행 3의 VOTE22 결측자는 투표자로 셈). 미분류 질량(가중·비가중)과 행별 건수를 보고한다. v1.1의 미결 '기권/균등'은 이 표로 닫는다.
- 값 라벨 전수(VOTE22·VOTE221·PRTYID23·**PRTYPR23**)를 이 표로 매핑한 결과를 발주 전 커밋(§7-3). 표기가 다르면 정당 동일성으로만 매핑하고, 불명확하면 미분류.
- **실효 모집단 차이와 동일 인물 보조 비교**: 기준선은 매핑된 인물만, LLM은 300명 전원으로 점유를 만들므로 같은 부트스트랩 인덱스를 써도 실효 모집단이 다르다. 보조로 **BL-b 행 3에 해당하는 인물 집합 M_b**에서 LLM(K-POL-b×I2×E1)과 BL-b의 유효표 MAE를 같은 인물로 비교해 보고한다(BL-a는 M_a). F-BL의 결론은 "지정된 매핑 기준선과의 비교"로만 쓴다.
- **민감도(보고만, 판정 미사용)**: S1 미분류 → 5후보 균등(각 .2) · S2 BL-b 미분류를 BL-a 매핑으로 보충 · S3 진보당 → 이재명(진보당은 최종 후보 명단에 없음 — 계열 판단의 대안).
- **알려진 구조적 한계 — 이준석 0%**: 개혁신당은 2023 웨이브 이후에 창당됐으므로(§7-2에서 값 라벨로 확인) VOTE221·PRTYID23 어디에도 이준석 대응 범주가 없다. 따라서 **두 기준선 모두 이준석 점유가 구성상 0%로 고정**된다(실제 8.34%). 송진호(무소속)도 0%(실제 0.10%). 점유 합이 100으로 보존되므로 빠진 질량은 다른 후보의 양의 오차로 옮겨 간다 → 기준선의 유효표 MAE 하한은 **이준석만으로 2×8.34/5 ≈ 3.34%p, 송진호까지 2×8.44/5 ≈ 3.38%p**다(v1.2의 1.67%p는 이준석 항 하나의 기여만 센 값 — 정정). F-BL은 LLM에 유리하게 기울어 있다. 보정 비교(사전 지정, 보조): 이준석을 뺀 4후보 재정규화 MAE를 LLM·기준선 모두에 병기한다. 이 비교는 구조적 불이익의 일부만 없앤다.

## §1b. 확증 대비·다중성·성공 규칙 (Codex 2차 #10·#27)
- **지표**: 주 = 유효표 MAE(5후보, 질량 우선 Σwᵢpᵢc / Σwᵢ Σc pᵢc, WT 가중). ISS-015 결정 1의 ⑥ 1·2위 마진 오차와 ⑦ 후보별 최대 오차를 병기. 군소 합 = 권영국+송진호 유효표 점유. 기권 = 전체 질량 중 '투표하지 않음'.
- **평균 가중치**: 살 주효과는 5개 정보·표현 셀(I0, I1E1, I1E2, I2E1, I2E2)에 1/3, 1/6, 1/6, 1/6, 1/6(정보 균등 → 표현 균등). 정보 주효과는 살 4단계 균등, I1·I2는 E1·E2 균등. MAE 대비는 **셀별 MAE 차의 가중 평균**이다(점유를 먼저 평균한 뒤 MAE를 내지 않는다 — 셀 간 상쇄 방지).
- **추론**: 인물 재표집 부트스트랩 B=10,000, 전 암 동일 인덱스(paired), 백분위 CI. 로컬 재표집 시드 20260923(기록용 — 결정론 주장은 하지 않는다, ISS-011).
  - 0 기준 양측 p = min(1, 2·min(1 + #{Δ* ≤ 0}, 1 + #{Δ* ≥ 0}) / (B + 1)). |Δ*| < 1e-9(%p 단위)는 0으로 보고 두 꼬리 모두에 센다(동률). p 상한 1.
  - 퇴화: 모든 Δ*가 허용오차 안에서 같으면 p = 1, 그 대비는 "퇴화(변동 없음)"로 표기하고 Holm 순위에는 p = 1로 넣는다.
  - H2b 경계 검정(±3%p): 지표 k의 점추정이 +3 초과면 p_k = (1 + #{Δ*_k ≤ 3}) / (B + 1), −3 미만이면 p_k = (1 + #{Δ*_k ≥ −3}) / (B + 1), 그 외 p_k = 1(단측). 수준 내 6개에 Holm을 α = .025(단측)로 적용한다. 동등은 6개 모두 90% 백분위 CI ⊂ (−3, +3).
- **결측·실패 처리**(Codex 2회차 #9):
  - 재시도: 파싱·검증 실패 레코드만, 같은 모드로 최대 2회. 처음 받은 유효 응답을 채택한다(유효 응답을 여러 번 받아 고르지 않는다).
  - 대비별 **공통 유효 인물 집합**: 그 대비에 들어가는 모든 셀에서 최종 유효 레코드가 있는 인물만 쓴다. 여러 셀을 평균하는 대비는 **인물 단위**로 제외한다(한 셀이라도 최종 실패면 그 대비에서 그 인물 제외). 제외 수·셀별 사유를 보고한다.
  - 하한: 공통 유효 n ≥ 270/300(H3(b)는 ≥ 900/1,000), 가중 ESS ≥ 전체 표본 ESS의 .85. 미달이면 그 대비는 "미결(결측 과다)"로만 쓴다.
- **검정군**(군 내 Holm, α=.05. 군 간 FWER는 통제하지 않으며 결론은 군별로 쓴다):
  - F-H1(3): ΔMAE K-ATT−K-ID, K-POL-a−K-ATT, K-POL-b−K-POL-a.
  - F-H2(3): ΔMAE(I1−I0), ΔMAE(I2−I0), Δ군소 합(I2−I0).
  - F-H3(4): H3(a) Δ군소 합·Δ기권(기준판 − 삽입판, 4셀 균등), H3(b) Δ군소 합·Δ기권(D1_nosent − D1_rerun). 판정은 §1 H3의 방향별 규칙.
  - F-BL(1): MAE(K-POL-b×I2×E1) − MAE(BL-b). 95% CI 상한 < 0 → LLM 우위 / 하한 > 0 → 기준선 우위 / 그 외 미결.
  - H2b: §1의 교집합-합집합 규칙(수준별).
- **성공 규칙**: ΔMAE 대비는 Holm 유의이고 점추정 < 0이면 '개선'. **악화 경고(관측 기준 — 안전 게이트 아님)**: 같은 대비에서 어느 한 후보의 절대오차(셀 가중 평균) 증가의 **점추정**이 +2%p를 넘으면 '개선(후보 상쇄 경고)'로 표기하고 §5 결정 연결에 쓰지 않는다. 후보별 증가량의 95% 상측 신뢰한계도 함께 보고하지만 판정에는 쓰지 않는다(비열등성 보장 아님). 살 사다리의 단조성은 요구하지 않는다(인접 대비별 판정).
- **하위집단**: 이념 3집단·성×연령 대분류의 투표 정답이 없다 → 하위집단 '악화'는 판정할 수 없고, 점유 이동만 기술 보고한다(Codex 2차 #27의 '하위집단 악화 판정' 요구는 정답 부재로 이행 불가 — 한계).
- **최상 조건(사전 지정)** = **K-POL-b × I2 × E1**(가장 많은 정보). F-BL·llama 대조·헤드라인 보고는 이 셀만 쓴다. 결과를 보고 가장 좋은 셀을 고르는 것은 탐색이며 "사후 선택(낙관 편향)"으로 표기하고 §5에 쓰지 않는다.
- 나머지(H4, 부속, 분해 보조, 상호작용, 권역·하위집단 점유 이동, llama, 강제선택, 기준선 민감도·동일 인물 비교)는 무보정 paired CI로 기술 보고하고 '탐색'으로 표기한다. 군 간 FWER를 통제하지 않는다는 점은 결론을 군별로 쓰는 전제로 명시한 것이다.
