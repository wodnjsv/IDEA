# IDEA 연구 과정 — EXP-001~013

조사 기준: 2026-09-22 로컬 HEAD `2e4f3d681f9fe8994b0dc126e00beeee080ac11b`. 이 문서는 저장소 원문과 Git 이력을 읽어 정리했으며, 실험·캐시 재채점·새 지표 계산은 하지 않았다. 아래 수치는 기존 카드에 기록된 결과다. 실험 일자는 카드의 실행일, 커밋일은 Git 기록으로 구분한다. 개인정보 원문과 키는 읽지 않았다.

## 1. 연구 흐름의 핵심

초기 질문은 "공개 페르소나와 LLM으로 실제 선거를 재현할 수 있는가"였다. 첫 실패 뒤 원인을 샘플 크기가 아니라 표본 구성·프롬프트 힌트·응답 수집 방식에서 찾았다. 실제 센서스와 설문 도너로 인구를 만들고 위생 실험을 하자 이재명 +21%p 편향 가운데 약 12.3%p가 설계 문제로 줄었다. 그러나 이념 명찰은 인간의 다양성을 없애고, 명찰 대신 5개 신념 문장을 넣으면 이념과 투표의 결합 자체가 사라졌다.

그래서 카드 문장 최적화를 멈추고, 실제 개인의 풍부한 응답 기록을 주었을 때 LLM이 무엇을 할 수 있는지 확인했다(EXP-008). 개인 기록을 읽는 신호는 있었지만 같은 입력의 통계 방법에 졌다. 이 결과로 LLM의 역할을 이미 조사된 문항의 빈칸 채우기에서 새 질문·표현 조건의 반응으로 좁혔다.

프레이밍 검증(EXP-009)은 강제선택 채널의 과민반응·순서편향·유보 소멸을 드러냈다. 분포를 직접 발화하는 채널(EXP-010)로 바꾸자 집단 분포와 방향 재현이 좋아졌다. 다만 개인 예측은 여전히 우연 수준이고, 위약 및 선택지 순서 문제는 남았다. 현재 주 연구 질문은 "실제 태도 응답을 다른 지역의 센서스 인물에게 붙여도 쓸 수 있는가"(EXP-011)와 "실측 정치·비정치 정보, 후보 사실 정보, 지시 문장이 각각 선거 재현에 무엇을 더하는가"(EXP-013)다. 두 실험 모두 현재 최신 개정안은 승인 대기이며 본런 결과가 없다.

**확인된 방향과 확인되지 않은 목표를 구분해야 한다.** 분포 발화는 현재 가장 유망한 응답 채널이다. 그러나 전국 여론조사 대체, 개인 디지털 트윈, 광명 지역 고유성, 일반 정책 예측 정확도, 안정적인 anchor+Δ 상품 전체가 검증됐다는 뜻은 아니다.

### 2.5 2026-08-20~30: 개인 정보의 가치와 LLM의 역할 재정의(EXP-008)

### 2.7 2026-08-31~09-14: 분포 발화의 집계 개선과 개인 예측 한계(EXP-010)

같은 모델·페르소나·문항·정답지에 강제선택 대신 두 채널을 적용했다.

"dist가 한국 모든 게이트 통과"라는 일부 요약은 상세 결과와 맞지 않는다. 한국 SSR은 해당 가능한 게이트를 통과했지만 순서 위약은 선택지 비노출이라 원리상 검사 대상이 아니었다.
