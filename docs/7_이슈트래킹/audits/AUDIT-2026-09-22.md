# AUDIT-2026-09-22 — 민심테스트 Git 보관 경로 정리

관련: ISS-027, ISS-028, ISS-029. 사용자 요청: 민심테스트 폴더로 커밋·GitHub 푸시. 상세 프로필·raw 제외를 사용자가 명시 선택.

## 착수 전 설계 검토
- 경로 위험: scripts 이동 시 repo ROOT와 자식 프로세스 경로가 깨질 수 있음. ROOT를 parents[2]로, 자식 실행 경로를 동일 디렉터리 기준으로 조정. 데이터 원본은 기존 data/minsim 유지해 registry 및 IDEA_DATA_DIR 의미 보존.
- 이슈·게이트: ISS-002 레지스트리 유지, ISS-020/028의 집계 표시 유지. 새 실험·채점·생성 없음. 이슈·실험·감사 정본 위치 유지.
- 회귀·노출: 원시 프로필/응답/로그 제외. results는 기존 집계 사본만 허용. 웹 내부 상대 경로 유지.

## 완료 후 검토
- Python 7개 AST 파싱 통과. ROOT 및 자식 실행 경로 소스 대조.
- JSON 파싱 통과. results 파일은 data/minsim 원본과 바이트 일치.
- 집계 JSON 재귀 검사: pid/thread_id/full_lines/raw/items 키 없음.
- 보관 폴더 텍스트의 API 토큰·개인키 패턴 검사에서 일치 없음.
- git diff --check 통과. 웹 렌더·모델 실행·재채점은 수행하지 않음. 기존 실험 검증은 9/14 감사 기록 참조.

독립 서브에이전트 감사를 요청했으나 모델 용량 초과로 실행되지 않았다. 위 항목은 주 에이전트가 레드팀 관점으로 검토한 범위이며 독립 감사 통과로 주장하지 않는다. 기존 실험의 상태를 승급하지 않는다.
