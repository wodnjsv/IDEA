## 문제 (Issue)

접근 가능한 실존 속성은 수십 개. 뼈대만으로 350문항 태도를 예측하면 개인 상관 **0.10**(EXP-008 셀 최빈값), 문헌도 인구 요약이 행동 분산의 **~1.5%**만 설명([2603.27056](https://arxiv.org/pdf/2603.27056)). 즉 사람 위치의 98%는 뼈대 밖 잔차이고, **그 잔차를 어디서 가져오느냐**가 B단계의 본질. 후보 셋:
- (A) 실존 도너 복사 — 진짜 잔차를 빌림(ISS-022 현행). 결합 구조 자동 보존, 지역 고유성 약점(CIA).
- (B) 실측 속성 확장(경기도 사회조사·카드사 등) — 설명 분산 증가. 법적(ISS-008)·비용 부담, 행동 데이터가 태도를 설명하는 정도는 별개.
- (C) LLM 증강 — 뼈대에서 서사·성향을 LLM이 생성(Anthology, Nemotron-Personas). 서로 다른 인물 수는 폭증하나 잔차는 **모델 사전분포**에서 나옴 → 유효 rank인지 가짜 rank인지는 실측 대조로만 판정 가능.

### 추가 실측·문헌 (2026-09-14 — 도너 풀 희소성 + 서사 층 근거 재검토)

**도너 풀 계측** (광명 뼈대 4,568 vs KGSS 2018/21/23/25 합산 성인 4,676, 수도권 2,200 — `scratchpad/donor_pool.py`):
| 매칭 셀 | 셀당 도너 중앙값 | 도너<10 인물 | 도너<30 인물 | 뼈대/도너 비 |
|---|---|---|---|---|
| 성×연령10×학력×수도권×혼인 (106셀) | 59 | 9.3% | 35.6% | **2.09** (도너 평균 2회 재사용) |
| 성×연령10×학력×수도권 (58셀) | 83 | 5.3% | 15.7% | 2.08 |
| 성×연령10×학력 (전국) | 189 | 3.1% | 8.5% | 0.98 |
- 결론: "도너 10명" 상황은 최세밀 셀에서 인물의 9%에 해당(전체가 아님). 수도권 제한 시 도너 재사용 ×2 불가피 → **합성 광명 인구 = 실존 태도 프로필 ~2,200개의 재가중**이 정직한 서술(표본 2,200명 조사의 해상도 ±2%p와 등가). 핫덱 문헌: 도너 풀 소형 시 셀 내 분산 과소 편향 — 셀당 ≥30 확보를 사다리 폴백(L1→L2)으로 강제. 도메인 블록별 도너 혼합(정치 블록 A, 가족 블록 B — 블록 내 결합 보존·블록 간 부분 손실)은 조합 다양성 증대의 중간안 — EXP-011 손잡이로.

**서사 층 근거 재검토 — D 제안의 수정**:
- Kinzinger et al. 2026 (SOEP 500명·183 홀드아웃·2.1M 응답, [2606.04592](https://arxiv.org/pdf/2606.04592)): **"서사 페르소나 요약 → 과거 응답 원문 대화 이력으로 바꾸면 전 모델×추론 셀에서 홀드아웃 정확도 상승"**(최고 78.8%, r=.59). 정보 깊이는 **정규화 섀넌 엔트로피(문항 변별력) 순위**로 선별, 75% 분위 이후 수확 체감.
- Beyond Raw Transcripts ([2608.20344](https://arxiv.org/html/2608.20344)): 구조화 추출이 원 전사록 대비 동질 과제 +1.9pp, 이질 과제 ±0; 비구조 요약은 원문과 차이 없음(−0.58 ns).
- Twin-2K(전문 71.7 > 요약 68.0)·스탠퍼드(인터뷰 **전사록** 사용)와 정합 → **"LLM이 쓴 서사가 원 응답 나열보다 낫다"는 근거 없음, 반대 증거 우세.**
- **수정**: D의 "LLM 서사" 층을 기본에서 제거. D′ = 실존 뼈대(광명 사실은 센서스 텍스트 그대로) + 도너 실측 350답 원문 나열(도메인별 정렬 = 저비용 구조화) + **엔트로피 기반 문항 선별**(EXP-010 정보 과포화 문제의 원칙적 해법 후보). LLM 서사는 EXP-011의 선택 암(서사 유/무)으로만 검정.

## 결정 (Decision)

(제안) ISS-022의 생산 규칙(살 = 실측 모듈만)은 **유지**하되, **실험 조건부 예외**를 허용: EXP-011 시도 숨기기 격자에 (C) Nemotron-Korea 페르소나 암과 하이브리드 암을 추가해, 정답이 있는 지역에서 (A)/(C)/하이브리드를 **같은 판정(마진·결합·분산·하류)**으로 대조. (C)가 이기면 ISS-022 supersede 안건, 지면 기각 근거 강화.

**결정 (jinwoo, 2026-09-14)**: 실험 예외 **승인** — EXP-011에 (C)암(Nemotron-Korea + 우리 뼈대→LLM) 포함. 봉인 지역 경기·부산·전북, 도너 = KGSS + 통계청 사회조사 블록, 예산 ~$15/1주. 생산 규칙(ISS-022)은 실험 결과 전까지 불변. 상태 → DECIDED(실험 예외 한정).
