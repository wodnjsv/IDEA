## 문제
NESDC "동일 이슈 상이 문항" 쌍은 기관·모드(ARS/CATI)·표본·시점이 동시에 다른 두 조사다. 관측 차이 = 프레이밍 + 하우스 + 모드 + 시점 + 표집오차의 합성이고, 쌍당 1관측으로 분해 불가. 한국 ARS-CATI 격차(수~10%p)는 기대 프레이밍 효과와 같은 자릿수 — 혼입비 ~1. 그런데 백테스트 문서는 NESDC를 "프레이밍 앵커 ★ T1"으로 뒀다(서열 역전). 오염된 정답지에 G8 크기 상관을 최적화하면 LLM Δ를 하우스 효과에 맞추는 선택압이 걸린다.

## 결정 (2026-07-18, 대표 승인)
1. **G8 소스 서열 역전**: 1차 = **무작위 split-ballot**(TESS/SocSci210 — 단 모델 학습 오염 감사 + "미국 도메인" 한계 명기), 2차 = NESDC 중 **동일 기관·동일 모드·인접 시점 쌍만** 필터(하우스 상쇄), 그마저 **방향 채점만** 허용 — 크기 상관은 무작위 소스에서만.
2. **자체 split-ballot 소액 실측 검토**: 옴니버스 조사에 1~2문항(n≈1,000) — 국내 유일의 무혼입 프레이밍 앵커. W8 전 예산·실행 여부 결정(비용 견적 선행).
3. 백테스트 문서 §3의 NESDC ★ 표기에 혼입 경고 병기(정정 완료).
