## 왜 2단인가 (Codex 종합 지적 수용)
형태·선택정책·딱지재심·선거전이를 얹기 전에, 이 패러다임의 존립 질문 두 개부터 깨끗하게 결정한다:
**(Q1) 모델은 개인의 실제 정보를 사용하는가** (길이·형식이 아니라 내용을) — 음성 대조로만 증명 가능.
**(Q2) 같은 입력을 받는 강한 통계 모델을 이기는가** — 못 이기면 "행렬 완성엔 LLM 불필요"가 결론이고, LLM 가치 주장은 행렬 밖(새 질문·프레이밍)으로 한정된다. 둘 다 유효한 답이다.
1단 통과 시에만 2단(EXP-009 — K 곡선 정밀화·형태·선택정책·딱지재심·투표 이식 점검)을 등록한다.

## 가설 (전부 가설 — 심판 명기)
- **H1 (개인 신호)**: 진짜 프로필(K=전체)이 섞인 프로필(같은 셀 타인의 답, 동일 길이·형식)보다 개인 재현이 좋다. 심판: 진짜 vs 섞임 paired 비교.
- **H2 (LLM 증분)**: K=전체(사전 고정 — best-K 선택 편향 차단)에서 LLM이 같은 입력의 강한 ML 베이스라인 3종을 이긴다. 심판: 사람 단위 paired 비교.
- **H3 (정보량, 예비)**: K=전체 > K=5 > K=0. 1차 대비 = 전체 vs 5, 최소 효과 크기 명기.

## 설계 (Part A' — 1단)
- **모집단**: KGSS **2023 파동 단일**(측정동일성 — 3파동 혼합 기각), 응답자 n=1,230 중 **배터리 10문항 중 8+ 유효응답자에서 무작위 300명**(포함 기준·시드 사전 고정). 나머지 ~900명 + 타 파동 = **베이스라인 참조셋**(평가자 답 미사용 — 누출 차단).
- **고정 배터리**: 전원 동일 10문항 (5영역×2 — 정치·경제/가족·젠더/종교·전통/신뢰·사회/문화·생활; 커버리지·유분산 기준 선정, 절차·시드 고정). 프로필에서 배터리 문항 + 동일 배터리·|r|≥0.85 준중복 + 투표·정당·이념 인접 173변수 제외.
- **암 4종** (동일 300명, paired):
  | 암 | 내용 |
  |---|---|
  | K=0 | 실제 인구속성만 |
  | K=5 | + 실제 답 5개 (전영역 층화, 시드 고정) |
  | K=전체 | + 그 사람의 유효 응답 전부 (2023 중앙값 ~376개, 순서 무작위) |
  | **섞인 프로필** | K=전체와 동일 구조·길이, 답만 같은 셀(성×연령대×권역×학력) **타인 1명** 것으로 교체 — 음성 대조 |
- **호출**: **문항별 개별 호출**(배터리 1콜 오염 기각 — Codex #5), k=1, temp 1.0 → 300×4×10 = **12,000콜**, $0(llama-3.1-70b, 동시성 12·RPM 25), 벽시계 ~18h(재개 안전 러너 필수). 교차모델 점검은 사전등록에서 **제외**(조건부 항목의 조작 여지 — 후속 별도 등록).
- **베이스라인 (전부 $0 오프라인, 참조셋 학습)**: ① 순서형 로지스틱(K 입력 동일) ② kNN(응답 벡터 거리) ③ 저계수 행렬완성 ④ 셀 최빈값(약한 기준 병기).

## 판정 기준 (사전등록 — 변경 금지)
- 지표 정의: 문항별 **Spearman**(예측=단일 응답, 실제=원척도; 역코딩 정규화 명기), Fisher-z 평균. 정확도 = 정확 일치 + 서열 ±1 인접.
- **H1 합격**: (진짜 − 섞임)의 사람 단위 부트스트랩 95% CI > 0 **그리고** Δ(Fisher-z) ≥ 0.10 (최소 의미 효과).
- **H2 합격**: K=전체 LLM 정확도 ≥ 베이스라인 ①~③ 전부 (사람 단위 paired, α=.05, 군집 반영). 하나라도 못 이기면 "행렬 내 예측에서 LLM 비우위"로 기록 — 실패도 결과.
- **H3 보고**: 전체 vs 5 (동일 규격) — 예비, 곡선 정밀화는 2단.
- 추론 단위: **사람**(300) — 문항·샘플은 사람 내 군집. 관측치 4,000 독립 취급 금지.
- 일반화 범위 명시: 결론은 "이 고정 10문항"에 한정 — 문항 일반화는 2단에서 배터리 확장으로.
- 상한 규율: raw 80% 초과는 성과 아닌 점검 신호(문헌 재검사 천장) — 섞인 프로필 암이 경험적 영점 제공.
