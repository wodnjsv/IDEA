## 질문 4개 (전부 가설 — 심판 명기)
- **Q1 민감도**: 실측에서 효과 있던 표현 쌍에서 같은 방향의 반응 차이를 내는가. 심판: 미국 실쌍 20 중 **≥15 방향 일치**(단측 이항 α=.05 — 14/20은 p=.058로 불합격, Codex 교정).
- **Q2 특이도**: 실측 무효과 쌍에서 가짜 효과를 만들지 않는가. 심판: 무효과 쌍 20개에서 **등가마진 판정**(각 쌍 |Δ_focal| 90% CI ⊂ ±3%p 비율 ≥ 70% + 실쌍 대비 |Δ| 중앙값 ≤ 1/3). "유의 검출률" 지표는 표본수 의존이라 폐기(Codex #6).
- **Q3 크기·구조**: Δ_실측 ~ a + b·Δ_LLM 회귀 — **leave-study-out 교차검증**으로 b 추정(in-sample 금지). 한국: 사후가중 topline 비율 + 무당파×당파 상호작용(당파층 비민감은 등가마진으로).
- **Q4 프로필 증분 (신규 — Codex #1·2)**: 표현 반응의 정확한 재현에 **개인 프로필이 더 기여하는가**. 심판: 한국 3암(무프로필/인구속성만/풀 프로필) 비교 — 풀 프로필이 구조 재현(하위집단)·개인Δ 정밀도에서 우위인가. 증분 0이면 "표현 반응은 모델 일반 상식"으로 기록 — 그것도 답.
