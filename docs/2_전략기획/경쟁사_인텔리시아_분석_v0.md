## 2. 공통점

- 실측 소비자/응답자 데이터에 정박한 합성 인구(웹 스크래핑·순수 LLM 상상과 차별화 주장) — 우리 ISS-022 원칙과 방향 동일.
- 검증 서사: "실제 조사 결과와 합성 응답의 유사도" — 우리 EXP-009/010의 정답지 대조와 같은 틀.
- 가치 제안의 시간축: 주·월 → 시간 (우리도 표현 100종 하루 탐색).

## 4. 해자 분석 — 냉정하게

**인텔리시아의 해자**: (a) **고객 PoC 데이터 루프** — 120건 PoC의 실제 조사 결과가 검증·보정 데이터로 축적(우리에게 없는 것). (b) 소비재 카테고리 지식·리포트 UX·영업망. (c) 자본·속도. 이 셋은 우리가 따라갈 수 없고 따라갈 필요도 없다(도메인이 다름).

**인텔리시아가 (공개 정보상) 못 하는 것 = 우리 자리**:
1. **위양성 계측**: "재현율 90%"는 효과 있는 문항 재현만 말한다. 우리 실측(EXP-009: 정렬된 모델이 위약에서 −48%p 날조, 델타 4배 과장)이 시사하듯, 위약 시험 없는 재현율은 **증폭기를 측정기로 오인**할 수 있다. 우리는 이 함정을 공개 데이터로 검증하는 방법론 자체를 상품화한다.
2. **프레이밍 델타의 실측 정박**: 소비재 컨셉 테스트도 결국 프레이밍인데, 델타 크기 보정(모델별 과장/감쇠, LOSO r≈.67)을 공개 정답지로 하는 곳은 없다.
3. **정직 브랜드 + B2G 신뢰**: 공공 의사결정자는 "90%"보다 "어디서 틀리는지"를 산다. 사전등록·실패 공개 기록 자체가 진입장벽(경쟁사는 마케팅상 실패를 공개하기 어렵다).
4. **지역 소단위**(시군구) 합성 + 검증 총연습 — 소비재 회사는 전국 세그먼트면 충분하므로 투자하지 않는 영역.

**우리 해자가 아닌 것(착각 금지)**: 모델·프롬프트 기법(SSR·분포 발화는 공개 문헌 — 6개월 내 누구나 복제), 합성 인구 생성 자체(Nemotron-Korea가 CC-BY로 700만 명 배포), KGSS 사용(공개 데이터).

## 5. 우리에게 주는 교훈 (프론티어·경쟁사 이동 관찰 규율)

- 시장은 이미 "실측 정박 합성 응답자 + 재현율 숫자"로 수렴 — **재현율 숫자 경쟁은 지는 게임**(정의를 각자 정하므로). 우리의 차별은 숫자가 아니라 **검증 프로토콜의 공개성**과 **위양성·델타 보정**.
- 인텔리시아의 "핵심 기억" 속성은 우리 미디어 다이어트(경로 1: 감쇠 가중 노출 기억)와 같은 착상 — 그들이 어떻게 캘리브레이션하는지 공개되면 대조 가치.
- 오픈서베이의 "세그먼트≥30명" 규칙은 우리 도너 사다리(셀당 ≥30)와 같은 실무 상수 — 독립 수렴.
- 행동 항목: (1) EXP-011 완료 후 "재현율" 대신 **{방향 재현·위양성률·델타 보정 오차·수준 TVD} 4종 리포트 규격**을 공개 표준으로 제안(ISS-020 표시 규격과 연결). (2) 인텔리시아 Medium 기술 블로그 정독(403 우회 필요) — 응답 채널·검증 정의 확인.
