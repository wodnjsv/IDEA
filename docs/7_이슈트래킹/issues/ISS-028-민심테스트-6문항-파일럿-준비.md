# ISS-028 — 민심테스트 6문항 파일럿 준비

- 상태: ANALYZED
- 유형: 방법론·설계·데이터

- 관련: ISS-003·011·014·022·023·025·026

## 문제
최근 실험용 1,200명을 이용해 6개 신규 사회 질문을 실행하려 함. OpenAI API 키가 현재 환경에서 확인되지 않았고, 사용자는 ChatGPT 구독 사용량 활용 가능성을 재질문함. API 호출은 하지 않음.

기존 페르소나의 full_lines 결손은 실제 설문 무응답뿐 아니라 prep 단계에서 need_full이 아닌 연도를 빈 배열로 저장한 결과이기도 함(scripts/exp009_kr_prep.py:187 부근). 이를 시민의 실제 정보 부재로 간주할 수 없음. 정치 중심 기존 제외목록도 신규 문항 누출 제외를 보장하지 않음.

## 분석
- [강: 코드] 6개 질문과 각 A/B 조건을 data/minsim/questions_six_v1.json에 준비. 12개 조건, 전부 판단 유보 선택지 포함.
- [중: 설계] 전원을 대상으로 가상 상황에 대한 판단을 요청. 주4일제는 근로자 자신의 전환 의사가 아니라 선택 제도에 대한 찬반으로 좁힘. 원래 콘텐츠 제목의 임금 포기 한계는 이 문항으로 추정하지 않음.
- [중: 설계] dist만 먼저 유지하고 짧은 의견은 별도 후속 설계. 의견 동시 생성이 분포에 주는 영향을 이번에 섞지 않음.
- 실측 정답지가 없어 이 실행으로 인간 반응 정확도나 전국민 대표성 검증 불가.

## 결정
인간의 모델·규모·별도 API 이용 선택 대기. 에이전트는 실행을 승인하거나 표준 채널 결정을 변경하지 않음. 이번에는 질문지 작성 및 정적 검증만 수행.

## 실행 전 준비 항목
1. 조사 연도별 full_lines 생성 범위 확인, 원자료 변수 ID와 직접·준중복 문항 제외 목록 고정. 관련 가치관은 일괄 제거하지 않음. 민감한 원응답은 서비스에 노출하지 않음.
2. 시점은 과거 응답자 기반 가상 판단으로 명시. 2026년 상태로 나이·직업·가족을 임의 갱신하지 않음.
3. 선택지 순서는 페르소나별 무작위화하고 짝 안에서 동일, 조건 A/B는 독립 대화. 확률을 단일 최빈 선택으로 바꾸지 않음.
4. EXP 카드 신규 채번 후 모델 스냅샷·컷오프·표본·프롬프트·입력 해시·비용·상한 기록. 프레이밍 비교는 ISS-011 MDE 표 선행; MDE 계산 역시 EXP 등록 이후.
5. 실제 API 이용 경로와 모델·규모 확인. 구독 잔여량을 API 잔액으로 취급하지 않음. 키는 채팅으로 받지 않음.
6. 모델 분포 원문·파싱 결과·호출별 토큰·오류를 보존. 유효 확률·합계·옵션 완전성을 검증하고 누락 응답을 숨기지 않음.

### 사용자 실행 범위 정정 — 상세 설문 응답 전원 포함
사용자는 parent_support B(부모 집값70% 지원) 1문항·1200명 NVIDIA 실행을 요청한 뒤, 인구정보만 있는 사람도 그대로 실행하려던 접근을 명시적으로 정정함. **기존1200명의 ID를 유지하고 전원의 상세 설문 응답을 포함해야 함.** 600명만 실행하거나 나머지를 인구정보만으로 실행하는 것은 승인 범위와 다름. API 시뮬레이션 호출은 여전히0회. 단일조건이므로 조건차분/MDE 실험이 아니며 델타를 주장하지 않음.

원자료 확인: registry의 kgss_cum_2003_2025 경로 data/raw/kor_data_CUM0074_V2.sav가 없음. 홈 내 접근 가능한 .sav/CUM0074 및 관련 캐시 검색에서도 원자료를 찾지 못함. EXP008 reference.parquet은 2023 중심 선택변수의 일부 값과 o_j 인덱스만 저장하므로 2021/2025 원래 개인의 전체 응답 및 원자료 라벨을 완전히 복원하는 대체물이 아님. 원자료 또는 같은 ID의 상세 응답 완성본 필요. 복원 시 원자료 해시를 registry와 대조하고, 원본 exp009 캐시는 보존하며 별도 버전으로 저장할 것.
