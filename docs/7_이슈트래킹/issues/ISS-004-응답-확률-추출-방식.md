# ISS-004: 응답 확률 추출 방식 (k-샘플 vs logprob vs verbalized)

- **상태**: ANALYZED
- **유형**: 방법론 | 설계
- **심각도**: P2
- **발견**: 2026-07-18 (Q6) — 단일 선택 대신 확률 출력 검토
- **관련**: 오차축소 문서 §D1-D4, phase0/구현분석.md(최빈값 집계가 분포를 죽임)

## 문제
phase0는 페르소나당 5회 샘플을 최빈값으로 뭉개 분포(=상품)를 파괴. 추출 방식 자체를 재설계해야 함.

## 분석
| 옵션 | 내용 | 장점 | 단점 | 근거 |
|---|---|---|---|---|
| A | k회 샘플 분포 (최빈값 금지) | 화이트박스(이유) 동반, drill-down 가능 | k배 비용 | [중] |
| B | first-token logprob + affine 보정(D2+D3) | 1 forward, 거부 0, 최저가 | 텍스트 답변과 60%+ 불일치·과도 뾰족(2402.14499) — 보정 없인 금지 | [중], 경고 [강] |
| C | verbalized 확률(모델이 30/70 진술, D4) | 분포정렬 벤치마크 3방식 중 최고(2411.05403) | 10단위 반올림·합≠100·수행적 확률 위험, 반대 증거 존재 | [중] |

주의: CoT-SC 다수결은 분포 수축이라 전면 금지(§B3).

## 결정
미확정 — 잠정 설계만: **주 채널 A**(제품이 이유·drill-down 요구), 보조 B(대량 스크리닝), 실험 C(집계 앵커·조건별 차분). 세 채널을 같은 홀드아웃에서 A/B하고 G지표로 판정. C는 샘플 빈도와의 정합성 소표본 검사 선행. 한국 정치 도메인 검증이 없으므로 실측 전 채택 금지.

## 구현
미착수. **T1 출력 스키마에 3채널 공통 인터페이스 포함, A/B 실험은 T10(어블레이션·A/B 러너)에 배정**(2026-07-18 감사 F13 반영 — 구현계획_v1 참조). Δ 추정 한정으로 logprob 채널 우선 검토는 ISS-011 결정 3 참조.

## 검증
계획: 3채널 A/B 결과 → 본 이슈 DECIDED로 승급 + 결정 기록.
