## 질문 4개 (전부 가설 — 심판 명기)
- **Q1 민감도**: 실측에서 효과 있던 표현 쌍에서 같은 방향의 반응 차이를 내는가. 심판: 미국 실쌍 20 중 **≥15 방향 일치**(단측 이항 α=.05 — 14/20은 p=.058로 불합격, Codex 교정).
- **Q2 특이도**: 실측 무효과 쌍에서 가짜 효과를 만들지 않는가. 심판: 무효과 쌍 20개에서 **등가마진 판정**(각 쌍 |Δ_focal| 90% CI ⊂ ±3%p 비율 ≥ 70% + 실쌍 대비 |Δ| 중앙값 ≤ 1/3). "유의 검출률" 지표는 표본수 의존이라 폐기(Codex #6).
- **Q3 크기·구조**: Δ_실측 ~ a + b·Δ_LLM 회귀 — **leave-study-out 교차검증**으로 b 추정(in-sample 금지). 한국: 사후가중 topline 비율 + 무당파×당파 상호작용(당파층 비민감은 등가마진으로).
- **Q4 프로필 증분 (신규 — Codex #1·2)**: 표현 반응의 정확한 재현에 **개인 프로필이 더 기여하는가**. 심판: 한국 3암(무프로필/인구속성만/풀 프로필) 비교 — 풀 프로필이 구조 재현(하위집단)·개인Δ 정밀도에서 우위인가. 증분 0이면 "표현 반응은 모델 일반 상식"으로 기록 — 그것도 답.

## 설계 (동결)

### 한국 트랙 — 제품 구성 사례검증 (통계판정 미산입)
- 정답지: 한국 조사기관의 무작위 워딩 실험(총선 구도, 두 기관 문구, n=1,000×2회 — 효과 ~13%p·무당파 집중·하위집단 공개).
- 인물: KGSS 2023 실제 응답자 300명(직전 실험 풀·시드 고정). **3암**: 무프로필(질문만)/인구속성만/풀 프로필(y-제외 372문항 풀). 정당지지·이념은 프롬프트 제외, 분석 라벨로만.
- 처치: 표현 A·B 각각 독립 호출, k=3, 날짜 앵커("2023년 가을") 명시. 3암×2표현×k3×300 = **5,400콜**.
- 모델: **gpt-4o-mini-2024-07-18** (컷오프 2023-10 < 정답지 공개 2023-11 — 오염 클린). 비용 ~$8-10. **블로커: OPENAI 키(사용자 준비)**. llama 복제판은 암기 프로브(실험 결과 직접 질문 ×10) 통과 시에만·참고 기록.
- 대조: 정답지 표본의 정당지지 구성으로 사후가중한 topline Δ 비율 + 무당파/강성 내부 Δ + 개인Δ 부트스트랩 CI.

### 미국 트랙 — 모델 일반능력 통계판정
- 소스: 개인응답 실험 코퍼스(290만 행)에서 **스터디당 1쌍**(군집 제거): 실측효과 20쌍(선별: 원연구 CI 0 제외 + |효과| ≥ 5%p — winner's curse 완화 위해 대형 효과만) + 무효과 20쌍(원연구 CI ⊂ ±2%p). 스크리닝 기준·목록은 실행 전 부록 동결. 유명 실험 회피 + 암기 프로브.
- 인물: 각 쌍 원연구 응답자 80명의 실제 인구속성 조건화(얕음 — 한계 명기). 2조건×k3×80×40쌍 = **19,200콜**, llama $0(코퍼스 공개 2025-08 > 컷오프 — 개별 응답 클린), 벽시계 ~2일.
- 공통 척도: 쌍별 focal 응답 범주의 %p 차 — 규칙표(이항=해당 범주, 서열=원연구 보고 지표, 다범주=원연구 focal) 실행 전 동결.
