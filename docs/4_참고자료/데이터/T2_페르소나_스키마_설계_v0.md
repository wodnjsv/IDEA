## 0. ⚠️ 먼저 처리할 것 — 데이터 본체 4개 누락

현재 4개 MDIS 폴더에는 **문서(파일설계서·조사표·주의사항)만 있고 데이터 파일이 없다** (KGSS만 .sav 데이터 완비).
MDIS에서 **'관련자료'(문서 묶음)와 '자료'(데이터 본체)는 별개 다운로드**다. 다시 받는 법:

1. MDIS 로그인 → **자료받기(다운로드 서비스)** → 해당 조사·연도·파일 선택
2. **항목 선택 화면에서 전체 선택** → 이용목적 입력 → 다운로드 신청
3. **MY서비스 > 다운로드 신청내역**에서 데이터 zip 수령 (CSV 본체 포함)
4. 받은 즉시 `data/raw/`로 이동 + sha256 레지스트리 등록 (ISS-002) — 대형 CSV는 `.gitignore` 확인

받아야 할 본체: ① 2020 2%_인구 ② 2020 2%_가구주택 ③ 지역별고용 2025 상반기 A형 ④ 가금복 2025 가구마스터

## 2. 페르소나 스키마 v0

```json
{
  "persona_id": "P-000001",
  "skeleton": {                          // ← 센서스 2% 실레코드에서 통째로 (합성 없음)
    "sido": "31", "sigungu": "31060",    // 행정구역시도·시군구코드 (광명=31060)
    "sex": "여", "age": 52,              // 성별코드, 만연령
    "edu": "고졸",                        // 교육정도코드(8분류→공통 4분류)
    "marital": "배우자있음",              // 혼인상태코드
    "econ": {"status": "주로일함", "empstat": "임금근로자",
              "industry": "도소매", "occupation": "서비스판매"},
    "commute": {"type": "통근", "dest": "타시도(서울)", "mode": "전철지하철", "minutes": 55},
    "housing": {"tenure": "자가", "dwelling": "아파트", "area_band": "60~85㎡"},
    "household": {"size_type": "2세대가구", "hh_id": "H-..."}
  },
  "drawn": {                             // ← 조건부 조회표에서 추첨 (실측 분포 기반)
    "wage_band": "월 200만원대",          // 지역별고용: P(급여|시군구,연령,성,학력,직업,종사상지위)
    "hh_income_decile": 5,               // 가금복: P(소득분위|수도권,연령대,학력,입주형태,가구원수)
    "ideology": "중도",                   // KGSS: P(PARTYLR|권역,연령대,성,학력) — ISS-010 게이트 후
    "party_lean": null                   // (선택) PRTYID — 정당ID 반응성 시험 통과 전 미사용
  },
  "weights": {"person": 49.1, "hh": 48.7},
  "provenance": {"census": "2020_2pct", "wage": "LAF_2025H1_A", "kgss": "CUM0074_V2"}
}
```

**원칙**: skeleton은 실레코드 무수정 사용(조합 보존), drawn은 반드시 실측 조건부에서 추첨(최빈값 배정 금지 — 다양성 보존), 모든 속성에 출처(provenance) 기록.

## 4. 파이프라인 (의사코드)

```
1  load 센서스인구, 센서스가구주택 → merge on 가구일련번호       # 정확 결합
2  filter 만연령 ≥ 18 → skeleton pool (~79만 레코드 예상)
3  build 조회표:
     W ← 지역별고용: P(급여구간 | 시군구,연령구간,성,학력4,직업대,종사상지위)  # 셀<임계 → 시도→전국 폴백
     I ← 가금복:     P(소득분위 | 수도권,연령구간,학력4,입주형태,가구원수)
     K ← KGSS:      P(PARTYLR | 권역7,연령구간,성,학력4)                    # 셀<5 → 권역→전국 폴백 (T2 명세)
4  sample skeleton: 층화(시도 n≥200; 광명 트랙은 시군구=31060 별도 층) × 가중값 비례
5  for each persona: draw wage~W, income~I, ideology~K   # seed 고정, 추첨(최빈값 금지)
6  render 템플릿 → 인물 카드 텍스트 (LLM 창작 금지)
7  validate: (a) 표본 마진 vs 2024 등록센서스 집계 ±1.5%p  (b) 시도 n≥200
             (c) KGSS 시딩 후 성향 주변분포 vs KGSS 원분포 일치
             (d) 정당ID 유/무 반응성 시험(T2 게이트) — party_lean 사용 시
```

## 5. KGSS 시딩 상세

- **시딩 변수**: `PARTYLR` (1=매우진보 ~ 5=매우보수, DK/무응답 별도 코드 — **DK도 하나의 상태로 보존** 권장, phase0 부동층 교훈)
- **파동 선택(결정 필요)**: 누적파일은 2003~2025 — 전 파동 합치면 시대 혼합 왜곡, 최근만 쓰면 셀 붕괴. 제안: **최근 3개 파동 가중 사용 + 민감도 체크**(전 파동 vs 최근, EXP 카드로)
- **지지정당(PRTYIDxx)**: 연도별 변수가 분리돼 있고 정당명이 시기마다 다름 → v0에서는 미사용, 정당ID 반응성 시험 설계 후 도입 검토
- ⚠️ 이념 라벨의 페르소나 사용은 **ISS-010 인간 이중코딩 게이트 선행** (DECIDED)
