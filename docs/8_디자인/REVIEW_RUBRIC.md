# REVIEW_RUBRIC.md — 디자인 반복 채점표

> **용도**: 디자인 루프(만들기 → 직접 보기 → 채점 → 피드백 → 개선)의 **매 반복을 같은 자로 재기 위한 도구**.
> 이게 없으면 "좋아졌다"가 의견이 되고, 반복할수록 원칙에서 표류한다.
>
> **정본 관계**: 기준의 출처는 [DESIGN_SOUL.md](DESIGN_SOUL.md)와 [ISS-020](../7_이슈트래킹/issues/ISS-020-산출물표시규격-디자인입장.md)이다.
> 이 파일은 그것들을 **체크 가능한 항목으로 펼친 것**이지 새 기준을 만드는 곳이 아니다. 충돌하면 SOUL이 이긴다.
>
> 작성 2026-08-06

## 0. 길 잃음 방지 조항 (이 문서에서 가장 중요한 절)

디자인 루프는 피드백을 받는다. 피드백은 거의 항상 **"더 시원하게" "숫자 하나 크게" "이건 너무 복잡해"** 방향으로 온다.
그 방향은 대부분 옳고, 동시에 이 제품의 하드 게이트를 정확히 겨눈다.

**규칙**

1. **피드백이 Gate A와 충돌하면 Gate A가 이긴다.** 예외 없다.
2. Gate A를 뒤집으려면 [AGENTS.md](../../AGENTS.md) 규칙 1의 **supersede 절차**를 밟는다 —
   새 ISS 카드 생성 + 원 카드를 `SUPERSEDED(by ISS-xxx)`로 표시 + **인간 결정자 기명**(규칙 8).
   대화 중 구두 합의로 게이트를 무력화하지 않는다.
3. 충돌이 발생하면 **말없이 따르지도, 말없이 거부하지도 않는다.** 충돌 사실과 어느 게이트인지를 명시하고,
   게이트를 지키는 대안을 최소 하나 제시한다.
4. Gate B~E는 근거를 제시하면 피드백이 이길 수 있다. 단 그 사유를 반복 로그에 남긴다.

> 이 조항의 근거: 이 프로젝트는 ISS-012에서 "산문 규칙은 지켜지지 않는다"를 실증했고,
> ISS-015에서 "표본이 작을수록 잘 통과하는 역선택"을 잡아냈다. 디자인에서 같은 일이 일어나는 경로가
> **데모 압박 하의 점진적 양보**다. W15가 가까워질수록 압력은 커진다.

## 1. 채점 절차

1. **만든다** — HTML로 실제 렌더 가능한 산출물. 정적 이미지 목업 아님(§6 실측치를 실제로 조판해야 하므로).
2. **직접 본다** — `browse`로 실제 렌더 → 스크린샷 → **에이전트가 이미지를 직접 읽는다.** 코드만 보고 판정 금지.
   최소 3종: `1920×1080`(프로젝터), `1440×900`(노트북), 흑백 변환본.
3. **채점한다** — 아래 게이트를 순서대로. Gate A에서 하나라도 FAIL이면 **B~E 점수는 산출하지 않는다**(무의미).
4. **피드백 받는다** — 사람. §0 조항 적용.
5. **개선하고 반복 번호를 올린다** — 로그(§7)에 기록.

## 7-1. 중단 기록 (2026-08-06)

**상태: PAUSED.** 창업자가 미학을 기각하고 **무드보드를 직접 가져오기로** 함.

> **근본 원인**: Phase 0a 무드보드를 **에이전트가 수집했다.** YC 파이프라인(Eve Bouffard)에서 무드보드는 사람이 해야 하는 유일한 단계다 —
> "당신이 왜 그 사이트를 좋아하는지 몰라도 된다. 에이전트가 분석해준다"의 전제는 **당신이 고른 것**이라는 데 있다.
> 에이전트가 고른 레퍼런스로 만든 시스템은 에이전트의 취향을 재생산한다. 이것이 generic AI design을 깨는 유일한 방법을 스스로 무력화한 것이다.

## 8. 이 루브릭이 놓치는 것 (정직)

- **미학은 측정하지 않는다.** 게이트를 전부 통과하고도 못생길 수 있다. 미학은 Phase 2 shotgun의 변형 비교와
  사람 판단에 맡긴다 — 단 게이트를 통과한 변형들 **안에서만** 고른다.
- **Gate C의 n이 작다.** 3~5명은 통계적 주장을 못 한다. 이건 스크리닝 도구지 증거가 아니다.
- **설명자 효과**: 데모에는 우리가 옆에 앉아 있다. 화면 혼자 세워두고 채점하면 실제보다 가혹하고,
  설명을 곁들여 채점하면 실제보다 관대하다. **둘 다 재고 둘 다 기록한다.**
- **프로젝터 시뮬레이션은 시뮬레이션이다.** 실제 회의실 장비에서 한 번은 확인해야 한다. W15 전 필수.
