# ISS-001: 이념·정당 마진 주입이 정답 순환(과대적합)이 되는 문제

- **상태**: DECIDED
- **유형**: 방법론
- **심각도**: P1
- **발견**: 2026-07-18, 대표 지적 (구현 설계 Q&A Q1)
- **관련**: ISS-006(Δ 외적타당도), docs/2_전략기획/오차축소_방법론_비교분석.md §A1, phase0/구현분석.md

## 문제
갤럽/KGSS 이념·정당 마진으로 페르소나를 채우면 topline이 사실상 "마진 + 이념→투표 매핑"으로 결정돼, 선거 백테스트가 부분 순환이 된다. 극단 증거: RSS(arXiv:2402.18144)에서 정당ID 프롬프트 주입 시 민주당 지지층의 99.96%가 Biden — 페르소나가 결정론화되어 **프레이밍 민감도(우리 상품)까지 죽음**. 단, phase0 실측상 매핑은 비결정론적("중도"의 ~78%가 이재명으로 쏠린 게 21%p의 원천)이라 "마진=정답"은 과장이고, LLM이 소유하는 매핑에 편향과 가치가 함께 산다.

## 분석
| 옵션 | 내용 | 장점 | 단점 | 근거 |
|---|---|---|---|---|
| A | 프롬프트에 이념 직접 주입 | topline 즉효 | 결론 절반 주입 + RSS 폭주(민감도 파괴) | [강] 기각 |
| B | 구성비로만 사용(서사에서 이념 라벨링 → 샘플링 가중, 모델엔 비공개) | 모델은 원인-인접 서사로 추론, 모집단만 실측 정합 | 라벨러 편향 개입 | [중] |
| C | 사후 재가중(Step1 자가진단 그룹을 갤럽 마진으로 가중) | 생성 무개입, 기존 raw로 $0 실험 | 자가진단 품질에 종속 | [중] |

## 결정 (2026-07-18, 대표)
**A 금지. B+C로 시작.** 추가 가드: (i) 마진은 타깃 선거와 독립적 시점·출처만 사용, (ii) **G9 비-LLM 베이스라인**("마진+기계적 매핑")을 항상 병기해 LLM 증분 기여를 분리 — 못 이기면 마진 낭독에 불과함을 인정, (iii) 정당ID 유/무 조건 반응성(델타 크기) 비교를 채택 게이트로. 선거 topline의 부분 순환성 자체는 제거 불가 — 한계로 공개. 제품 과제(광명 편입)는 좌우 이슈가 아니므로 이 우려가 완화됨을 기록.

## 구현
미착수. W3-8 페르소나 합성(T2)에서 B, 기존 raw 재가중 실험(C)은 0단에서 가능.
> **실행층 구체화 (2026-07-18)**: B의 라벨러 순환 차단 게이트와 MDIS 직접 샘플링 경로는 **ISS-010**으로 분리 결정됨. G9 베이스라인 구현은 **T8**(구현계획_v1) 신설로 해소.

## 검증
계획: 정당ID 유/무 반응성 게이트 + G9 병기 리포트.
