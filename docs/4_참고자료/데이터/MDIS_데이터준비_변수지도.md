# MDIS 데이터 준비 지도 — T2 페르소나 합성 재료

> **조사 기준일**: 2026-07-22 (웹 실측 검증. MDIS 페이지·Dynamo-K 원문 대조)
> **위치**: [구현계획_v1](../../2_전략기획/구현계획_v1.md) T2(페르소나 합성)·T9(광명 garnish)·W1-2(데이터 확보)의 실행 보조 문서. 태스크·주차 정본은 구현계획_v1.
> **표기**: ✅ = 웹에서 직접 확인 / ❓ = 미확인·확인 필요 (인용 전 검증)
> **기관명 주의**: 통계청이 **국가데이터처**로 개편됨. `mdis.kostat.go.kr` → `mdis.mods.go.kr` 리다이렉트 ✅ — 기존 문서 링크는 아직 동작하나 신규 표기는 mods 기준 권장.

---

## 0. 요약 — 핵심 발견 3가지

1. **"MDIS 신청"은 사실상 리드타임이 없다.** 인구주택총조사 **2% 표본은 공공용 다운로드** — 회원가입(ONE-ID) 후 이용목적 입력하면 **즉시·무료 다운로드** ✅. 심사·승인·수수료가 붙는 건 **인가용**(20% 표본, 원격접근 RAS)뿐. → W1 크리티컬 패스에서 "MDIS 승인 대기" 리스크 소멸. 오늘이라도 받을 수 있음.
2. **이번 학기에 쓸 수 있는 센서스는 2020년 2%가 유일.** 2025 총조사(2025-11 실시)는 **2026년 11월 결과 공표** ✅ → 마이크로데이터는 그 이후. Dynamo-K도 2020 2%를 썼으므로(✅ 원문 확인) **선례와 동일 연도** = 방법 이식에 유리. 2020→2026 인구구조 변화는 2024 등록센서스 **집계 마진으로 레이킹(E2)** 보정하는 걸 옵션으로.
3. **공공용 마이크로데이터의 지역 상세도는 시도(17개)까지** ✅ — 광명시(시군구) 레코드는 공공층에선 안 나옴. 광명 특화는 계획대로 **T9 집계 공변량 + F4 소지역 추정**으로 가는 게 맞고, 예외적으로 **지역별고용조사는 시군구 수준 공공 제공** ✅이라 소득(임금) 축만큼은 광명 조건부가 가능하다 (아래 §2).

## 1. 공짜로 결합돼 있는 것 — 인구주택총조사 2020 2% (공공용 다운로드)

### 파일 구성 ✅ (MDIS 서비스유형별 제공항목 페이지)

| 파일 | 항목 수 | 서비스 |
|---|---|---|
| 2020 **2%_표본_인구** | **90개** | 다운로드(공공용) |
| 2020 **2%_표본_가구주택** | **58개** | 다운로드(공공용) |
| (참고) 1%_표본_인구/가구주택 | 82/54개 | 다운로드(공공용) |
| (참고) 20%_표본_인구/가구/주택 | 130/71/16개 | **인가용** — 원격접근·센터 |
| (참고) 2024 전수(등록센서스) 인구·가구·주택 | — | **인가용** |

### 규모·지역 상세도 (Dynamo-K 원문 대조 ✅)

- 2020 2%에서 **유권자 연령(18+) 레코드 794,342명**, 대표 인구 약 4,160만. 지역은 **17개 시도** — 시군구 미분화.
- Dynamo-K 핵심 5축: 연령(14구간, 18-19~80+) × 성(2) × 시도(17) × 교육(4) × 혼인(4) → **비어있지 않은 셀 5,790개**.
- → T2의 "시도별 n≥200 층화"는 794k 레코드면 여유. KGSS 조건부 시딩에 필요한 **연령·성·시도·학력이 2% 인구 파일에 전부 존재** → 시딩 즉시 가능.

### 항목 그룹 (2020 조사표 기준 예상 — ❓ 최종 확인은 다운로드 시 파일 레이아웃/'항목보기'로)

- **인구(90항목)**: 성·연령·혼인상태, 교육정도(재학·졸업), 경제활동(산업·직업·종사상지위), **통근·통학(장소·수단·소요시간)**, 거주지 이동(1년·5년 전), 활동제약 등
- **가구주택(58항목)**: 가구 구성·세대 구성, 주택 종류, **점유형태(자가/전세/월세)**, 거주 층·연면적 구간, 거주기간 등
- **2%에 없는 것**: **소득**(센서스 비조사 항목 — 조인 필요, §2), **종교**(2015년 조사만 있음 — 필요 시 2015 2% 또는 KGSS 시딩), **시군구**.

## 2. 조인해야 하는 것 ① — 소득

> 배경: Dynamo-K는 센서스에 없는 6개 속성(직업·소득수준·주거유형·종교·미디어원·지역정체성)을 **규칙 기반으로 보강**했다 ✅. 우리는 직업·주거는 2% 실측 필드로 대체 가능하고, 소득은 아래 실측 조건부 조인으로 **선례보다 개선**할 수 있다 — 단 T9 원칙 준용: 조인 효과는 **T10 어블레이션 통과 후 채택**, EXP 카드 필수(AGENTS 규칙 6).

### 후보 비교

| | **지역별고용조사** (1순위) | **가계금융복지조사** (2순위) | 가계동향조사 (참고) |
|---|---|---|---|
| 제공 ✅ | 공공용 다운로드, 반기별 2013~2025 | 공공용 다운로드+온라인분석 (2017~2025) | 공공용 시계열 |
| 지역 | **A·D형 = 시군구 수준** ✅ (B형 전국·C형 시도) | **공공용은 시도 변수 미제공** ✅ ("표본규모 사유" — 페이지 명시) | 시도 수준 ❓ |
| 소득 변수 | **임금근로자의 임금** + 산업·직업·교육·종사상지위 | **가구 경상소득(근로·사업·재산·이전)·자산·부채** — 행정자료 보완 ✅, 가구마스터 160항목 | 분기 가구 소득·지출 |
| 용도 | **P(임금 \| 시군구·연령·성·교육·직업)** — 광명 조건부 가능 | 전국 조건부 P(가구소득 \| 연령·학력·점유형태·가구원수) — 자산·부채까지 | 보조 검증 |
| 한계 | 임금근로자의 **개인 임금**만 (자영업 소득·가구소득 없음) | 지역 조건부 불가(공공용). 인가용 RAS 207항목엔 시도 포함 가능성 ❓ | 표본 소규모 |

### 조인 설계 시 유의 (결합구조 보존)

- 소득은 나이·지역·학력을 통제해도 **점유형태·직업과 잔여 상관**이 있음 → 조건 집합에 **점유형태·종사상지위를 포함**해서 조인할 것 (조건부 독립 가정 최소화).
- 두 소스 병용 권장: 지역별고용조사로 **지역 기울기**, 가금복으로 **가구 단위 수준·자산** — 역할 분리.

## 3. 조인해야 하는 것 ② — 신념 (KGSS 조건부 시딩)

- **확보 경로 ✅**: KOSSDA(kossda.snu.ac.kr)에 **KGSS 2003-2025 누적자료** 등재 — 회원가입 후 신청·다운로드. Dynamo-K가 쓴 2003-2023 누적(21,055 유효 레코드)보다 **2파동 신선**.
- T2 명세 그대로: **P(성향 | 연령·성·지역·학력)** + 셀<5 계단식 폴백(셀→지역→전국). Dynamo-K는 신념 5차원(정부책임·경제관·사회관·국가자긍심·통일관)을 시딩 ✅ — 우리 문항 선정은 **코드북 대조 후 확정** ❓(이념성향·정당지지 문항 코드 확인).
- ⚠️ **이념 라벨을 페르소나에 쓰려면 ISS-010 인간 이중코딩 게이트 선행** (DECIDED).

## 4. 광명(시군구) 재료 — T9 garnish용 (마이크로데이터 밖)

공공층 마이크로데이터가 시도까지이므로, 광명 특화는 **집계 공표 자료**로 (T9 "실측 공공데이터만" 원칙과 정합):

- **SGIS(통계지리정보서비스)**: 광명시·동 단위 인구·가구·주택 집계, **통근·통학 흐름(서울 통근율)** ❓(구체 표 위치 확인)
- **국토부 실거래가 공개시스템**: 광명 주택가격
- **KOSIS 시군구 통계**: 점유형태·주택유형 집계
- **지역별고용조사 A/D형**: 광명 임금·고용 구조 (§2 — 유일한 시군구 마이크로데이터 축)
- (선택 업그레이드 ❓) **20% 인가용(RAS)의 시군구 포함 여부 확인** — 포함 시 광명 실레코드 직접 추출 가능. 단 유료·심사·반출승인이라 비용 게이트(ISS-014) 안에서 판단.

## 5. 이용 절차 (확인분)

- **공공용 다운로드** ✅: 회원가입 → 자료 검색 → **이용목적 입력 → 즉시 다운로드(무료)**.
- **인가용(RAS)** ✅: 신청서 + **연구계획서 + 예상 결과표** 제출 → 심사 → **결제(유료)** → 원격분석서버 접속, **자료 반입·반출은 국가데이터처 승인** 필요. 소요기간·수수료 구체 수치는 미게시 ❓ → 공지/콜센터 02-2012-9114.
- 공통 의무 ✅: 자료이용 **출처 명시** + **연구결과물 제출**.
- 다운로드 파일은 받는 즉시 `data/` 레지스트리 + **sha256 등록** (ISS-002·W1 인프라 절).

### 이용목적/연구계획 문안 초안 (수정해서 사용)

> 공공데이터와 대규모 언어모델(LLM)을 결합한 **합성 인구 기반 정책 여론 시뮬레이션의 정확도 검증 연구**(대학 창업형 현장실습 프로젝트). 인구주택총조사 2% 표본의 인구·가구 결합분포에서 합성 페르소나 표본을 가중 추출하고, 한국종합사회조사(KGSS) 조건부 분포로 신념 속성을 시딩하여, 공표된 선거·여론조사 실측치 대비 재현 오차를 채점한다. 분석 결과는 집계 수준(시도×연령×성 셀)으로만 산출하며 개별 레코드는 재식별·외부 공개하지 않는다.

## 6. 이번 주 체크리스트

- [ ] MDIS(mods) 회원가입 → **2020 2% 인구·가구주택 다운로드** + 파일 레이아웃 저장 (오늘 가능)
- [ ] 받은 즉시 `data/` 이동 + sha256 레지스트리 등록 (ISS-002)
- [ ] 레이아웃에서 §1 항목 그룹 실재 확인 (❓ 해소) — 특히 통근통학·점유형태·산업직업
- [ ] **지역별고용조사** 최신 반기 A형(시군구) 다운로드 + 광명시 코드 존재 확인
- [ ] **가금복** 공공용 가구마스터 다운로드 (전국 조건부 백업)
- [ ] KOSSDA 가입 → **KGSS 2003-2025 누적자료** 신청 + 코드북에서 이념·정당지지 문항 코드 확인
- [ ] (선택) 20% 인가용 항목표에서 시군구 여부 확인 → 필요 시에만 인가용 신청서 준비 (§5 문안)
