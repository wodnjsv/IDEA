## 2. 데이터별 상세

### ① 센서스 2% 인구사항 — 사용 변수 15개

`가구일련번호`(결합키) · `행정구역시도코드` · `행정구역시군구코드` · `성별코드` · `만연령` · `교육정도코드` · `혼인상태코드` · `경제활동상태코드` · `종사상지위코드` · `산업대분류코드` · `직업대분류코드` · `통근통학구분코드` · `통근통학장소코드` · `통근통학_소요분수` · `인구가중값`

- 필터: 만연령 ≥ 18 → **794,521명** (Dynamo-K 794,342와 정합 — 교차검증)
- **전국판 추출**: 시도 17개에 가중 인구 비례 배분(최소 5명) 후 시도 내 `인구가중값` 비례 무작위 추출 → 500명
- **광명 트랙 추출**: 시도=31 & 시군구=060 필터(성인 4,568명) → 가중 비례 500명

### ② 센서스 2% 가구주택사항 — 사용 변수 5개

`가구일련번호`(결합키) · `점유형태코드` · `거처종류코드` · `세대유형코드` · `가구가중값`

- ①과 `가구일련번호`로 **정확 결합** (같은 조사 내 ID 조인 — 조사 간 사람 매칭과 구별됨)

### ③ 지역별고용조사 A형 — 급여 조회표 W

사용 변수 6개: `4자리_행정구역시군구코드` · `성별코드` · `만연령`(연속형 — 자체 4구간 변환코드는 미사용) · `교육정도_학력구분코드` · `최근3개월_월평균급여`(단위 만원) · `시군구가중값`

- 표 구조: P(급여 7구간 밴드 | 조건) — 계단식 폴백:
  **L1** 시군구×연령6×성 → **L2** 시도×연령6×성×학력4 → **L3** 시도×연령6×성 → **L4** 전국×연령6×성 (셀 최소 n=30)
- 급여는 **스켈레톤이 임금근로자(종사상지위=1)일 때만** 추첨 (자영업 소득은 미커버 — 알려진 한계)
- 실사용 결과: 광명 트랙 급여의 98%가 L1(광명 3106 자체 셀), 전국판은 주로 L2

### ④ 가계금융복지조사 가구마스터 — 가구소득 조회표 I

사용 변수 6개: `수도권여부`(G1/G2) · `가구주연령_10세단위코드`(G1~G5) · `가구주_교육정도_통합코드`(G1~G4→3분류) · `입주형태통합코드`(자기집/전세/월세/기타) · `소득10분위코드(보완)(2017년~)`(D01~D10) · `가중값`

- 표 구조: P(소득10분위 | 조건) — **L1** 수도권×연령10×학력3×점유4 → **L2** 수도권×연령10×점유4 → **L3** 수도권×연령10 → **L4** 전국
- 조건 조회는 페르소나 본인 속성 기준 (가구주 근사 — 알려진 한계, 검증리포트 §6-3)
- 공공용이라 시도 변수 없음 → 지역 조건은 수도권 여부까지만

### ⑤ KGSS 누적자료 — 정치성향 조회표 K

사용 변수 6개: `YEAR` · `PARTYLR`(1=매우진보~5=매우보수, DK/무응답은 0으로 보존) · `REGION`(7권역) · `AGE` · `SEX` · `EDUC`

- 파동: **최근 3파동(2021·2023·2025)만** 사용 (시대 혼합 왜곡 방지 — 민감도 체크는 후속 EXP)
- 표 구조: P(성향 6상태 | 조건) — **L1** 권역7×성×연령6×학력4 → **L2** 성×연령6×학력4 → **L3** 연령6 → **L4** 전국 (셀 최소 n=5, T2 명세)
- ⚠️ KGSS 지역은 권역 7뿐(경기="인천경기") → 광명 성향은 사실상 수도권 평균
- ⚠️ **이념 라벨은 ISS-010 인간 이중코딩 게이트 통과 전 개발용** — 프로덕션 런 사용 금지

## 3. 하모나이제이션 (조회를 가능하게 한 공통 축)

- **연령 6구간**: 18-29 / 30대 / 40대 / 50대 / 60대 / 70+ (①③⑤는 연속형 나이에서 직접 생성, ④는 자체 10세 단위)
- **학력 4분류**: 중졸이하 / 고졸 / 전문·대졸 / 대학원이상 (①⑤ 8분류·③ 0~7 → 통일, ④는 자체 4분류를 3분류로 축약)
- **지역 3층**: 시군구(①③) > 시도 17(①③④수도권 파생) > 권역 7(⑤). 시군구 코드 이종 매핑은 광명 1건만 검증(센서스 31-060 ↔ 지역별고용 3106)
- 구현: `src/engine/harmonize.py`
