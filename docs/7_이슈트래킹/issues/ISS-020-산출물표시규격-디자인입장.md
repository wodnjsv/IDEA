## 문제 (Issue)

AGENTS.md 불변원칙은 **"벌거벗은 단일 숫자 금지"**, **"조건 민감도 보존"**, **"최빈값 집계 금지"**를 못 박았고, ISS-009·012·015·019는 `개발 지표` / `봉인 백테스트` / `미검정(부족 표본)` / `MEMORIZATION_RISK` / `paired 무효` 라벨을 각각 산출했다. 그러나 **이 규칙들이 사람에게 보이는 층(리포트·화면)에 어떻게 강제되는지에 대한 규격이 어디에도 없다.** 산문으로 흩어져 있을 뿐이다 — ISS-012가 "모델 버전 고정이 문서 산문에만 있고 코드 게이트가 없다"고 지적한 것과 **정확히 같은 실패 모드**가 표현층에서 반복되고 있다.

구체적 증거:

1. **디자인 관련 ISS 카드 0건.** gstack 리뷰 리포트에서도 Design Review는 실행 0회(`parkj-main-design-20260705-151404.md` GSTACK REVIEW REPORT). UI/UX는 이 프로젝트에서 한 번도 적대적 검토를 받지 않은 유일한 축이다.

2. **W15 데모 시점에 게이트 미달일 가능성이 높다.** EXP-004 잔여 편향 **+9.07%p** vs W10 게이트 **5%p**. EXP-005 D·E **양 암 기각**. EXP-006 실 API 콜 **0회**. 이 상태에서 화면이 "정확한 예측기"로 읽히면 발표대본의 정직 원칙과 정면 충돌하고, 선거법 §108조의2 리스크도 커진다.

3. **델타 자체가 프롬프트 표면 형식에 과민하다는 실측이 있다.** EXP-005 D암은 카드 문구만 바꿔 마진을 +27.55 → −38.24, **65.8%p** 흔들고 승자를 뒤집었다. 우리가 파는 것이 바로 그 조건 민감도 면이다. ISS-006이 "G8 통과 전 검증됨 마케팅 금지"를 이미 못 박았는데, **이 금지가 화면 카피에 어떻게 내려앉는지가 미정의**다.

4. **경쟁사 반례**: Aaru 랜딩은 `0.90 median correlation`을 오차·표본·조건 없이 맨몸으로 게시한다. 규격이 없으면 우리도 같은 형태로 미끄러진다 — 특히 데모 압박이 있는 W15에.

## 분석 (Analysis)

문제는 두 겹이다: **(A) 신뢰를 어디서 빌려올 것인가**(디자인 입장), **(B) 규칙을 무엇으로 강제할 것인가**(표시 규격).

### (A) 디자인 신뢰 입장 — 무드보드 10장 근거

레퍼런스 10건을 실측 캡처해 계열별로 신뢰의 출처를 분해했다.

| 옵션 | 계열 | 신뢰의 출처 | 장점 | 단점 | 근거 등급 |
|---|---|---|---|---|---|
| A | 관공서 (주민e직접·KOSIS·선관위·NESDC·경기데이터드림) | "공공기관이니까" | 의원실이 즉시 익숙. 고객 브랜드 색 차용 가능 | **학생팀은 빌릴 수 없는 신뢰.** 흉내내면 가짜로 보이고, 선거법상 공적 공시로 오인될 위험이 오히려 증가 | [중] 기각 |
| B | 조사기관 (갤럽·한국리서치) | 축적된 권위 | 절제된 톤. 가장 싸게 구현 | 권위가 아직 없음. 조건 민감도 면 같은 인터랙티브 산출물을 담을 형식이 부족 | [중] 부분 채택(절제 상한선으로만) |
| C | **데이터저널리즘 (Our World in Data)** | **"출처·오차를 다 공개했으니 직접 검증해라"** | **지금 당장 가질 수 있는 유일한 신뢰.** 정직성이 장식이 아니라 레이아웃 골격(제목 밑 정의문 / 차트 밑 출처 인라인 / Download·Share 1급 / 인코딩 토글). 발표대본 §6·§0과 동일 명제 | 한국 관공서 맥락에서 낯섦 | **[강] 채택** |
| D | 경쟁사 (Aaru) | 세련미 | — | C1(벌거벗은 숫자 금지) 정면 위반 | [강] 기각 — **반대 사례로 활용** |

근거 [강] 판정 사유: C는 취향 선호가 아니라 **팀의 현재 자산과 유일하게 정합하는 선택**이다. A·B는 우리에게 없는 자산(기관 지위·축적 권위)을 전제하고, D는 명문화된 불변원칙을 위반한다. 소거법이 아니라 정합성으로 남는다.

### (C) 판정 기준

YC 파이프라인 원문(Eve Bouffard)은 변형 16개를 **취향으로** 고른다. 랜딩페이지엔 맞지만 IDEA엔 안 맞는다 — 이 화면의 목적은 과신 방지이므로 판정도 측정 가능해야 한다. **과제 테스트**(DESIGN_SOUL §9)로 대체 제안: 변형을 보여주고 "이 결과 얼마나 믿어도 됩니까 / 인용해도 됩니까"를 묻고, **데이터가 허용하는 것보다 확신에 차서 답하면 탈락.** n=3~5. 이건 통계가 아니라 화면이 거짓말하는지 잡는 장치다.

## 결정 (Decision)

**(인간 결정자 대기 — 규칙 8. 아래는 에이전트 제안이며 2026-08-06 세션에서 창업자가 옵션 A(입장)·2(강제)를 구두 선택함. 기명 DECIDED는 별도 승인 필요.)**

제안 1 — **디자인 입장: 옵션 C (OWID 계열)**. 골격은 OWID, 표기 규율(시점·출처·라벨)은 KOSIS/선관위, 절제 수준 상한은 갤럽. 근거 [강].

제안 2 — **숫자 표시 규격(옵션 2)**: IDEA의 모든 대외/대내 산출 수치는 4필드를 달고 다닌다. **하나라도 없으면 렌더하지 않는다.**

```
Estimate {
  value        58.13
  interval     ±9.1%p          // CI / 예측구간 / 잔여편향
  provenance   gpt-4o-mini-2024-07-18 · cutoff 2023-10 · n=1,000 · k=5 · weight_bank
  status       개발지표 | 봉인백테스트 | 미검정(부족표본) | MEMORIZATION_RISK
}
```

제안 3 — **상태 라벨은 5종으로 고정.** 임의 추가 금지. 전부 기존 카드에서 유래:

| 라벨 | 의미 | 출처 |
|---|---|---|
| `개발 지표` | 반복 채점 허용, **대외 인용 금지** | AGENTS 홀드아웃 규율 |
| `봉인 백테스트` | 사전등록 커밋 동결 후 1회 채점 | ISS-009 |
| `미검정 (부족 표본)` | 검정력 미달 — 통과도 탈락도 아닌 제3 상태 | ISS-015 결정 2 |
| `MEMORIZATION_RISK` | 컷오프 오염 의심 | ISS-012 / ISS-019 |
| `paired 무효` | 암별 모델 혼재 | ISS-019 (`score_ab.py`가 이미 출력) |

제안 4 — **플랜 B는 별도 화면이 아니라 기본 상태.** 게이트를 통과해도 화면 구조는 바뀌지 않고 **status 라벨만 바뀐다.** 근거: W15 시점 게이트 미달 확률이 실질적이고(문제 §2), 두 벌 화면을 만들면 데모 당일 어느 쪽을 켤지가 정치적 판단이 되어 정직 원칙이 압력에 노출된다.

제안 5 — **판정은 취향 투표가 아니라 과제 테스트**(분석 C). 결과는 해당 라운드 카드 또는 `audits/`에 기록.

기각 기록: 옵션 A(관공서 계열) — 빌릴 수 없는 신뢰 + 공시 오인 리스크. 옵션 B 단독 — 형식 부족. 옵션 D — C1 위반. 옵션 1(산문 권고) — ISS-012가 실증한 실패 모드.
