# AUDIT — EXP-017 GPT-5.5 소득 동일·남편30%·아내30% 비교

- 날짜: 2026-09-14
- 독립 검토자: design_audit
- 상태: **최종 실제 캐시·paired 집계·보고서 검증 통과 — 인간 정확도·국민 대표성 검증은 아님**
- 관련: EXP-017, EXP-016, ISS-011, ISS-028, ISS-003, ISS-014
- 범위: 사용자 승인 모델 교체와 세 조건 재실행 설계. 이 감사에서 모델 호출·실제 비교 결과 열람·구현 코드 변경은 하지 않았다.

## 1. 승인된 설계

사용자는 구독 기반 GPT-5.5 대체와 E/H30/W30 세 조건을 명시 요청했다. 동일1,200명·동일 상세 응답과 질문·선택지 순서로 각 조건을 새 독립 세션에서 실행한다. 총3,600개 유효 응답이며 기존 Luna 결과는 보존하고 섞지 않는다. 소득 동일 baseline도 GPT-5.5로 새로 생성한다.

primary는 같은 인물의 H30−E 및 W30−E P50 확률 차분이다. 전체 여섯 선택지와 집단별 분모를 보존하며 실제 국민 반응·인간 정확도·확정적 인과효과를 주장하지 않는다. 비교2개, 가족 양측 alpha=.05, 목표 power=.8, n=1,200, k=1, SD(delta)상한1의 정규근사 기획 MDE는 약8.8999%p다. 실제 검정력이나 모델 예측오차 보장이 아니며 EXP 및 계획표를 실행 전에 기록한다.

## 2. 코드 감사에서 확인할 세 가지 경계

1. **모델·조건·캐시 분리:** GPT-5.5는 별도 `gpt55_housework_income` 경로에서 E/H30/W30만 허용한다. requested_model을 prompt cache hash, 모델 카탈로그 선택, thread_start, runtime 검사, launch와 보고서에 일관되게 사용한다. Luna 기본 호출의 해시·경로·캐시는 유지한다.
2. **재시도와 비용:** GPT-5.5는 인물·조건당 최대2회, 전체 최대7,200회다. Luna income에만 허용했던 과부하 세 번째 시도 예외는 적용하지 않는다. driver와 runner가 같은 모델별 재시도 규칙을 공유하며 성공 응답은 다시 생성하지 않는다. ChatGPT 구독 인증만 사용하고 유료 API키·리셋크레딧으로 대체하지 않는다.
3. **실행·보고 정합:** 단일 E probe를 정식 첫 유효 응답으로 포함한다. 성공하면 동일 인물 블록에서 세 조건 순서를 섞어 실행하며 총동시128 이하를 유지한다. 전원 GPT-5.5/openai 반환 정보를 보존하고 불일치·제한 오류는 중단한다. 지식 컷오프는 Luna 값에서 복사하지 않고 GPT-5.5 근거로 별도 확인하거나 미확인으로 표시한다. 실제 스냅샷 미확보 등 제한도 유지한다.

## 3. 현재 판정

설계에 실행을 막을 새 방법론 문제는 발견하지 못했다. 이는 아직 변경 코드나 실제 요청이 통과했다는 판정은 아니다. 구현 후 모델별 조건·캐시·재시도·전역 상한과 기존 결과 보존을 독립 확인하고, 최종 완료 후3,600개 PID-조건 응답·모델 메타데이터·paired 집계·보고서 수치를 따로 검증한다.

## 4. 구현 후 runner/driver 독립 검사 — 첫 요청 전

공유 runner와 driver의 현재 소스를 검토하고 SDK 초기화 없이 AST로 순수 함수·경로 선택·상한 검사 구문을 추출했다. 드라이버는 subprocess를 모형으로 대체해 임시 디렉터리에만 가상 캐시를 생성했다. 실제 모델 호출은 하지 않았다.

EXP-017가 새 모델·세 조건·2회/7,200회 상한·기획 MDE·별도 baseline을 실행 전에 기록한 것을 확인했다. 여기서는 GPT-5.5 접근 가능 여부나 실제 응답을 검증하지 않았다. 단일 E probe를 차단할 코드 오류는 발견하지 못했다. 보고서 모델별 적용 검토는 별도로 진행하며, 이 판정에 포함하지 않는다.

## 5. GPT-5.5 보고서 합성 입력 감사

`minsim_income_report.py`의 GPT-5.5 분기를 임시 디렉터리에서 가상 인물1,200명×3조건으로 실행했다. 실제 raw 결과는 읽지 않았다. 조건마다 행 순서를 다르게 섞고 인물별 확률도 달리하여 PID 기반 paired 집계를 검사했다.

| 검사 | 합성 실행 증거 | 판정 |
|---|---|---|
| 세 조건·두 대비 | E/H30/W30만 집계; 합성 P50 평균 .6/.4/.8에서 H30−E=-.2, W30−E=+.2 확인; 30−10 보조 차분 비어 있음 | 통과 |
| 여섯 키·집단 | 모든 조건·그룹에 여섯 확률 보존; 연도·성별·연령 각 구분 분모합1,200 | 통과 |
| 보고서 숫자 | 합성 핵심 표 60%/40%/80%, 대비−20/+20%p, 적게/많이/U 합산 표시 일치 | 통과 |
| 모델·설정 표시 | EXP-017,3조건,GPT-5.5,유효3,600/3,600,2대비,MDE8.90%p로 표시; EXP-016/5조건/Luna모델/6,000/10%소득열/4대비/9.64%p 잔재 없음 | 통과 |
| 표 구조 | Markdown 표3개 모두 각 헤더·구분선·본문 행의 열 수 일치 | 통과 |
| 미완료·혼입 차단 | W30 1,199명, Luna 요청모델, Luna runtime의 세 경우 모두 출력 생성 전 거부 | 통과 |

표의10%는 위 합성 입력에서 판단 어려움 확률 등으로 나타날 수 있으며, 금지한 것은 실행하지 않은 소득10% 조건 열과 비교다. summary의 question은 원래 다섯 조건 fixture를 보존하지만 실제 groups의 조건과 차분은 세 조건·두 대비만 포함한다.

이 검토에서 수정이 필요한 코드 오류는 발견하지 못했다. 구현 코드는 수정하지 않았다. 실제 모델 응답과 최종3,600건 완전성·집계 결과 검증은 아직 남아 있다.
