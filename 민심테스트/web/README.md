# 민심테스트 UI 프로토타입

사용자 요청(2026-09-11)에 따른 소비자용 소셜 게임 인터페이스입니다. 기존 IDEA 연구 엔진 및 정확도 리포트와 독립된 프런트엔드입니다. 프레임워크·설치 과정 없이 정적 서버에서 실행됩니다.

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory 민심테스트/web/dist
```

브라우저에서 `http://127.0.0.1:5173/`에 접속합니다. `index.html`을 파일로 직접 열지 마세요(ES 모듈 사용).

## 구현 범위

- 홈: 오늘의 민심, 질문 작성 진입, 6개 질문 카드, 카테고리 필터
- 피드: 검색, 인기·최신·반반 정렬, 책갈피
- 예측: 키보드 지원 슬라이더·숫자 입력, 최초 예측 고정
- 결과: 전체 응답, 예시 범위, 연령·성별 비교, 양측 이유, 근거 펼치기
- 투표: 브라우저당 질문별 체험 1표, 선택 변경 가능, 예시 방문자 분포와 합성 분포 분리
- 자유 질문: 찬반·양자선택 유형 → 대상·전제·선택지 편집 → 비공개 초안 저장
- 나의 기록: 참여 질문, 평균 오차(%p), 질문 초안 편집, 저장한 질문
- 공유: 1080×1080 PNG 내보내기, 질문 링크 복사와 실패 시 직접 복사 대안
- 반응형: 데스크톱 상단 메뉴, 모바일 하단 4개 메뉴

## 디자인 방향

2026-09-11 후속 요청: 게임형 디자인의 가독성이 떨어진다는 사용자 피드백에 따라 [Kalshi](https://kalshi.com/)의 실제 흰 배경 화면을 참고했습니다. 얇은 회색 경계, 진한 본문, 정렬된 선택지 행과 카테고리 탐색을 적용했습니다. 배경 그라디언트·기울어진 카드·입체 그림자를 제거하고 초록은 참여 및 선택 구분에 한정합니다.

홈 최상단은 자유 질문 입력창입니다. 8–180자의 질문을 Enter 또는 질문하기 버튼으로 기존 초안 작성 흐름에 전달합니다. Shift+Enter는 줄바꿈이며 한글 조합 중 Enter는 제출하지 않습니다. 그 아래 대표 질문과 인기 질문 3개, 네 테마별로 이어지는 6개 질문을 제공합니다. 홈은 왼쪽 2열 질문 카드와 오른쪽 인기/최신 목록으로 구성합니다. 테마 전환 없이 스크롤로 모든 질문을 보여주며, 별도 검색·탐색 화면은 필터와 정렬을 유지합니다. 1100px 이하에서는 보조 목록을 본문 아래로, 700px 이하에서는 질문과 보조 목록을 한 열로 배치합니다. 카드에는 결과 수치를 미리 공개하지 않습니다. 상단의 검색과 홈 자유 질문 입력창, 데스크톱 메뉴 및 모바일 하단 4개 메뉴로 전체 기능에 접근합니다. 검색은 탐색 경로로 연결되며 홈 복귀 시 숨은 검색어를 초기화합니다.

예측/결과의 기존 단일 질문 흐름을 보존합니다. 결과 비율·점수·내 의견 투표를 먼저 제공하고, 집단 비교·이유·근거는 접기 영역입니다. 차트 예시/미실행/신뢰도 및 범위 성격 고지는 접지 않습니다. 방문자 차트는 별도 파란색으로 구분합니다. 공유 이미지도 밝은 바탕과 진한 글자로 변경합니다. 거래 기능이나 시간에 따른 확률 추이는 도입하지 않습니다.

## 데이터 및 저장

기존 예시 6문항의 비율·범위·참여 수·집단 수치는 `dist/app.js`의 `questions`에 있는 작성된 fixture입니다. 실제 조사나 모델의 산출이 아닙니다. 출처를 발명하거나 검증 등급을 부여하지 않습니다. 공개 조사와 검증 오차는 미연결로 표시됩니다. 공유 이미지와 개별 차트에도 예시/미실행 안내가 포함됩니다.

기록·투표·책갈피·초안은 `minsim-demo-v1` localStorage 키에만 저장됩니다. 로그인·사용자 서버·실시간 투표 집계는 없습니다. 기기나 브라우저, 도메인이 바뀌면 기록은 이어지지 않습니다. 공개 배포 전 저장 정책 및 동의 UX 검토가 필요합니다.

예측 점수: `max(0, 100 - abs(내 예측 - 예시 비율) × 2)`. 최초 제출은 고정됩니다. 조건을 변경한 자유 질문에는 기존 예시 결과를 재사용하지 않습니다.

## 이후 엔진 연결 지점

1. `questions`: 질문 ID, 질문 유형, 대상, 조건, 선택지, 버전이 있는 질문 API로 교체.
2. `draft-step-two`: 현재 초안 저장을 서버 정규화/검토/승인 흐름과 연결. 사용자 확인 이후에만 실행.
3. `prediction-form`: 예측 저장 후 시뮬레이션 작업 ID를 받아 명시적 대기·실패·재시도 화면으로 연결.
4. `result`, `groups`: 집계값과 함께 불확실성 유형, 모델 스냅샷, 데이터 시점, 표본수·가중치, 검증 상태를 필수 수신. 근거 누락 시 결과 공개 중지. 미산출·미검정 상태를 성공처럼 바꾸지 않음.
5. `visitor`, `records`: 실제 사용자 투표와 인증된 예측 기록을 별도 API로 관리. 가중 합성 결과와 방문자 결과를 합산하지 않음.
6. `drawShare`: 연결된 질문 버전 및 결과 근거/상태를 카드에 함께 전달. 현재 시연 표시는 실제 연결 완료 및 검증 전 제거 금지.

기존 예시 6문항은 통계 실험·API 호출을 수행하지 않았습니다. 별도로 아래 완료된 실험 집계를 연결했으며, G8/TOST 게이트 통과나 인간 정확도를 주장하지 않습니다. 민심 월드컵, 랭킹, 시민과의 대화는 초기 MVP 밖의 후속 단계입니다.
