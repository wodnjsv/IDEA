# ISS-043: EXP-011 H1의 추정대상 결함 — 도너 복사(A)와 인구구성 재가중(B0′)은 같은 것을 추정한다

- **상태**: ANALYZED
- **유형**: 방법론
- **심각도**: P1 (EXP-011 재승인 전 해결)
- **발견**: 2026-09-26. EXP-019 설계 중 작성 에이전트가 유도했다(`EXP-019:40`). 내부 적대적 검토(EXP-019 개정 v0.1)에서 합성 다항분포 모의로 재확인했다. 이전 기록으로는 2026-09-23 팔로업 리뷰 N-05(b)와 ISS-026 추기(미검증)가 있다. Claude 단일 모델 결과이며 교차모델 검토 전이다.
- **관련**: EXP-011(H1 `EXP-011:24`, §5 행 1 `:81`), EXP-019 §0-3·§1, ISS-025, ISS-026, AUDIT-2026-09-15-codex-crossreview-2

## 문제 (Issue)
EXP-011 H1은 "도너 복사 A의 권역 TVD가 인구구성 재가중 B0′보다 작다(CI 하한 > 0이고 점개선 ≥ .02)"를 요구한다. 그런데 A는 B0′와 같은 셀에서, 같은 목표 구성으로 도너 1명을 뽑는 방식이다. 따라서 도너 추첨에 대한 기댓값은 **E[A의 주변분포] = B0′**이다. TVD는 볼록함수이므로 Jensen 부등식에 의해 **E[TVD(A, 진실)] ≥ TVD(B0′, 진실)**이 성립한다. A는 B0′보다 추첨 잡음만큼 기대적으로 나쁘다.

그러므로 H1은 우연이나 정의 불일치(뼈대 구성과 B0′ 구성의 차이, 폴백 셀) 외에는 통과할 수 없다. 이 경우 §5 행 1("3권역 실패 → 1단계 취소")이 **설계 단계에서 결론이 미리 정해진다.**

- 증거(합성 모의, 프로젝트 자료 미사용): 5범주 문항에서 참 귀무일 때 반분 바닥 대비 비율이 A 약 1.03~1.13, B0′ 약 0.74~0.85였다. 차이가 등가 마진의 약 2배다. 내부 검토자는 "3권역 모두 '실패 입증'이 거의 확실하다"고 판단했다(EXP-019 개정 v0.1 검토 F01·F02, 모의 스크립트는 세션 scratchpad에 있으며 저장소 외부).
- 이 계산은 추론과 합성 모의에 근거하며 교차모델 검토 전이다.
