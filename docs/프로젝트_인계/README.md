# IDEA 프로젝트 인계 — 먼저 읽을 문서

> 작성·확인: 2026-09-22. 분석 기준: `2e4f3d681f9fe8994b0dc126e00beeee080ac11b`.
> GitHub `origin/main`과 로컬 HEAD가 위 커밋으로 같음을 읽기 전용 확인했다.
> 목적: 새 작업에서 연구 맥락을 다시 복원하지 않아도 되도록 남기는 저장소 내부 참고 문서다. 기존 결정·실험 정본을 대체하지 않는다.

## 1. 현재 프로젝트를 한 문단으로

IDEA는 공공 마이크로데이터와 실제 설문 기록을 바탕으로 가상 응답자의 확률분포를 만들고, 질문·조건 변화에 대한 집단 반응을 실측과 비교하는 연구 프로젝트다. 초기 목표는 광명시 서울 편입 등 B2G 정책 자문이었다. 실제 구현은 **공유 엔진 모듈 + 실험별 로컬 실행/채점 스크립트 + 저장된 결과를 보여주는 민심테스트 정적 웹**으로 구성된다. 미래 여론을 검증된 정확도로 실시간 예측하는 통합 제품이 완성된 상태는 아니다. 강제선택 응답의 편향을 찾아 분포 응답으로 일부 개선한 증거는 있지만, 개인 예측·위약 특이도·지역 전이·새 질문의 실제 정확도는 서로 다른 검증 문제로 남아 있다.

4. 웹/민심 작업이면 [민심테스트와 운영 규칙](03_민심테스트와_운영규칙.md), [DESIGN_SOUL](../8_디자인/DESIGN_SOUL.md).

**우선순위:** 인간이 승인한 DECIDED와 AGENTS의 규칙 → 최신 개정 EXP 및 실제 코드/기록 → 이 인계 요약 → 과거 README·발표 원고·기획 초안. 최근 문서라는 이유만으로 인간 결정을 자동 변경하지 않는다. 코드가 규칙을 구현하지 않았으면 구현 공백으로 기록한다.

## 3. 연구 흐름의 핵심

| 단계 | 배운 것 | 다음 방향 |
|---|---|---|
| phase0 / EXP-001 | 이재명 유효표 과대예측 +21%p. 당시 표집·프롬프트·최빈값 집계 문제가 섞임 | 오차를 모델 탓으로 단정하지 않고 배관과 프롬프트부터 분해 |
| EXP-002~004 | 실측 뼈대 뱅크와 위생 수리. 자책골 약 11%p 회수, 잔여 편향 약 9.1%p | 이념 라벨·저정보 후보·조건 반응을 따로 실험 |
| EXP-005~007 | 신념카드 두 번 실패, 후보 프로필도 역효과. 라벨 제거가 결합구조까지 지움 | 더 그럴듯한 설명 대신 실측 개인 신호의 가치 검사 |
| EXP-008 | 실제 개인 정보는 읽지만 기존 설문 행렬 내 예측에서 통계 기준선에 패배 | LLM의 추가 가치를 새 문항·프레이밍에 한정해 검증 |
| EXP-009 | 강제선택은 효과 크기 과장·위치 편향·유보 소멸 | 응답 채널 자체를 교체 |
| EXP-010 | 분포 발화가 집계·방향 재현을 개선. 개인 수준 재현과 위약에는 실패 잔존 | 분포 출력 유지하면서 지역 전이·특이도·개인성 분리 평가 |
| EXP-011~013 | 실측 살의 지역 전이, 선거 재현의 정보·표현 요인을 분리하는 설계. EXP-012만 실행·정정됨 | EXP-011 v2.1 재승인, EXP-013 v1.1 승인 및 필요한 데이터 대기 |
| EXP-014~017 / 민심테스트 | 상세 실측 프로필 1,200명으로 생활 질문 시뮬레이션, 일부 결과 웹 제공 | 실행 성공과 인간 정답 검증을 구분 |

## 4. 현재 숫자를 읽는 법

- **뱅크:** 전국 5,000명, 광명 4,568명. 광명 '전수'는 **센서스 2% 공개 표본에 있는 성인 레코드 전부**라는 뜻이며 광명 전체 주민 전수조사가 아니다. 인구 속성 정합이 의견 정확도를 보장하지 않는다.
- **분포 채널:** EXP-010 미국 방향 14/17은 해당 등록 방향 기준 통과. 미국 dist 위약 오탐 14/20과 한국 순서 위약 실패도 존재하므로 '모든 게이트 통과'로 압축하지 않는다.
- **개인 충실도:** EXP-010 부속 분석의 AUC≤.55는 해당 평가에서 개인 재현이 우연 수준에 가까웠다는 기록. 집계가 맞는다고 디지털 개인이 맞는 것이 아니다.
- **EXP-012:** 양당 내 54.4% 대 실측 54.6%는 정정된 집계의 탐색 지표다. 전체 후보 분포에서 군소후보 질량 과대, D1 MAE 약 9.8%p가 남았다. 채널 단독 효과가 아니라 프롬프트 묶음 변경이다.
- **민심테스트:** 부모지원 동의 확률 평균 49.7%; 기본 가사 반반 선택확률 81.8%; GPT-5.5 소득 조건 P50 66.7/52.5/54.7%. 모두 실제 국민 비율이나 평균 가사분담률이 아니라 모델 출력 확률 평균이다. 정확도·전국 대표성·인과효과는 미검증이다.
- 단위 구분: %는 확률/비율, %p는 비율 간 차이, TVD는 분포 거리, AUC는 판별 지표, 상관은 절대 오차가 아니다. $0 기록은 해당 실행 당시 API 과금 기록이며 구독·시간 비용까지 0이라는 뜻이 아니다.

## 5. 실제 작업 전에 잊으면 안 되는 것

- 새 실험·캐시 재채점도 EXP 카드부터. 이번 문서화에서는 어떠한 새 모델·임베딩 호출이나 성능 재산출도 하지 않았다.
- `src/engine/registry.py`는 `IDEA_DATA_DIR`을 지원하지만 모든 실험 스크립트가 이를 따르는 것은 아니다. 일부 `exp011_pre_*`는 Windows 절대경로를 가진다.
- EXP-008~010의 일부 재개 key는 모델/프롬프트 변경을 구분하지 않는다. 기존 캐시에 설정을 바꿔 이어 쓰지 말고 [ISS-032](../7_이슈트래킹/issues/ISS-032-실험캐시-설정식별과-재채점-API경계.md)를 확인한다.
- `exp010_kr_score.py`는 SSR 임베딩 API를 호출한다. 'score'라는 이름만 보고 순수 오프라인 작업으로 가정하지 않는다.
- 민심테스트는 `민심테스트/web/dist/`의 정적 웹이다. 새로운 사용자 질문이 실제 모델 실행으로 이어지지 않는다. 투표·북마크·초안은 브라우저 localStorage에만 저장한다.
- 민심테스트 상세 프로필·raw·로그는 로컬 `data/minsim/`에 있으며 GitHub에서 제외했다. 새 clone만으로 전체 재현 입력이 갖춰지지 않는다.
- 현재 생산 원칙은 ISS-022(실측 살). ISS-025의 LLM 증강 허용은 EXP-011의 실험 예외다. dist 사용 사실도 ISS-023의 최종 DECIDED 승인을 뜻하지 않는다.
- 실험 동결·결과 판정과 비자명 코드 감사에는 ISS-026의 **다른 모델** 검토가 필요하다. 같은 모델의 서브에이전트 분업만으로 이 요구를 충족했다고 쓰지 않는다.
- 법적·데이터 사용 경계는 AGENTS/ISS-008/009/012를 따른다. 이 문서는 기존 프로젝트 규칙의 요약이며 현행 법률을 새로 해석한 문서가 아니다.

2026-09-22 원격 병합에서 민심테스트 로컬 번호를 변경했다. 옛 로그와 무하이픈 문자열에는 구번호가 남을 수 있으므로 제목까지 확인한다.

## 7. 문서의 유지 방법과 검토 범위

새로운 인간 결정·EXP 결과·아키텍처 변경이 생기면 해당 정본 카드부터 갱신하고 이 인계서의 날짜·기준 커밋·해당 단락을 함께 고친다. 이 문서가 영구 기억을 자동으로 보장하는 것은 아니므로 AGENTS와 docs 인덱스에 시작 링크를 둔다.

이번 분석은 저장소의 연구 카드·감사·전략 문서, 구현 소스, 저장된 집계, Git 이력 대조에 근거한다. 원시 개인 자료를 새로 분석하거나 모든 PDF·이미지·영상 산출물을 전문 재검증한 것은 아니다. 외부 논문·경쟁사·법률의 최신성을 웹으로 다시 검증하지 않았으며 과거 문헌 수치는 원문 문서의 기록으로 취급한다. 세부 근거와 이번에 찾은 문서 불일치는 [ISS-031](../7_이슈트래킹/issues/ISS-031-인계문서와-검증상태-불일치.md), 코드 실행 위험은 ISS-032에서 추적한다.
