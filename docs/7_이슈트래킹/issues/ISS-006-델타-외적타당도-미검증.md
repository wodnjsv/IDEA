# ISS-006: Δ(프레이밍 민감도)의 외적 타당도 미검증 — 제품 존립 전제

- **상태**: ANALYZED (2026-07-18 상태 정정 — 분석·옵션 정리 완료 상태였음; 감사 F12 반영. G8 운영은 ISS-013·015로 구체화됨)
- **유형**: 방법론 | 사업
- **심각도**: P1 (프로젝트 최대 미해결 리스크)
- **발견**: 2026-07-04, 오차축소 워크플로우 §4bis
- **관련**: ISS-005, 오차축소 문서 §4bis·G8, design doc(§Open Questions)

## 문제
우리 상품은 "조건 X를 바꾸면 여론이 얼마나 움직이는가"(Δ)인데, **LLM의 Δ가 실제와 일치한다는 긍정 근거가 코퍼스에 없고 반증이 있다**: Bisbee — LLM 추정 효과의 48% 유의 불일치·32% 부호 반전(Δ 부정확성의 직접 증거); counterfactual persona 취약(2504.06460). 선거 백테스트는 프레이밍이 1개(투표용지)라 Δ를 구조적으로 검증 못 함. Δ 검증 전의 topline 최적화는 "topline 게임"에 불과.

## 분석
검증 경로: (i) 실측 스플릿 밸럿/설문 실험 대비 LLM Δ의 방향·크기 일치 채점(G8) — 후보 데이터: NESDC 동일이슈 상이문항 쌍(문항 전문 법정 공개), TESS(tessexperiments.org), SocSci210(HF). W2까지 사용 가능 데이터 확정, W8 1차 검증이 design doc에 명시됨. (ii) 모든 프레이밍 실험은 paired within-persona 설계(분산 소거). (iii) 실측 있는 타 이슈를 '무실측인 척' 풀고 봉인 해제 채점(4단 리허설).

## 결정
미결 — 검증 결과가 곧 결정. 단 운영 원칙은 확정: **G8 통과 전 프레이밍 민감도를 "검증됨"으로 마케팅 금지**(대내외 동일), B2G 주장은 "조건별 집단 반응의 방향·크기"로 한정하되 그것도 검증 미완임을 명시.

## 구현
- [ ] W2: split-ballot 데이터 3후보(NESDC/TESS/SocSci210) 사용성 확정
- [ ] W8: 1차 Δ 방향·크기 대조
- [ ] 4단: 신규 이슈 리허설

## 검증
게이트: LLM Δ의 방향 일치율 + 크기 상관을 실측 실험군에서 보고. 미달 시 상품 주장 하향(방향만 / 탐색 도구로).
