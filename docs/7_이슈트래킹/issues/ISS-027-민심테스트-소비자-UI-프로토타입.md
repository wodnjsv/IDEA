# ISS-027: 민심테스트 소비자 UI와 연구 산출물 경계

- **상태**: ANALYZED
- **유형**: 설계·코드
- **심각도**: P2
- **발견**: 2026-09-11 사용자 UI/UX 구현 요청
- **관련**: ISS-020, ISS-021, DESIGN_SOUL.md, web/README.md

## 문제

기존 화면 규격은 의회 연구 리포트와 실제 실험 수치를 대상으로 한다. 최신 사용자 요청은 ‘민심테스트’라는 일반 사용자용 소셜 게임이며, 시뮬레이션 엔진 연결은 이후로 명시했다. 기존 연구 리포트에 새 상품 디자인이나 예시 수치를 적용하면 목적과 검증 상태가 섞인다.

## 분석

| 옵션 | 장점 | 단점 | 근거 |
|---|---|---|---|
| 기존 연구 화면 변경 | 단일 화면 유지 | 기존 수치·표시 규격과 소비자 UX 혼동 | [강] 기각 |
| 독립 web/ 프로토타입 | 연구 엔진 보존, 예측 게임 체험 가능 | 이후 실제 데이터 계약 연결 필요 | [강] 최신 사용자 요청에 부합 |

## 결정

2026-09-11 사용자 지시를 구현 근거로 삼아 `web/`에 독립 체험판을 추가한다. 에이전트는 연구 방법론 결정이나 ISS-020/021의 상태를 변경하지 않는다. 이 카드는 정식 정책 결정이 아니라 구현 범위 분석 기록으로 ANALYZED를 유지한다.

## 구현

- `민심테스트/web/dist/index.html`, `민심테스트/web/dist/style.css`, `민심테스트/web/dist/app.js`
- 자유 질문은 로컬 비공개 초안만 저장. 무관한 질문에 fixture 결과 재사용 금지.
- 결과/집단 차트/공유 카드에 예시·시뮬레이션 미실행·신뢰도 미평가 고지.
- 최초 예측 고정, 투표 변경은 1표 유지, 모델 정확도와 체험 점수 분리.
- 구현 파일을 저장했으며 사용자의 원격 저장소로 커밋/푸시하지 않음.

## 검증

착수 전 독립 설계 감사 및 완료 후 소스 감사 수행. 발견된 라우팅·접근성·저장 실패 안내 결함 6건 수정. 실행 증거는 `../audits/AUDIT-2026-09-11.md` 참조. 모델 검증과 외부 사용자 과제 테스트는 미실시이며 기존 게이트를 VERIFIED로 변경하지 않는다.

## 2026-09-11 게임형 리디자인 후속

사용자는 설명이 과밀하다고 지적하고, 국내외 레퍼런스와 첨부한 보라·코랄·골드 게임 이미지 분위기를 반영하도록 지시했다. 소비자 UI에 한정해 메뉴·홈·참여·결과를 재구성하고 상세 분석은 접기 영역으로 옮겼다. 각 차트의 예시/미실행/신뢰도 표시는 보존했다. 연구 화면 및 엔진의 설계 입장은 변경하지 않았다. 직접적인 사용자 피드백을 근거로 색상 변경만 하는 옵션보다 화면 위계를 함께 바꾸는 옵션을 채택했다([강]: 사용자 요청, [추측]: 실제 참여율 개선은 미측정). 상태는 ANALYZED 유지.

## Kalshi 참고 가독성 개선

사용자는 앞선 게임형 화면의 가독성 저하를 지적하고 Kalshi를 참고한 재수정을 요청했다. 게임 배경의 장식을 줄이는 옵션과 밝은 정보 탐색형 화면으로 바꾸는 옵션을 검토하고, 명시된 새 레퍼런스에 맞춰 후자를 적용했다([강]: 사용자 지시, [추측]: 참여율 효과는 미측정). 흰 배경·짙은 본문·정렬된 선택지·전역 검색·모바일 단일열 카드. 연구 엔진이나 검증 상태는 변경하지 않음. 예측 전 결과 미공개, 예시 참여 수 고지 및 결과별 신뢰도/미실행 안내 보존.

## 홈 자유 질문 입력

사용자가 Kalshi형 화면을 승인하고 자유 질문을 서비스 핵심으로 강조하여 홈 최상단에 채팅형 입력창을 요청했다. 새 대화 시스템을 도입하는 대신 기존 초안 작성 흐름에 입력을 전달하는 최소 변경을 적용했다. trim 후 8–180자 검증, Enter 제출/Shift+Enter 줄바꿈, IME 조합 보호. 등록된 질문 검색과 라벨을 구분하고 체험판/초안 저장 안내 유지.

## 홈 테마 연속 탐색

사용자 요청에 따라 홈의 테마 전환 버튼/정렬을 제거하고 전체 질문을 테마별 연속 섹션으로 표시. 모든 테마를 스크롤만으로 탐색할 수 있으며, 기존 검색/필터 상태로 홈 질문이 누락되지 않음. 질문 카드와 별도 검색 화면의 기능 보존.

## 질문 카드 비율·보조 목록

사용자의 Kalshi 첨부 화면에 따라 홈을 왼쪽 질문 카드 2열/오른쪽 보조 목록 구조로 조정. 기존 인기 목록 이동 및 기존 date순 최신 질문 목록 추가. 입력창과 테마별 연속 탐색 유지. 1100px 이하에서는 본문 다음에 보조 목록을 배치하여 좁은 카드 방지. 데이터는 기존 fixture만 사용하며 예시 고지 유지.
