# ISS-005: 보정(캘리브레이션)의 앵커 과적합 — 일반화 성능 상실 위험

- **상태**: DECIDED
- **유형**: 방법론
- **심각도**: P1
- **발견**: 2026-07-18, 대표 지적 (Q8)
- **관련**: ISS-006(Δ 외적타당도), 오차축소 문서 §E1-E4·§4bis

## 문제
보정을 앵커에 세게 걸면 topline은 맞아도 일반화가 죽는다. 증거: Bisbee — topline 맞춰도 하위집단 회귀계수 48% 불일치·32% 부호 반전; 앵커 과적합의 테일 억압(2505.17682 — 소수 선택지 더 붕괴); OSLR 시점 과적합; SubPOP FT의 제3후보 악화 가능(C1 iv). 보정 자유도가 클수록 일반화 손실.

## 분석
기존 방어선(계획 내): E1 PPI(rectifier를 소량 실측으로 추정, CI가 실측량 따라 확장, 최악에도 고전 추정 수렴 — 원리적 보정), baseline에만 rectifier·Δ는 원출력(anchor+Δ 격리), 홀드아웃 문항 채점, 6·3 지선 홀드아웃, 2×2 델타 불변성, G5 placebo, G9 비-LLM 베이스라인, 4단 신규 이슈 리허설.

추가 검토 옵션:
| 옵션 | 내용 | 근거 |
|---|---|---|
| A | 계층적 축소(partial pooling) — 셀별 보정치를 전역으로 shrink | MrP 표준, low-n 셀 과적합 방지 [중] |
| B | 보정 자유도 최소화 — 문항별 보정 금지, 저차원 축(logit affine·이념조건부 매핑)만 | 일반화 원리 [중] |
| C | leave-one-election-out CV — 대선 학습→총선 검증 교차 | 우리 데이터로 가능 [중] |
| D | DSA(2510.21977) — 조건 변화 시 이동을 직접 학습 | 제품 철학과 동형, 오픈모델·한국 미검증 [중], 중기 |

## 결정 (2026-07-18)
기존 방어선 유지 + **A·B·C를 보정 설계 원칙으로 추가 채택**(D는 중기 검토). 정직한 하한 명시: 도메인 내(선거↔선거) 일반화는 문헌 수준으로 방어되나, **도메인 간 전이(선거→광명 정책)는 task exchangeability(F2, 정량 미확인)에 걸려 4단 리허설 전 미검증** — 이 한계는 보정 기법 선택과 무관하게 존재하며 ISS-006과 함께 관리.

> **결정 추가 (2026-07-18, 감사 F4 반영, 대표 승인)**: C(LOEO)는 **하이퍼파라미터 선택에 사용 금지** — fold가 2~3개뿐이고 선거 유형이 체계적으로 이질(교환가능성 약함)이라 선택은 잡음 적합이 된다. LOEO는 전이 오차의 **기술적 보고(descriptive robustness) 전용**. 하이퍼파라미터(shrinkage 강도 포함)는 사전 고정(default prior·이론값), 지선 fold는 LOEO에서 영구 제외(봉인 백테스트 전용 — ISS-009).

## 구현
미착수. **T7(보정 엔진: ppi_py + balance/ipfn + partial pooling)**에서 A·B·C 반영 (구현계획_v1, 2026-07-18 태스크 신설 — 감사 F5 해소).

## 검증
계획: LOEO 교차검증 결과 + 홀드아웃 5%p + 델타 불변성 + G9 lift.
