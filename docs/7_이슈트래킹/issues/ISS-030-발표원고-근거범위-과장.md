- **상태**: ANALYZED

## 문제 (Issue)

발표 초안은 (1) 김포/경기도의 다른 모집단 조사를 기관만 다른 동일 조사로 설명하고, (2) 인간 비응답·고관여·사회적 바람직성 편향이 LLM에서 모두 사라진다고 하며, (3) 국내 데이터 규제로 해외 경쟁자가 배제된다고 추론하고, (4) EXP-010의 특정 조건 TVD 범위를 전반 정확도처럼 설명한다. 원문 출처와 내부 실험 기록이 허용하는 결론보다 강하다.

상세 근거·출처·수정문: [발표원고 근거 검증](../../4_참고자료/발표원고_근거검증_2026-09-16.md).

PNAS Nexus DOI 10.1093/pnasnexus/pgae533은 LLM의 사회적 바람직성 편향을 보고한다. 개인정보 보호법 제28조의8은 국외 이전 허용 근거를 열거한다. EXP-010은 TVD .015~.081의 범위 외에 역순 .16~.22도 기록한다. 상용 해외 API와 인가용 상세자료의 결합은 승인 환경 적합성을 확인해야 하며 기업 국적으로 해결되지 않는다.
