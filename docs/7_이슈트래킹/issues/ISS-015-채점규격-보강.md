# ISS-015: 채점·게이트 규격 보강 — 지표 희석, 무규격 등가성 게이트, Δ 불확실성

- **상태**: DECIDED
- **유형**: 방법론
- **심각도**: P1
- **발견**: 2026-07-18, 적대적 감사(방법론 F9·F10·F11·F12)
- **관련**: 백테스트 문서 §6(정정), 구현계획_v1 T4·T6·T8

## 문제
(1) **MAE 희석**: phase0의 정치적 유효량인 1·2위 마진 오차는 32.6%p(시뮬 +40.8 vs 실제 +8.3)인데 6후보 평균 MAE "8.4%p"가 헤드라인 — 군소후보 ~0%p가 분모를 채우는 게이머블 지표. (2) **무규격 등가성 게이트**: 델타 불변성·정당ID 반응성·placebo·DK 프로파일 등 "차이 없음"을 요구하는 게이트 전부에 등가 마진·α·검정력이 없다 — 표본이 작을수록 잘 통과하는 역선택(absence of evidence 오류). 다중비교 통제도 없음. (3) **Δ 불확실성 공백**: PPI 보증은 rectify된 baseline에만 닿고, 상품 수치(baseline+Δ)는 비보정 Δ의 편향·분산을 상속하는데 구간 추정이 없다. G8을 통과/탈락 게이트로만 쓰면 상관의 척도 불변성 때문에 "일관되게 3배 과대한 Δ"도 통과한다. (4) **셀 크기**: phase0 시도 채점이 시도당 n~30-60으로 자기 인용 기준(RSS 108명 반전)조차 위반.

## 결정 (2026-07-18, 대표 승인)
1. **지표 추가(T4 필수)**: ⑥ 1·2위 마진 오차, ⑦ 후보별 최대 오차. 5%p 게이트가 의미하는 판세 해상도(마진 최대 10%p)를 리포트에 1줄 명기.
2. **게이트 명세 표준 1쪽**: 각 등가성 게이트에 (등가 마진 예: |Δ 왜곡|<1.5%p, TOST α=0.05, 검정력 ≥80%, 필요 n) 기입. 블록 선택용 평가셋과 최종 통과 선언용 홀드아웃 분리. **명세 작성 규칙(재감사 ⑧)**: MDE 표에서 **예산($500) 내 달성 가능한 (마진·n·k)를 역산해 먼저 고정**하고, 예산 내 검정력 확보가 불가한 게이트는 "**미검정(부족 표본)**" 제3 상태로 정직 표기 — 통과로 위장 금지.
3. **G8을 게이트에서 보정 모형으로 승격**: Δ_real = a + b·Δ_LLM + ε 적합 → 상품 출력은 **b·Δ_LLM ± 예측구간**. 방향 일치율은 |Δ_real|>임계 문항 한정. 회귀 최소 n(문항쌍 ≥20) 사전 명시.
4. **채점 단위 최소 n≥200** 층화 제약(비례 아닌 최소보장+가중 복원) + 시도 승자 적중에 표집 CI 병기.
