# ISS-019 — 추론 백엔드 이중화 (NVIDIA NIM 무료 티어)와 비교가능성 게이트

- **유형**: 코드·사업(비용) · **P**: P2 · **상태**: **VERIFIED** (2026-08-07 실 API 프로브 통과 — §검증. 모델 최종 확정만 인간 결정 대기)
- **관련**: ISS-012(컷오프 게이트) · ISS-014(비용 게이트 $500) · ISS-011(paired 규약) · AGENTS 규칙 6(모델 스냅샷 기록)

## 문제
EXP-004·005를 유료 OpenAI로 돌려 누적 ~$1.3을 썼다. T10 어블레이션·2단 보정은 반복 실행이 전제라 유료 유지 시 ISS-014 예산이 빠르게 소모된다. NVIDIA NIM 무료 티어(`https://integrate.api.nvidia.com/v1`, OpenAI SDK 호환)로 옮기면 비용은 $0이 되지만 **세 개의 새로운 게이트 위험**이 생긴다.

1. **컷오프 오염(치명)** — 무료 카탈로그의 간판 모델(2025년 이후 학습분)은 21대 대선 결과를 이미 알고 있다. ISS-012 게이트에서 전량 차단 대상이며, 통과하는 것은 오히려 **구형 모델**뿐이다. "성능 좋은 모델을 고른다"는 직관이 여기서는 정반대로 작동한다.
2. **비교가능성 파괴** — EXP-005의 D·E 판정은 EXP-004 B암(gpt-4o-mini)과의 paired 비교로 정의돼 있다(ISS-011). 백엔드만 바꾸면 암 간 차이에 **모델 효과가 교란**된다.
3. **병목의 이동** — 유료에서는 비용이, 무료에서는 **RPM(공개 한도 40 RPM, 모델 무관 계정 단위)**이 병목이다. 게다가 다수 NIM 엔드포인트가 `n>1`을 지원하지 않아 K=5 수집이 1콜→5콜로 늘면 요청 수가 5배가 된다.

## 결정 (코드로 강제한 사항)
- `src/engine/llm_client.py` 신설 — 백엔드·모델 레지스트리, 컷오프 게이트, 레이트리미터, K 샘플러를 한곳에 둔다.
- **컷오프 게이트를 기본 차단으로**: 컷오프가 선거일 이후이거나 **1차 출처로 확인되지 않으면 실행 자체를 막는다**(`--allow-memorization-risk`로만 강행, 그 경우 결과에 `MEMORIZATION_RISK` 라벨 강제). 종전 `assert MODEL_CUTOFF < ELECTION_DATE` 하드코딩보다 강한 규격.
- **n=K 자동 강등**: n=K 1콜을 먼저 시도하고 실패·부족 시 K콜 직렬로 내려간다. 판정은 1회만 하고 고착시킨다(페르소나마다 실패콜을 반복하지 않음).
- **원자료 모델 분리**: `raw_{arm}[_smoke][_{tag}].jsonl`. gpt-4o-mini는 tag 없음 → 기존 EXP-004/005 산출물과 파일 충돌 없음. 각 레코드에 `model` 필드를 남긴다.
- **모델 혼재 경보**: `score_ab.py`가 암별 `model`을 대조해 혼재 시 "paired 무효" 경고를 출력한다.
- **키 취급**: 환경변수 우선, 없으면 gitignore된 키 파일에서 정규식 추출. 로그에는 `nvapi-…(API.txt, 70자)` 형태의 지문만 남기고 키 문자는 한 글자도 출력하지 않는다.

## 잔여 리스크 (문서로 못 없앰)
- 컷오프 근거는 **모델카드 등 2차 공개문서**다. 학습 데이터 실물 감사는 불가능하므로 "컷오프 이전"은 강한 주장이 아니라 **최선의 방어**로만 기술한다. 반증 도구는 EXP-006의 사후 지식 프로브(§검증)로 남긴다.
- 무료 티어 한도(40 RPM)는 NVIDIA가 공식 표로 보증한 값이 아니라 계정·모델·혼잡도에 따라 변동한다는 것이 개발자 포럼의 모더레이터 답변이다. 리미터 기본값을 35로 두되 429 관측치를 실행 로그에 남긴다.
- **한국어 역량**은 후보군(Llama·Gemma·Qwen)의 공식 지원 언어 목록과 무관하게 실측해야 한다 → `scripts/probe_nvidia.py`.
