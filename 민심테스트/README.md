# 민심테스트

민심테스트 체험 웹, 실험 스크립트, 기존 집계 결과를 모은 폴더입니다. 결과는 모델 시뮬레이션이며 실제 국민 여론·전국 대표성·예측 정확도를 검증한 수치가 아닙니다.

- `web/dist/`: 정적 웹과 집계 표시 데이터
- `scripts/`: EXP-014~014 실행·프로필 복원·보고서 스크립트
- `questions/`: 실험 질문 정의
- `results/`: 기존 집계 JSON과 결과보고서 사본 (재채점하지 않음)
- [질문지](../docs/8_디자인/민심테스트_6문항_테스트질문지_v1.md)
- [이슈·실험·감사 인덱스](../docs/7_이슈트래킹/ISSUES.md): 정본 문서는 기존 위치 유지

## 웹 확인

저장소 루트에서 실행합니다.

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory 민심테스트/web/dist
```

## 실험 데이터

실행 스크립트는 상위 IDEA 저장소의 `src/engine/registry.py`와 `data/registry.json`을 사용합니다. `IDEA_DATA_DIR` 설정을 지원하며 기본 데이터 위치는 저장소 루트 `data/`입니다. 질문 사본만으로 실험이 실행되는 것은 아닙니다. 등록된 질문 원본·KGSS·기존 페르소나 등 로컬 입력이 필요합니다.

개인별 상세 프로필, 원시 응답 캐시, 실행 로그, 통계 원자료는 이 커밋에 포함하지 않습니다. 기존 로컬 `data/minsim/`은 이동·수정하지 않았습니다. 실행·재집계 출력은 계속 해당 데이터 디렉터리에 저장됩니다. 이 폴더의 `results/`는 2026-09-22 보관본입니다.

스크립트는 기존 환경의 `openai_codex` SDK 및 스크립트별 Python 의존성이 필요합니다. 생성은 구독 모델 세션을 사용하므로 실행 전 관련 EXP 카드·예산·MDE 규약을 확인해야 합니다. 이번 정리에서는 모델 호출이나 재채점을 하지 않았습니다.
