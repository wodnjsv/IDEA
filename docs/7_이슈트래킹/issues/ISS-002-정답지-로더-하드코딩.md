# ISS-002: 정답지 로더 경로 하드코딩 → 데이터 레지스트리로 재설계

- **상태**: DECIDED
- **유형**: 코드 | 데이터
- **심각도**: P2
- **발견**: 2026-07-05, phase0/구현분석.md D2
- **관련**: docs/6_백테스트/백테스트_그라운드트루스.md, phase0/build_ground_truth.py

## 문제
`build_ground_truth.py`가 외부 POSIX 절대경로(`/sessions/trusting-zen-gates/...`)를 하드코딩해 Windows/타 환경에서 실행 불가. 지역명 문자열 매칭도 취약("전북특별자치도" 개명으로 이미 한 번 깨짐).

## 분석
필요 소스가 이질적: 읍면동 정답지는 파일(15025528 대선/15025527 총선 CSV, KOGL), 구시군은 OpenAPI(15000900), 사전투표는 별도 API. 하나의 canonical 스키마로 수렴시켜야 하류 채점 코드가 출처 무관해짐.

## 결정 (2026-07-18)
**레지스트리 + 로더 + 정규 스키마 3층**으로 재작성:
1. `data/registry.yaml`에 데이터셋 선언(출처 URL·파일명·인코딩·컬럼 매핑·라이선스·sha256) — 코드에 경로·컬럼명 0개.
2. 경로 해석은 한 곳: `IDEA_DATA_DIR` env → 기본 `repo_root/data`. 절대경로 금지.
3. 로더: 없으면 다운로드, 있으면 checksum 검증.
4. 정규 스키마 `(election_id, level, region_code, region_name, candidate, party, votes)` — API/파일 어댑터가 같은 스키마 방출(이중 경로).
5. 조인 키는 행정표준코드(법정동코드), 이름은 표시용.
6. 골든 테스트: 전국 합계·후보 총득표를 공표치와 assert.

## 구현
미착수. W1 정답지 수집 태스크(T4 선행)로 예정. CLI: `python -m src.data.ground_truth --election pres2025 --level emd`.

## 검증
계획: 골든 테스트 통과 + phase0 기존 정답지와 시도 단위 수치 일치 재현.
