## 왜 2단인가 (Codex 종합 지적 수용)
형태·선택정책·딱지재심·선거전이를 얹기 전에, 이 패러다임의 존립 질문 두 개부터 깨끗하게 결정한다:
**(Q1) 모델은 개인의 실제 정보를 사용하는가** (길이·형식이 아니라 내용을) — 음성 대조로만 증명 가능.
**(Q2) 같은 입력을 받는 강한 통계 모델을 이기는가** — 못 이기면 "행렬 완성엔 LLM 불필요"가 결론이고, LLM 가치 주장은 행렬 밖(새 질문·프레이밍)으로 한정된다. 둘 다 유효한 답이다.
1단 통과 시에만 2단(EXP-009 — K 곡선 정밀화·형태·선택정책·딱지재심·투표 이식 점검)을 등록한다.

## 가설 (전부 가설 — 심판 명기)
- **H1 (개인 신호)**: 진짜 프로필(K=전체)이 섞인 프로필(같은 셀 타인의 답, 동일 길이·형식)보다 개인 재현이 좋다. 심판: 진짜 vs 섞임 paired 비교.
- **H2 (LLM 증분)**: K=전체(사전 고정 — best-K 선택 편향 차단)에서 LLM이 같은 입력의 강한 ML 베이스라인 3종을 이긴다. 심판: 사람 단위 paired 비교.
- **H3 (정보량, 예비)**: K=전체 > K=5 > K=0. 1차 대비 = 전체 vs 5, 최소 효과 크기 명기.

## 설계 (Part A' — 1단)
- **모집단**: KGSS **2023 파동 단일**(측정동일성 — 3파동 혼합 기각), 응답자 n=1,230 중 **배터리 10문항 중 8+ 유효응답자에서 무작위 300명**(포함 기준·시드 사전 고정). 나머지 ~900명 + 타 파동 = **베이스라인 참조셋**(평가자 답 미사용 — 누출 차단).
- **고정 배터리**: 전원 동일 10문항 (5영역×2 — 정치·경제/가족·젠더/종교·전통/신뢰·사회/문화·생활; 커버리지·유분산 기준 선정, 절차·시드 고정). 프로필에서 배터리 문항 + 동일 배터리·|r|≥0.85 준중복 + 투표·정당·이념 인접 173변수 제외.
- **암 4종** (동일 300명, paired):
  | 암 | 내용 |
  |---|---|
  | K=0 | 실제 인구속성만 |
  | K=5 | + 실제 답 5개 (전영역 층화, 시드 고정) |
  | K=전체 | + 그 사람의 유효 응답 전부 (2023 중앙값 ~376개, 순서 무작위) |
  | **섞인 프로필** | K=전체와 동일 구조·길이, 답만 같은 셀(성×연령대×권역×학력) **타인 1명** 것으로 교체 — 음성 대조 |
- **호출**: **문항별 개별 호출**(배터리 1콜 오염 기각 — Codex #5), k=1, temp 1.0 → 300×4×10 = **12,000콜**, $0(llama-3.1-70b, 동시성 12·RPM 25), 벽시계 ~18h(재개 안전 러너 필수). 교차모델 점검은 사전등록에서 **제외**(조건부 항목의 조작 여지 — 후속 별도 등록).
- **베이스라인 (전부 $0 오프라인, 참조셋 학습)**: ① 순서형 로지스틱(K 입력 동일) ② kNN(응답 벡터 거리) ③ 저계수 행렬완성 ④ 셀 최빈값(약한 기준 병기).

## 판정 기준 (사전등록 — 변경 금지)
- 지표 정의: 문항별 **Spearman**(예측=단일 응답, 실제=원척도; 역코딩 정규화 명기), Fisher-z 평균. 정확도 = 정확 일치 + 서열 ±1 인접.
- **H1 합격**: (진짜 − 섞임)의 사람 단위 부트스트랩 95% CI > 0 **그리고** Δ(Fisher-z) ≥ 0.10 (최소 의미 효과).
- **H2 합격**: K=전체 LLM 정확도 ≥ 베이스라인 ①~③ 전부 (사람 단위 paired, α=.05, 군집 반영). 하나라도 못 이기면 "행렬 내 예측에서 LLM 비우위"로 기록 — 실패도 결과.
- **H3 보고**: 전체 vs 5 (동일 규격) — 예비, 곡선 정밀화는 2단.
- 추론 단위: **사람**(300) — 문항·샘플은 사람 내 군집. 관측치 4,000 독립 취급 금지.
- 일반화 범위 명시: 결론은 "이 고정 10문항"에 한정 — 문항 일반화는 2단에서 배터리 확장으로.
- 상한 규율: raw 80% 초과는 성과 아닌 점검 신호(문헌 재검사 천장) — 섞인 프로필 암이 경험적 영점 제공.

## 2단 예고 (EXP-009 — 1단 H1·H2 통과 시에만 등록)
K 곡선 정밀화(30/90 중첩 티어) · 형태(무손실 서사 — LLM 생성+검증기) · 선택 정책 · 딱지 재심 · Part B 투표 이식 점검(실측 정박 밴드). 1단에서 확정된 규격(고정 배터리·참조셋·문항별 호출·사람 단위 추론)을 승계.

## 결과 (2026-08-26 — H1/H2는 완집 데이터로 확정, K0/K5는 77% 시점 중간치·429 잔여 회수 중)

| 판/기준선 | n | 정확 일치 | ±1 인접 | 개인 간 상관(Fisher-z) |
|---|---|---|---|---|
| 인구만 (K0) | 2,288* | 35.2% | 81.7% | 0.047 |
| 성질 5개 (K5) | 2,300* | 34.2% | 81.1% | 0.061 |
| **전체 프로필 (FULL)** | 2,993 | 39.9% | 83.9% | **0.186** |
| **섞인 프로필 (SHUF)** | 2,992 | 35.9% | 82.6% | **0.061** |
| 릿지 회귀 | 2,996 | **54.3%** | 95.5% | **0.490** |
| 행렬완성 | 2,996 | 51.4% | 93.7% | 0.397 |
| kNN | 2,996 | 50.2% | 92.1% | 0.293 |
| 셀 최빈값 | 2,996 | 45.3% | 91.1% | 0.099 |

- **H1 (개인 신호): 통과** — Δz(진짜−섞임) = **+0.126**, 95% CI [0.073, 0.176] > 0, 최소효과 0.10 충족. 모델은 개인의 실제 답변 기록을 **진짜로 읽는다**(상관 3배: 0.186 vs 0.061).
- **H2 (LLM 증분): 기각 — 완패.** 같은 입력의 강한 ML 3종 전부에게 패배(사람 단위 평균 차 −10~−14%p, p=1.0 방향 역전). **셀 최빈값(최약체)조차 LLM 전체프로필보다 정확**(45.3 vs 39.9%).
- **H3 (정보량, 예비): 방향 확인** — Δz(전체−5개) = +0.125, CI [0.075, 0.176] > 0. 정보량 효과는 실재(K0 0.047→FULL 0.186). 단 5개는 0에 가깝게 무력(0.061 — EXP-007 결합소멸과 정합).
- 해석 주의(기록): LLM은 temp 1.0 단일 샘플(확률적), 베이스라인은 점추정 — 정확도 격차의 일부는 표집 노이즈. 단 상관 격차(0.19 vs 0.49)는 그것만으로 설명 불가.
- 비용 $0 · 재개 3회(절전·429) · 429 대응: 2단 페이싱(대형 8rpm) + 저속 재개 패스.

## 판정

**부분 성공 — 그리고 "LLM의 자리"가 실측으로 확정됐다.**

1. **사용자 가설(개인성·정보량)은 LLM 내부에서 입증**: 모델은 개인 기록을 실제로 사용하고(H1), 정보가 많을수록 개인 재현이 좋아진다(H3). 페르소나 층은 장식이 아니다.
2. **그러나 "측정된 문항 행렬 안" 예측에서는 고전 통계가 압도**(H2 기각) — Codex 사전 경고("행렬완성 과제에서 강한 기준선을 못 이기면 LLM 필요성 없음")가 적중. 사전등록 해석 그대로: **LLM 가치 주장은 행렬 밖 — 새 질문·프레이밍 반응·자연어 조건화 — 으로 한정**된다. 이는 anchor+Δ 전제(수준은 실측/통계, LLM은 Δ)의 개인 수준 재확인이다.
3. **아키텍처 함의(제안)**: 행렬 안 작업(프로필 보완·결측 대치)은 통계 모델이 싸고 우월 → **통계로 채운 완전 프로필을 LLM에 공급하고, LLM은 행렬 밖 과제(새 질문·프레이밍)에만** 쓰는 하이브리드가 자연스러운 다음 구조.
4. **2단(EXP-009) 재검토 필요**: 원안(K곡선 정밀화·형태·딱지)은 "LLM의 행렬 내 재현" 최적화라 H2 기각으로 투자 근거가 약화됨. **다음 결정 시험은 행렬 밖 = G8 프레이밍 실측 대조**(재플랜 P1 — 원래 최우선이던 그것)로 피벗 제안. 인간 결정 대기.
