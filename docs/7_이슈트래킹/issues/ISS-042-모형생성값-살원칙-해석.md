## 문제 (Issue)

ISS-022의 구속 규칙(`ISS-022-페르소나-살-소스원칙.md:23`): "페르소나 뱅크에 새 속성을 추가할 때 그 소스는 실측 마이크로데이터(도너 복사 또는 조건부 추첨)여야 하며, LLM이 속성 값을 발명하는 경로는 금지. 렌더링(문장화)은 사실 불변 조건에서만 허용."

EXP-019는 사용자 요청에 따라 인구 생성 계열을 비교한다. 그중 ② 통계적 합성(순차 CART·DPMPM 잠재계층·베이지안망·가우스 코풀라)과 ③ 심층 생성(조건부 TVAE·학습형 사전 CVAE·TabDDPM)은 LLM이 아니고 실측 KGSS로만 학습하지만, 출력하는 값의 조합은 실존 응답자의 답안이 아니다. 규칙 문구 "도너 복사 또는 조건부 추첨"이 이것을 포함하는지 정해져 있지 않다.

증거:
- 명시 금지 대상은 "LLM이 속성 값을 발명하는 경로"뿐이다(`ISS-022:23`).
- 기각 근거 ① 순환성은 "살 생성 LLM의 고정관념이 … 응답 LLM과 같은 편향 계열"이라는 LLM 특정 논리다(`ISS-022:13`). 실측으로만 학습한 통계·심층 모형에는 그대로 적용되지 않는다 [구조 논증].
- 기각 근거 ② 검증 불가능성은 "발명 속성의 결합분포는 실측 정답이 없다"는 것이다(`ISS-022:14`). 모형 생성 결합은 같은 조사의 실측과 대조할 수 있다 — EXP-019 S1·S2가 바로 그 대조다. 단, 대조를 거친 경우에만 해당한다.
- **좁은 해석 쪽 증거(v0.1 추가 — C-R07)**: ISS-022가 채택한 옵션 3의 문구는 "살은 **실측 마이크로데이터 도너 복사**(현행 KGSS 핫덱 방식)로만 붙인다"이다(`ISS-022:17`). 인덱스 요약도 "(도너 복사, lazy 확장)"이다(`ISSUES.md:28`). 이 문구만 보면 모형 생성 값은 규칙 밖이다.
- **넓은 해석 쪽 증거**: 구속 규칙은 "도너 복사 **또는 조건부 추첨**"이고 명시 금지는 LLM 발명뿐이다(`ISS-022:23`). ISS-025의 비교표는 릿지 문항별 대치(B — 값이 모형 예측)를 규칙 '준수'로 분류했고(`ISS-025:41`), EXP-011은 B(릿지)·B′(PMM)를 예외 없이 계획했다(`EXP-011:45-46`). 즉 비LLM 모형 값에 대한 선례가 있고, 방향은 '준수'다. v0의 "비LLM 모형 생성 값에 대한 기록은 없다"는 틀렸다.
- **범위 쪽 증거**: 규칙의 적용 대상은 "페르소나 뱅크에 새 속성을 추가할 때"다(`ISS-022:23`). LLM을 부르지 않고 뱅크에도 들어가지 않는 $0 오프라인 비교(EXP-019 1단계 S1·S2)가 이 범위에 드는지는 문언상 분명하지 않다.
- **현행 코드(v0 서술 정정 — A-F22, C-R09)**: 생산 뱅크는 KGSS에서 PARTYLR 1문항만, 셀별 **비가중** 경험분포에서 추첨한다(`src/engine/bank.py:66-68`, `src/engine/tables.py:122-146`, `"w": 1.0`은 139행). 이 추첨은 dev 게이트 뒤에서만 쓴다(ISS-010). 나머지 속성은 다른 조사(지역별고용·가계금융복지)에서 속성별로 독립 추첨된다. 따라서 현행 코드가 만드는 비실존 조합은 **조사 간 결합**이고, 한 조사 안에서 여러 문항을 모형으로 합성한 선례는 생산에 없다. v0의 "좁은 해석은 현행 코드와도 맞지 않는다"는 과장이었다 — 근거 등급 [약]. 다문항 도너 복사는 실험 스크립트(`scripts/exp008_prepare.py:166`, `scripts/build_belief_cards_v2.py`)와 EXP-011 계획에만 있다.
- ISS-025의 예외는 LLM 살(C암)을 EXP-011에 한정해 허용했다(`ISS-025:3,67`). ISS-022에는 ISS-025로 가는 역링크가 없다.
- 모형 생성 값의 새 위험: 과적합 모형은 학습 행을 복제한다(개인정보 면에서 핫덱과 같거나 나쁨 — ISS-034). 결합이 무너지거나 가짜 조합을 만들 수 있다(Nemotron-Korea 결합분포 감사에서 결합 3개 실패, `ISS-025:23` — LLM 사례지만 합성 일반의 위험). 딥모형은 KGSS 크기(2023 ≈1,230명)에서 과적합하기 쉽다.

## 결정 (Decision)

**미결 — 인간 결정 대기.** 에이전트는 아래 권고까지만 제안한다.

**에이전트 권고(제안 — 결정 아님, v0.1 변경)**: **옵션 D(EXP-019의 열거된 $0 오프라인 단계 전체는 적용 범위 밖 — v0.2 범위 확대) + 옵션 B(합성 값을 LLM에 넣는 S3에 한정한 실험 예외)**. A·C는 EXP-019 결과 뒤 재상정. D를 받지 않으면 아래 (B′) 문안, 즉 B를 1·2단계 오프라인 암과 S3 전체로 넓힌 'B 단독' 서명으로 덮는다(v0.2 점검). v0 권고는 'B 단독'이었다.
