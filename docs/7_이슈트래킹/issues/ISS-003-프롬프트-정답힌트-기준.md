# ISS-003: 프롬프트에서 "정답 힌트"와 "필요한 세계 지식"을 가르는 기준

- **상태**: DECIDED
- **유형**: 방법론
- **심각도**: P1
- **발견**: 2026-07-18, 대표 지적 (Q5) — 무차별 제거 시 필요한 지식까지 잃는 위험
- **관련**: ISS-007(제3후보 붕괴), phase0/구현분석.md D1, 오차축소 문서 §B2·B4

## 문제
phase0 프롬프트는 지역·세대 성향("영남 보수 우세")과 응답 사전분포("양당 90%", "swing이라고 제3당 고르지 마세요")를 주입 — 정답 오염이자 이준석 0/5,135의 유력 원인. 그러나 제거는 공짜가 아님: ElectionSim 어블레이션에서 이념 태그 제거 시 Macro-F1 58.2→53.5, 정당 태그 제거 −5.6%p. 기준 없는 제거는 위험.

## 분석
검토한 기준: 코퍼스에 이 문제를 정면으로 다룬 논문은 없음. 근접 선례 — Dynamo-K의 명시적 정당-이념 매핑 큐(0.9→18.8% 복원 = 정당한 시나리오 사실 제공), ElectionSim 어블레이션(제거 비용 실측), Domínguez-Olmedo(측정 아티팩트), ML의 target leakage 개념.

## 결정 (2026-07-18)
**기준: "x는 주고, P(y)는 주지 않는다."**
- **주는 것(x·세계 사실)**: 페르소나 사실(직업·거주·통근), 시나리오 사실(출마자, **정당-이념 매핑**, 이슈 타임라인·뉴스 환경).
- **빼는 것(y의 사전분포)**: 응답변수의 집계 통계·행동 지시 — P(투표|지역), P(투표) 사전, "제3당 고르지 마" 류.
- **회색지대(지역 정치 정체성)**: 집단 통계 문장 대신 페르소나 수준 x로 번역해 서사에 싣고, 최종 판정은 **블록별 ± 어블레이션**(홀드아웃에서 정확도 + 하위집단 구조 + 델타 보존 + G5 placebo로 채점). 이 기준은 문헌 종합이지 기성 이론이 아님 — 어블레이션이 최종 심판.

## 구현
미착수. 0단 위생수리(T3)에서 프롬프트 v2 작성 시 적용. 어블레이션 하네스는 paired 소표본부터.

## 검증
계획: 블록별 어블레이션 결과표. 게이트 — 정확도 개선 ∧ 델타 보존인 블록만 유지.
