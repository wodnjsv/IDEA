# LLM 설문 응답 확률 분포 추출·샘플링 방법론 조사 v0 (2026-08-31)

> 작성 경위: EXP-009 한국장에서 응답 붕괴(300명 중 97% 동일 답, temp 1.0에서도)·유보 소멸·위치 편향을 실측한 뒤,
> 돌파구 조사를 위한 딥 리서치(웹 에이전트) 결과 전문. 다음 실험(분포 채널 파일럿) 설계의 입력.
> 모든 수치는 미국(일부 터키) 데이터 기준 — 한국 이전성은 미검증 가설.

## 배경 진단: 왜 단일 답 샘플링이 붕괴하는가

"300명 중 97% 동일 답"은 문헌에서 **mode collapse**로 확립된 현상. Verbalized Sampling 논문(Zhang et al. 2025)은
원인을 **선호 데이터의 전형성 편향(typicality bias)** — RLHF 어노테이터가 익숙한 텍스트를 체계적으로 선호 — 으로
규명. post-training된 모델은 temperature를 올려도 분포 자체가 뾰족해져 있어 반복 샘플링으로는 복원 불가.
터키 WVS 재현 연구(2607.18310)는 독립 에이전트 방식에서 응답 집중도 0.685(실제 0.358), 유닛의 85% 붕괴,
TVD 0.437 보고 — 우리 관찰과 동일 패턴.

## 1. 분포 발화 (Verbalized Distribution)

- 원리: 모델에게 "선택지별 확률을 말로 출력"시켜 분포를 직접 받는다.
- 대표: Verbalized Sampling [arXiv 2510.01171](https://arxiv.org/abs/2510.01171) ·
  [GitHub](https://github.com/CHATS-lab/verbalized-sampling) (VS-Standard/CoT/Multi 변형) ·
  Just Ask for Calibration [2305.14975](https://arxiv.org/abs/2305.14975) ·
  Calibrating Verbalized Probabilities [2410.06707](https://arxiv.org/abs/2410.06707)
- 보정 증거(엇갈림): RLHF 모델에서 verbalized 확률이 logprob보다 ECE 상대 ~50% 낮음. SimBench 부록 E:
  instruct 모델에서 verbalized 분포가 첫 토큰 확률을 일관되게 크게 이김. "Emulate or Estimate?"
  [2608.03044](https://arxiv.org/html/2608.03044) (2026-08): post-trained 모델의 분포 직접 추정 Wasserstein
  0.267–0.347 vs 개별 응답 집계 0.573–0.707. **부정**: 터키 연구에서 과분산 초과교정(SD비 0.40→1.26–1.37) —
  붕괴는 고치나 반대쪽 초과. 표준 처방: invert-softmax 후 온도 스케일링(ECE 추가 30–50%↓).
- 우리 적합성: 페르소나 프롬프트에 그대로, 문항당 1콜. 개인 수준 보정 증거는 얇음(집단 수준 위주).
  ISS-003과의 관계: 집계 통계를 주는 게 아니라 받는 것이므로 원칙 통과로 보이나 카드 명시 필요.
- 난이도/비용: 최저 (프롬프트 변경만).

## 2. 로그확률 / 첫 토큰 확률

- 원리: API logprobs로 선택지 토큰 확률을 직접 읽는다.
- 대표: OpinionQA [2303.17548](https://arxiv.org/abs/2303.17548) · Argyle et al. [2209.06899](https://arxiv.org/abs/2209.06899) ·
  Random Silicon Sampling [2402.18144](https://arxiv.org/pdf/2402.18144)
- 왜곡·완화: 첫 토큰 확률은 신뢰 불가 사례 다수(["Look at the Text" 2404.08382](https://arxiv.org/html/2404.08382v1)).
  **Answer Prefix(출력 프리필)** 로 크게 완화: Llama-3.1-8B MMLU 6.4%→64.0% ([2505.15323](https://arxiv.org/abs/2505.15323)).
  instruct 모델에선 verbalized에 패배(SimBench), base 모델에선 유효(2608.03044).
- 가용성: OpenAI logprobs+top20 지원(gpt-4o-mini 가능) · **Anthropic 미지원** · Gemini는 Vertex 경유.
  1콜로 전체 분포 = 비용 최소, paired 차분에 결정론적이라 유리. 위치 편향 처리 필수.
- 난이도: 낮음 (prefix + 순열 평균 엔지니어링).

## 3. 반복 샘플링 (k회 경험 분포) — 기각 권고

- temperature 1에서 k회 샘플링은 첫 토큰 확률 분포에 수렴 — 그 분포가 붕괴해 있으면 k 증가 무의미(우리 실측).
- Bisbee(Political Analysis 2024): 평균은 근접하나 분산 과소 → 통계 추론 불가. 온도 상승은 구조 없는 노이즈만 추가.
- ±5pp 정밀도에 k≈100, ±2pp에 k≈600 — logprobs 1콜의 100–600배 비용으로 같은 왜곡 분포.
- 유일한 정당 용도: 자유 텍스트 k회 → SSR 매핑/semantic entropy 입력.

## 4. 프롬프트 순열 / 앙상블 — 위생층

- 위치 편향 규모: 순서에 따라 13–85% 성능 변동. 주원인 옵션 ID 토큰 사전확률.
- PriDe [2309.03882](https://arxiv.org/abs/2309.03882): 소량 샘플로 토큰 사전확률 추정·제거 — 전체 순열보다 저비용.
- 성격: 분포 재현 기법이 아니라 **모든 방법 밑의 위생층**. 프레이밍 델타의 교란 제거용으로 paired 규약(ISS-011)에 편입 가치.

## 5. 분포 목표 파인튜닝

- SubPOP [2502.16761](https://arxiv.org/abs/2502.16761) (ACL 2025, [GitHub](https://github.com/josephjeesungsuh/subpop)):
  Pew+GSS 70K (하위집단, 분포) 쌍으로 파인튜닝 — LLM-인간 갭 최대 46%↓, 미본 설문·하위집단 일반화.
- DSA [2510.21977](https://arxiv.org/abs/2510.21977) (ACL 2026 Findings): 1단계 KL 정렬 + 2단계 "속성 1개만 다른
  배경 쌍의 분포 *변화(shift)* 정렬" — WD 0.106 vs 일반 FT 0.121, 필요 실데이터 53–69% 절감.
  **분포 변화 학습은 우리 프레이밍 델타 철학과 개념적으로 가장 가까움.**
- 제약: 미국 데이터 기반 체크포인트는 한국 이전 미검증. 하위집단 수준 학습 — 개인 페르소나 신호는 별도 검증.
  파인튜닝 모델이 델타를 뭉개지 않는지 2×2 델타 게이트(ISS-015) 통과 필수.
  OpenAI FT API로는 KL 손실 지정 불가 — 분포 목표 학습은 오픈소스 경로만. 비용: LoRA 단일 GPU /
  gpt-4o-mini FT 훈련 $3/1M tok.

## 6. 시뮬레이션 특화 / 벤치마크 우승자

- SimBench [2510.17516](https://arxiv.org/abs/2510.17516): 최고 모델(Claude-3.7-Sonnet)도 40.8/100 —
  **최고 모델조차 인간 분포보다 균등분포에 가깝다**. instruct는 합의형 문항에 강하고 다양성 문항에서 base보다 나쁨.
  CoT 도움 안 됨.
- **SSR(Semantic Similarity Rating)**: 자유 텍스트 응답 → 앵커 문장 임베딩 코사인 → softmax(τ) → 척도 분포.
  구매의도 [2510.08338](https://arxiv.org/abs/2510.08338): 인간 test-retest 신뢰도의 90%, KS>0.85.
  정치(ANES 감정온도계) [2607.28550](https://arxiv.org/abs/2607.28550): **직접 숫자 응답 KL 0.61–1.97 → SSR 0.07–0.13**
  — mode collapse 교정 폭 최대 보고. 페르소나 조건화 세팅 검증. 한계: 평균의 체계 편향(극단 경향)은 못 고침.
  우리 파이프라인 원칙(생성/채점 분리, 캐시 위 보정)과 정합. 한국어 임베딩·앵커 문장 설계는 새 자유도(사전등록 필요).

## 7. 불확실성 정량화 이식 후보

- Conformal prediction [2305.18404](https://arxiv.org/abs/2305.18404): 통계 보장 예측 집합 — "정확도 리포트"의 신뢰구간 장치로.
- 온도 스케일링 재보정: verbalized/SSR 공통 후처리 — 개발셋(21대 대선)에서 τ 캘리브레이션으로 자연 편입.
- Semantic entropy(Nature 2024): 자유 텍스트 채널의 신뢰도 플래그로.

## 8. 2025–26 신규

- **Rectification/PPI** [2510.11408](https://arxiv.org/pdf/2510.11408): 소량(100–500명) 인간 표본으로 LLM 예측의
  체계 편향을 통계 교정 — 프롬프팅·파인튜닝을 이기는 경우 다수. **방법이 아니라 통계층 — 어떤 추출 방식과도 결합.
  우리 한국 앵커 표본과 결합할 최우선 후보.**
- Emulate vs Estimate [2608.03044](https://arxiv.org/html/2608.03044): base=개별 집계, post-trained=분포 직접 추정.
  post-trained는 집단 간 차이를 ~2배 과장(우리 4배 과장 관찰과 정합 방향).
- Three-Axis Fidelity [2606.28963](https://arxiv.org/html/2606.28963): 구조·주변·개인 3축 — LoRA+MLP 최강이나
  **개인 충실도 상관 0.37 정체, 보수층 하위집단에서 구조 충실도 0.85→0.40 붕괴** — 개인 수준 재현 한계의 정량 경고.
- 비-WEIRD 검증(터키 WVS) [2607.18310](https://arxiv.org/html/2607.18310): VS +6.8~10.1pt 개선하나 과분산 초과교정 —
  한국 적용의 최근접 선례.
- 기타: When Synthetic Users Fail [2607.26348](https://arxiv.org/html/2607.26348) · 페르소나 조건화 신뢰성(WWW'26,
  평균적으론 개선 없음) · [PyMC Labs 합성 소비자 가이드](https://www.pymc-labs.com/blog-posts/synthetic-consumers-a-practical-guide)

## 추천 순위 (증거 기준, 우리 세팅)

1. **SSR** — 정치 태도에서 붕괴 교정 폭 최대 입증. 페르소나 유지·저비용·생성/채점 분리 정합. 한국어 앵커 문장 + τ 보정을 EXP 카드로 사전등록해 파일럿.
2. **분포 발화 + 재보정** — 1콜 최저가, instruct 기준 벤치마크 우승. SSR과 같은 문항 A/B 대조 1순위.
3. **Rectification(PPI) 층** — 방법 선택과 독립으로 채택 권고 (한국 앵커 표본 보유).
4. **logprobs (prefix+순열)** — OpenAI/오픈소스 경로 한정, 초저가 대조군 병기.
5. **DSA류 파인튜닝** — 2단계 과제 (한국 데이터·델타 게이트 전제).
6. 반복 샘플링(객관식) 기각. 순열·conformal은 위생·리포팅 층 상시 편입.

## 공통 경고
