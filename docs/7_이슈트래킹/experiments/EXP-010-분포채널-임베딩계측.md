## 설계 (동결)

**공통**: 페르소나·문항·정답지·모델은 EXP-009 산출물 그대로 재사용 — 강제선택 채널의 EXP-009 원자료가 기준선(재실행 없음). paired(동일 페르소나 A/B) 유지. 반복 k=1(분포가 1콜 산출물 — 강제선택의 k3 역할을 분포가 대체).

**채널 ⓑ 분포 발화(dist)**: 선택지 제시 후 "**이 인물이** 답한다면 각 선택지를 고를 확률"을 JSON으로 요구. temperature 0(분포 내용의 재현성). 파서: 옵션별 확률 → 음수/합≠1은 정규화(합 0 또는 파싱 실패 시 재시도 6회 후 실패 기록), 누락 옵션 0 처리.
  - **함정 방지(설계 감사 반영)**: "사람들의 비율"로 해석되면 집단 추정이 되어 개인 시뮬레이션이 무너짐 — 프롬프트에 "이 인물 한 사람의 내면 확률(그 사람이 여러 번 답한다면의 비율)"로 명시. ISS-003 검토: 집계 통계를 **주입하지 않고 수신**하므로 통과 — 단 프롬프트에 어떤 실측 분포도 노출 금지 유지.
- **채널 ⓒ SSR(ssr)**: **선택지 비노출** — 문항만 주고 "이 인물로서 2~4문장, 생각과 확신 정도를 솔직하게(모르겠으면 모르겠다고)" 서술 요구. temperature 1.0(서술 다양성). 채점 시 서술을 `text-embedding-3-small`로 임베딩, **앵커 문장 = 선택지 라벨의 기계적 문장화**("나는 ~라고 생각한다" / "I would say: ~" — 규칙 동결, 연구자 자유도 차단) 유사도 → softmax(τ) → 개인 분포. τ는 한국 앵커(개발셋)에서 1회 캘리브레이션 후 전 문항 고정.
  - 미국장 자극의 응답 지시 꼬리("Only return an integer...")는 SSR에서 기계적 제거(마지막 'Only return' 이후 삭제 — A/B 동일 규칙이라 대조 보존). dist에서는 시스템 프롬프트가 지시를 오버라이드.
  - 순서형 조작은 SSR에서 원리적으로 성립 불가(선택지 비노출) — 한국 순서 위약(NUKPLT18)은 dist 전용, 워딩 위약(SAMPTHOU23)은 양 채널.

**한국장** (gpt-4o-mini-2024-07-18, 즉시 발사): 문항 = 앵커 + 강한 위약 2쌍. 3암(무프로필/인구/풀 — 프로필 역설이 채널에 따라 달라지는지가 핵심 부속 질문) × 2형 × 300명 × 2채널 = **10,800콜, 예상 ~$6** (풀암 3,600콜×~8k tok 지배).
**미국장** (llama-3.2-90b, EXP-009 완료 후 자동 발사): 실측 17 + 참고 1 + 위약 20 × 2조건 × **n=120 통일** × 2채널 = **18,240콜, $0**. n 근거: 분포 채널은 개인당 1콜이 분포를 산출 — 쌍당 SE가 개인 간 이질성 항만 남아(≈SD/√n, SD~0.15 가정 시 SE≈1.4%p) 소효과 5%p 검출에 충분. EXP-009의 소효과 n=300은 샘플링 이항 노이즈 대응이었음.

**판정 게이트 (동결)**:
- G1 델타 교정(한국 앵커): 어느 채널이든 3암 중 1개 이상에서 Δ ∈ [4.3, 39.0] (EXP-009 강제선택: 전 암 밖).
- G2 위약(한국): NUKPLT18(순서, dist) |Δ| CI가 ±5%p 내 / SAMPTHOU23(워딩, 양 채널) 무분산 아닌 상태로 |Δ| CI ±5%p 내. (미국): 위약 20쌍 오탐 ≤3 (EXP-009 규격 승계).
- G3 유보(한국 앵커): 유보 확률질량 > 5% (인간 17~18%, EXP-009 ≈0%).
- G4 방향(미국): 실측 17쌍 ≥13 방향 일치 (EXP-009 동일 게이트 — 채널 간 직접 비교).
- G5 붕괴 계기: 개인 분포 평균 엔트로피·개인 간 분산이 강제선택 대비 증가 + 과분산 감시(인간 분산의 2배 초과 시 "초과 교정" 기록 — 조사 문서의 터키 사례).
- 기술 보고: 절대 분포 vs 인간(38/45/17, 31/51/18) TVD, 3암×2채널 전 조합.

**실행 하네스**: `scripts/exp010_run.py`(--track kr|us --channel dist|ssr, 재개 안전, 비용 집계) + `scripts/exp010_orchestrate.ps1`(EXP-009 미국장 완료 감지 → exp009_us_score 자동 실행 → EXP-010 미국장 2채널 자동 발사). 한국장은 등록 직후 발사.

**알려진 한계(등록 시점)**: SSR 앵커 문장·τ가 새 자유도(기계적 규칙+개발셋 고정으로 차단) · 분포 발화의 과분산 위험(G5로 감시) · 채널 간 비교는 같은 페르소나 재사용이라 완전 독립 아님(paired 비교로 오히려 검정력 이득) · 미국장 SSR 임베딩은 영어(주 검증), 한국어 임베딩 품질은 한국장에서 별도 확인.

## 사전 분석 1 — 임베딩 거리 ↔ 인간 효과 (등록: 2026-08-31, $0급)

- **가설**: 자극 쌍의 텍스트 임베딩 거리가 인간 효과 크기와 연관된다면(실측쌍 분리·크기 상관), L4(질문-국소 보정)·L5(임베딩 응답 엔진)의 성립 조건이 갖춰진다. 연관이 없으면 "임베딩만으로는 프레이밍 효과를 못 잡는다"는 경계 증거 — L5의 영토가 좁아지고 LLM 해자가 넓어진다.
- **설정**: EXP-009 동결 38쌍(실측 17·참고 1·위약 20)의 stimA/stimB를 `text-embedding-3-small`로 임베딩, 코사인 거리 산출. 판정 지표: (a) 실측 vs 위약 분리 AUC + Mann-Whitney (b) 실측 17쌍 내 거리↔|인간 효과| Spearman. 주의: 쌍 선별이 효과 크기로 절단되어 있어(실측 ≥5, 위약 ≤2) 상관은 이봉 구조 지배 — AUC가 1차 지표.
- **결과** (2026-08-31 실행, `scripts/exp010_pre_embed.py` → `data/exp009/exp010_pre_embed.json`):
  - (a) 실측 vs 위약 분리 **AUC=0.374** (역방향! 거리 중앙값: 위약 0.079 > 실측 0.047, MW p=.91) — 임베딩상 크게 다른 텍스트가 인간에겐 무효과, 거의 같은 텍스트가 대효과.
  - (b) 실측 내 거리↔|효과| ρ=0.287 (p=.26, ns).
  - 극단 사례: 정의 문장 추가(거리 0.031) → 인간 −36.3%p / 초당파 단어(0.005) → +13.5%p ↔ 논거 문단 전체 교체(0.286, 최대 거리) → +1.1%p(위약).
- **판정**: **프레이밍 효과는 의미 임베딩 공간의 기하와 거의 무관** — 가설 기각. 함의: ① L5(임베딩 응답 엔진)가 프레이밍 델타를 잡을 성립 조건 부재 — **LLM 해자의 실증 방어**(임베딩+통계로는 표현→반응 매핑 불가, LLM은 한국장에서 방향을 맞혔음). ② L4는 "질문 유사→왜곡 유사" 대신 **조작 유형별(순서/워딩/톤) 보정**으로 재설계. ③ SSR·분포 발화(L2·L3)는 영향 없음 — 응답 텍스트 측정이지 자극 거리 예측이 아니며, 오히려 "생성은 LLM만" 구도를 강화. [근거 강도: 중 — n=37, 선별 절단 구조]

## 사전 분석 2 — SSR 측정기 비교: 최소대립 붕괴의 원인 분리 (등록 2026-09-02, ~$0.5)

- **배경(jinwoo 가설)**: ① 짧은 선택지 텍스트는 임베딩이 부실 → 선택지 증강(상세 문장 여러 개)으로 완화 가능? ② 유사도가 곧 선호인가 — 서술이 어떤 선택지와 topically 유사해도 그 선택을 지지한다는 뜻은 아니지 않나.
- **설정**: 기존 한국 SSR 서술(재호출 없음) 중 실패 문항 SAMPTHOU23(실측 33/67, 임베딩-SSR ~50/50 붕괴)과 성공 문항 ANCHOR(대조)에 측정기 3종 적용 비교 — (a) 기존: 라벨 문장화 임베딩+softmax(τ=8) (b) **증강 앵커**: 선택지당 상세 진술 3개 임베딩 앙상블(옵션별 평균 유사도; 탐색 — 진술 작성은 연구자 자유도, 사전등록 아님을 명시) (c) **LLM 채점자**(미국장 개정 1과 동일 규격, 한국어) — 유사도가 아닌 판정 기반. 지표: 집단 분포 TVD vs 실측.
- **판정 규칙**: (c)가 (a)를 크게 이기면 "유사도≠선호(스탠스)"가 원인 — 측정기를 판정 기반으로 교체. (b)가 (a)를 이기면 짧은 텍스트 부실이 부분 원인 — 증강으로 완화 가능. 둘 다 실패하면 서술 자체에 정보가 없는 것(생성 단계 문제).
- **결과** (2026-09-02 실행, 3,600 서술 × 3측정기, 채점자 3,600/3,600 성공, $0.20 → `meter_compare.json`):

|---|---|---|---|
| 여론조사 신뢰 A (33/67) | 49/51 (TVD .164) | **37/63 (.049)** | 6/94 (.263) |
| 여론조사 신뢰 B (33/67) | 49/51 (.164) | **37/63 (.043)** | 6/94 (.271) |

| 앵커 B (31/51/18) | **32/53/16 (.025)** | 35/37/28 (.141) | 18/23/59 (.413) |

(인구암 기준. 전체암은 json 참조 — 패턴 동일.)
- **가설 ①(짧은 라벨 임베딩 부실) 지지**: 최소대립 문항에서 증강 앵커가 0.16→0.04로 회복 — 붕괴 원인의 상당 부분은 앵커 텍스트 빈약. 단 앵커 문항에선 증강이 역효과(0.02→0.15, 유보 과대 배분) — **증강 진술 작성이 새 편향을 주입**(연구자 자유도의 실증) → 증강은 만능이 아니라 문항별 검증 필요.
- **가설 ②(유사도≠선호 → 판정 기반이 낫다) 기각 — 역전**: LLM 채점자가 전 문항 최악(TVD .26~.41). 원인: 서술의 조심스러운 화법("~같다, 잘 모르겠지만")을 채점자가 유보/부정 **확정 판정**으로 붕괴 — 강제선택 병리(mode collapse)를 계측 단계에서 재도입. **유사도 softmax의 '부드러움'이 결함이 아니라 개인 불확실성 보존 장치**였음이 판명.
- **함의**: ① 측정기 서열: 명확한 대립 선택지 → plain 임베딩 / 최소대립 → 증강 앵커 / LLM 판정자 → 기각. ② **미국장 SSR 채점(개정 1: LLM 채점자)에 리스크 플래그** — 같은 판정-붕괴 왜곡 가능성. 미국 SSR 게이트 결과는 이 한계 명시 하에 해석하고, 확률 분산 지시("spread probability")의 완화 효과를 결과에서 검증할 것.
- **증강 역효과 메커니즘 진단** (2026-09-02 추가 분해, 앵커 DEMO 600서술 대상):
  - 범인 1 — **유보#3 진술("정치는 잘 몰라서… 지켜봐야겠다")이 9개 진술 중 전체 흡인력 1위**(평균 유사도 0.346 > plain 유보 0.257): 유보를 '정치 무관심 서사'로 쓰자 정치 담화 공통 어휘 때문에 스탠스와 무관하게 모든 서술을 끌어당김 → 유보 19%→30% 과대.
  - 범인 2 — **옵션 간 변별력 반토막**(옵션 간 유사도 격차 중앙값 plain 0.119 → aug 0.053): 지원·견제 증강 진술이 공통 정치 어휘("정부·여당·야당·국정운영")를 공유해 대비가 희석. plain 라벨은 문항이 만든 최소대비 좌표(같은 문장 틀, 방향만 상이)라 차이 성분이 순수했음.
  - **일반 원칙 도출**: 증강은 '신호 추가'가 아니라 '어휘 확장'이며, 확장 어휘가 옵션 간 공유되면 신호 대 잡음비가 하락. 앵커 설계 규칙 = **옵션 간 공유 성분 최소화·차이 성분만** — plain 라벨이 기본(자동으로 최소대비), 라벨 자체가 임베딩 해상도 밑(부정어 1개 차이)일 때만 상이한 논거 어휘로 증강. 기계적 사전 게이트 가능: **옵션 앵커 간 상호 유사도(off-diagonal)가 낮은지 발사 전 검사**.

## 판정 (2026-09-03 — 최종)

**채널 전환 가설 확증. 표준 후보 = 분포 발화(dist).**
1. **분포 발화는 두 트랙·두 모델에서 유일하게 전 방향 게이트를 통과**: 한국 G1(크기)·G2(워딩 위약)·G3(유보) + 미국 G4(방향 14/17, p=.006). 강제 선택(한국 전패·미국 12/17)의 병리를 채널 교체만으로 해소 — 프로필 역설도 채널 산물로 판명.
2. **SSR은 측정기 의존적**: 임베딩 앵커(한국) — 전 게이트 통과·최소대립 취약(증강으로 완화) / LLM 채점자(미국) — 불합격. "서술→분포" 측정에서 **부드러운 유사도 사영이 확정 판정보다 우월**하다는 것이 이번 사이클의 방법론 발견. 미국 SSR은 라벨 구조화 후 임베딩 측정기로 재채점하면 판정 가능(후속).
3. **잔여 결함(정직 기록)**: dist의 위치 편향 잔존(역순 제시 TVD .16~.22 → 순서 무작위화 필수) · llama의 강한 감쇠(중앙 쏠림, 모델별 스케일 보정 필요 — LOSO r≈.67 유지) · 위약 "유의 개수" 게이트는 정밀도 의존이라 효과 크기 기준으로 재규격 필요 · 한국 SSR τ 인구암-A 자기채점.
4. **결정 제안(ISS-023)**: 신규 실험·상품 파이프라인의 응답 채널을 **분포 발화 + 선택지 순서 무작위화**로 표준화, 강제 선택은 기준선 재현 외 금지, SSR(임베딩)은 최소대립 아닌 문항의 교차 검증용. 채택은 인간 결정.
5. 총비용: EXP-010 ≈ $8 (KR 6 + 채점자 1 + 임베딩·사전분석 <1). 누적 EXP-009+010 ≈ $15.
