# KoreanSim 통합 실행 계획

## 프로젝트 한 줄 정의

> 한국 사회를 LLM 기반 멀티 에이전트로 시뮬레이션해서 선거 예측·정책 반응·시장 반응을 추정한다. 단, AI를 맹신하지 않고 진짜 데이터로 안전장치를 두면서.

---

## 세 가지 핵심 원칙 (절대 흔들리지 않을 것)

1. **진짜 데이터로 기준을 잡고, AI는 변화만 추정한다**
2. **편향을 측정하고 가중치로 보정한다**
3. **백테스트할 때 답을 외우지 않게 한다 (학습/검증 분리)**

---

## 단계별 계획

### 0단계: 죽일 수 있는지 빠르게 확인 (1~2주)
- Nemotron 페르소나 100개 층화 추출
- Sonnet 4.6에 21대 총선 투표 질문 × 20회 반복
- 출구조사 결과와 비교
- 합격: 정당별 오차 ≤5%p AND 그룹 1위 80% 일치

### 1단계: 페르소나 설계 (2~3주)
- Nemotron 26개 + 소득/자산/미디어/종교 추가
- 7M → 2,000개 군집 압축

### 2단계: 편향 측정 (1~2주)
- 그룹별 AI 편향값 측정 → 보정 가중치 도출

### 3단계: 모델 선택 + 미디어 다이어트 (3~4주)
- Qwen/Llama/EXAONE 비교, 미디어 노출 conditioning

### 4단계: 진짜 데이터 기준선 결합 (2주)
- 갤럽 micro-data로 baseline 고정, LLM은 Δ만 추정

### 5단계: 안전한 백테스트 (3~4주)
- 학습용: 19~21대 / 검증용: 22대 (절대 손대지 않음)

### 6단계: 베이스라인 비교 (1주)
- 단순 여론조사 / 직전 선거 답습보다 우월한지 확인

### 7단계: 실전 예측 (지속)
- 사전 등록, 분포 출력

### 8단계: 도메인 확장 (선거 검증 후에만)
- 정책 반응 → 시장 반응 → 사회 갈등

---

## 의사결정 게이트

- 0단계 게이트: 검증 실패 → 전략 재설계
- 2단계 게이트: 편향 보정 불가 → 모델/데이터 재검토
- 5단계 게이트: 합격 미달 → 페르소나/모델 재설계
- 6단계 게이트: 단순 방법보다 못함 → 프로젝트 재검토
