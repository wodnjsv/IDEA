# ISS-021: 화면 크롭 시 법적 고지 유실 + CSS 강제층의 허구성

- **상태**: OPEN
- **유형**: 법률·윤리 | 코드 | 설계
- **심각도**: **P1** (공직선거법 §108조의2 — 최대 징역 5년)
- **발견**: 2026-08-06, Phase 1 디자인 시스템 워크플로의 적대적 심사 (규격 준수 렌즈 + 타이포/안티패턴 렌즈가 독립 수렴)
- **관련**: ISS-020(표시 규격) · [DESIGN_SOUL §4 C1·C3](../../8_디자인/DESIGN_SOUL.md) · ISS-012(산문 규칙 실패 모드) · ISS-008(윤리 가드레일)

## 문제 (Issue)

디자인 시스템 제안 3종을 적대적으로 심사한 결과, **세 제안 모두 공통으로 못 푼 구멍이 두 개** 확인됐다. 어느 한 제안의 결함이 아니라 접근법 자체의 공백이다.

### (A) 크롭 유출 — 차트만 잘라낸 스크린샷에 고지가 따라가지 않는다 [P1]

C3(선거법 §108조의2) 방어는 세 제안 모두 **용도 한정 고지를 푸터 밴드에, status 스탬프를 헤더 밴드에** 둔다. 그런데 실제 전파 경로는 우리가 만든 내보내기 버튼이 아니라 **OS 스크린샷**이다.

> 의원실은 화면을 캡처해서 카톡으로 보내고 PPT에 붙인다. 그때 잘리는 것은 대체로 **차트 영역만**이다.

차트 영역만 잘라낸 이미지에는 헤더 밴드도 푸터 밴드도 없다 — 즉 **status도 없고 선거법 고지도 없는 맨몸 그래프**가 유통된다. 세 제안 모두 "내보내기 경로(PNG/SVG 버튼)"와 "OS 스크린샷"을 혼동해, 자기가 통제하는 경로만 방어하고 **실제 전파 경로는 비워뒀다**.

부분 해법 1건만 확인됨: 제안 3(GWANBO)의 `{부호}{값}{단위}{status 글리프}` **단일 텍스트 노드 용접** — 숫자만 잘라낼 DOM 경계를 없앤다. 그러나 이것도 status 글리프 하나만 남길 뿐 **선거법 고지는 못 남긴다.**

### (B) CSS `:has()` 강제층은 강제하지 않는다

세 제안 모두 C1(4필드 강제)의 1차 방어선으로 `.estimate:not(:has(.e-value):has(.e-interval)…){display:none}` 형태를 쓰고, 이를 "산문 규칙이 아니라 선택자다"라고 주장한다.

**`:has()`는 DOM 존재만 검사하고 내용을 검사하지 않는다.** `<span class="e-interval"></span>` 빈 엘리먼트 하나면 전부 통과한다. 세 제안 다 `:has(.e-interval:not(:empty))` 형태를 쓰지 않았다.

파생 결함 — **fail-open**: 제안 1의 `.stamp[data-status="untested"]:not(:has(.n-readout)){display:none}`와 제안 2의 `.status:not(:has(svg)){display:none}`는 조건 미충족 시 **경고를 침묵 삭제**한다. 그 결과 미검정 값이 **상태 라벨 없는 정상 추정치**로 렌더된다 — C9가 막으려던 바로 그 위장이 강제 장치의 실패 모드로 재생산된다.

이건 ISS-012가 실증한 실패 모드("규칙이 산문에만 있고 코드 게이트가 없다")의 변종이다: **게이트가 있는데 게이트가 아니다.**

## 분석 (Analysis)

### (A) 크롭 유출

| 옵션 | 내용 | 장점 | 단점 | 근거 등급 |
|---|---|---|---|---|
| A1 | **고지를 플롯 영역 안쪽에 반복** — 차트 카드마다 용도 한정 축약 표기를 마크 레이어와 같은 상자 안에 | 크롭 단위가 카드이므로 잘라도 따라감 | 반복 노출 → warning fatigue, 지면 소모 | [중] 제안 |
| A2 | **워터마크** — 플롯 배경에 저대비 반복 텍스트 | 어떻게 잘라도 남음 | 차트 판독 방해, 저대비면 프로젝터·흑백에서 소멸(= 방어 실패) | [약] |
| A3 | **텍스트 노드 용접**(제안 3) — 값·단위·status 글리프를 한 노드로 | 숫자 단독 추출 불가 | 선거법 고지는 못 실음 | [중] 부분 채택 |
| A4 | 방치 + 사용자 교육 | 비용 0 | ISS-012가 기각한 바로 그 접근(산문 규칙) | [강] 기각 |

**잠정 방향**: A1 + A3 병용. 단 A1의 "축약 표기"가 법적으로 충분한지는 **법률 판단이 필요**하며 에이전트가 결정할 사안이 아니다.

### (B) 강제층

| 옵션 | 내용 | 근거 등급 |
|---|---|---|
| B1 | **타입 층을 정본 게이트로 선언**하고 CSS는 2차 방어선으로 강등 — `interval`을 판별 유니온으로 잠금(제안 2). 빈 문자열이 타입에 없음 | **[강] 채택 제안** |
| B2 | `:has(.x:not(:empty))` 로 선택자 보강 | [중] 병용 |
| B3 | **fail-loud 전환**(제안 3) — 조건 미충족 시 `display:none`(침묵)이 아니라 붉은 outline으로 시끄럽게 실패 | **[강] 채택 제안** — 데모 압박 하에서도 경고가 먼저 보임 |
| B4 | CI 린트로 DOM 검사 | [중] 보조. 단 제안 1의 정규식 린트는 자기 각주에서 빌드를 깨뜨린 전례 있음 |

**핵심 교정**: "CSS가 강제한다"는 서술은 **과장**이다. 진짜 게이트는 타입이다. ISS-020 제안 2의 4필드 규격은 이 사실을 반영해 **타입 층 우선**으로 다시 써야 한다.

## 결정 (Decision)

미결 — (A)는 법률 판단 필요, (B)는 인간 결정자 기명 필요(규칙 8).

운영 원칙만 선행 확정 제안:
- **크롭 유출이 해소되기 전까지, 화면 캡처를 외부에 전달하는 시연 방식은 사용하지 않는다.** W15 데모는 화면 직접 시연 + 인쇄물 배포로 한정하고, 캡처 요청 시 우리가 고지 포함 이미지를 생성해 전달한다.
- 강제층 서술에서 **"CSS가 강제한다"는 표현 금지.** 타입 층을 명시한다.
