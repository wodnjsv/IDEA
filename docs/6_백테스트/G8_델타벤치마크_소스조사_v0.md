## 1. TESS (Time-sharing Experiments for the Social Sciences) — 판정: **사용 가능 (조건부)**

**정체·규모**: NSF 지원, 미국 확률표본(NORC AmeriSpeak, 과거 Knowledge Networks)에 설문실험을 실어주던 플랫폼. 현재 **신규 접수 중단** — 아카이브 고정(벤치마크엔 오히려 안정적). 아카이브(2003–2024) 스터디 **517건**(목록 HTML 직접 카운트).

**접근성 [강 — 실물 수신 검증]**:
- 경로: `tessexperiments.org/paststudies` → 스터디별 페이지 → **OSF 링크**. **무료·무가입.**
- OSF "Data and Materials"에 zip: **응답자 수준 SPSS 마이크로데이터(.sav, 조건 배정 포함) + 설문지 원문(.docx, 조건별 워딩 전체)** — 조건별 분포를 직접 재계산 가능. (실검증: Schuldt301.zip 수신·내용 확인)
- 최신(2024 필드)도 ~1년 후 공개 패턴 확인.
- 한계: 사이트 검색 기능 없음(404) — 목록 스크립트 순회 필요. Roper 경로는 기관 구독 필요 + 재배포 금지라 미사용.

**프레이밍/워딩 실험 규모**: 제목 grep 기준 framing ~28건 + wording/순서 ~5건 ≈ **32건(하한)** — 본문에만 워딩 조작이 있는 스터디는 미포함이라 실제는 더 많음. 주의: 상당수가 **주장 제시형(emphasis)**이고, 우리가 원하는 **동등 표현형(equivalence — 같은 정보, 표현만 다름)**은 부분집합 → 유형 라벨을 달아 선별해야 함.

**확인된 예시 3건**:
| 스터디 | 조작 | 실측 효과 |
|---|---|---|
| Schuldt (N=2,041) | "global warming" vs "climate change" 용어만 교체 | 당파 격차 확대·과학자 합의 인식 하락(방향 확인, 크기는 .sav 재계산 필요) — **동등 표현형, 최적** |
| Singer & Couper (N=1,570) | "baby" vs "fetus" | 검사 의향 **−5%p** (방향+크기 명시) |
| Hiscox (N=1,610) | 무역 찬성/반대 프레임 | 반대 프레임 −17%, 찬성 무효과(비대칭) — 주장 제시형 |

**한계 (채점 설계에 반영할 것)**:
1. **미국 표본·이슈** — 한국 엔진 검증이 아니라 **"LLM이 프레이밍 Δ를 재현하는 일반 능력"** 검증으로 위치.
2. **암기 리스크** — 유명 출판 연구라 학습 코퍼스 포함 가능성 높음 → 이 소스의 채점은 "예측"이 아니라 **"재현"**임을 명시, MEMORIZATION_RISK 태그(ISS-012 논리 준용).
3. **번역 불가** — 워딩 효과는 언어 표층에 붙음("baby/fetus"의 한국어판 정답지는 없음) → **영어 원문 채점만 엄밀**, 한국어 번역판은 별도 탐색으로만.
4. 효과크기 다수가 서술형 → 스터디별 .sav 재계산 수작업 필요.
5. 라이선스 무명시 → 원자료 재배포 불가, **파생 통계 + OSF 링크** 방식.

## 2. SocSci210 — 판정: **사용 가능 (구조 최적 · 오염 주의 최대)**

**실체 [강 — 1.37GB 전량 다운로드·전수 검증]**: HF `socratesft/SocSci210`. Stanford HCI(Kolluri·Wu·Park·Bernstein), "Finetuning LLMs for Human Behavior Prediction in Social Science Experiments", **EMNLP 2025 main** (arXiv:2509.05830). 원천은 TESS(§1과 동일) — **미국 TESS 실험 210개의 개인 단위 원응답 2,901,390행**(참가자 400,491명, 조건 1,194개, 자극 원문 포함). Hewitt 계열(Nature 2026, 효과 단위)과 별개 팀·같은 원천.

**왜 구조가 우리에게 최적인가**:
- 집계 효과가 아니라 **개인 응답 분포가 통째로** 있다(조건·문항당 n≈230–660) — "최빈값 집계 금지" 원칙과 정합, 분포 대 분포 채점 가능.
- 같은 스터디·같은 문항에서 조건만 다른 **실용 조건쌍 6,158개**(2–8조건 셀 910개) — n≥20 목표를 압도적으로 상회. 단 "표현만 다른 순수 최소쌍"은 스크리닝 필요(내용 조작 혼재).
- 실측 예시(원자료에서 직접 계산): vignette 서술만 교체 → 7점 척도 Δ=1.36 대형 효과(9nphm); 후보 이름/인종만 교체 → 지각 Δ 대형 + 호감도 무효과(q9w6s) — **"효과 없음"까지 채점 가능**.

**접근성**: 완전 공개·비게이트, `load_dataset` 1줄. 라이선스 파일 부재(형식 미비 — 내부 연구용은 공개 취지 부합, 기록만).

**한계 (채점 설계 반영)**:
1. **오염 리스크가 4소스 중 최대**: 2025-08-31 공개 후 파인튜닝·평가 코퍼스로 활발히 유통 중(파생 리포 다수 실확인). **컷오프 2025-09 이후 모델은 데이터 자체를 봤을 수 있음.** 우리 고정 모델(gpt-4o-mini-2024-07-18, 컷오프 2023-10)은 데이터셋 공개 전이지만 TESS 원문·논문은 2009년부터 공개 → 역시 "재현" 채점.
2. 미국 표본 전용 — §1과 동일하게 "일반 능력" 검증으로 위치.
3. **자동 구축 품질**: LLM 에이전트 자동 파싱(인간 검수 언급 없음) — 역방향 척도 실례 확인됨(9nphm 문항2). 사용 스터디는 TESS 원 문서 대조 필수.
4. `reasoning` 필드는 GPT-4o-mini 합성 — 인간 근거로 오용 금지.
5. 인간 측은 between-subjects, 우리 LLM 측은 paired(동일 페르소나 차분) — 비교 설계의 이 비대칭을 채점 프로토콜에 명시(ISS-011).

## 3. 한국 소스 — 판정: **한국리서치 실험이 1차 소스 최상위 · 여심위는 자극쌍 광산 · KGSS는 형식 실험**

### 3-a. 한국리서치 '여론 속의 여론' — **G8 1차 소스로 즉시 사용 가능** [강 — 본문·수치 실확인]
무료·비로그인, 게시물마다 보고서·결과표 PDF. **무작위 배정 실험 3건 실물 확인**:

| 실험 | 설계 | 실측 효과 |
|---|---|---|
| **총선구도 워딩 스플릿** (archives/28057, 2023-11) | MS패널 웹조사 7월·8월 각 n=1,000, **A(NBS 워딩)/B(갤럽 워딩) 무작위 배정** — 워딩만 상이 | 안정-견제 격차 A **−7%p** vs B **−20%p**; 다항로짓 워딩계수 p<0.001; **효과가 무당파·태도갈등층에 집중, 강성 당파층 둔감** — 하위집단 민감도 구조까지 제공. 무작위 배정 불균형 자체 공개(재가중 시 격차 절반 이하) = 정직 보고의 모범 |
| AI 편향 안내문 프레이밍 (archives/37137, 2026-07) | n=1,000, 실험 498/통제 502, 전·후 측정 | '편향' 동의 +18%p, 신뢰 하락 −15 vs −8%p (p<0.001) |
| 청년 기본수당 비네트 (archives/34520, 2025-11) | n=1,000, 6속성 팩토리얼 | 속성 영향력: 경제상태 34% > 취업 20% = 건강 20% > … |

- **왜 최상위인가**: 한국인 표본 + 무작위 배정 + 워딩 최소쌍 + 효과크기·하위집단 공개 = ISS-013 서열 1차(방향+크기 채점)의 모든 요건 충족. 28057의 "무당파에 효과 집중" 패턴은 LLM 페르소나별 민감도와 **구조 대 구조로** 대조 가능.
- 한계: 시리즈 내 무작위 실험은 소수(3건+ — 검색이 제목·태그 위주라 '실험조사' 태그·수동 발굴 의존). 웹패널은 진보 과대(본문 자인) → 분포용 아님, **델타용** — 우리 paired 규약과 정합. 원자료는 KOSSDA 기탁(2018·2019분 확인, 2020년대분 미확인).

### 3-b. 여심위(nesdc.go.kr) — **자극 문구쌍 광산, 인간 효과크기 정답지로는 부적합** [강 — PDF 3건 실수령]
- 설문지·집계표 PDF **비로그인 다운로드 스크립트화 가능 확인**(FileDown.do). 등록 17,210건+.
- **핵심 실측 2건**: ① 같은 주간·같은 이슈·**다른 기관** 쌍은 풍부(국정평가·정당지지 문구 차이 실례 인용 확보 — "국정 수행에 대해 전반적으로/잘하는 편이다" vs "국정 운영을/대체로 잘하고 있다"). ② 같은 기관·다른 시점(트래커) 쌍은 **문구가 자구까지 동일** — 워딩쌍 발굴 실패로 기록.
- 함의: 기관 간 쌍은 표본·조사방식(ARS/면접) 교란이 커 **관찰 비교** — ISS-013대로 방향 채점 한정이며, 그마저 보수적으로. 1차 용도는 **LLM에 던질 실전 자극 문구쌍의 대량 소스**(정답지는 아님).

### 3-c. KGSS 스플릿 밸럿 — **존재 확인(핵심 발견), 단 '형식' 실험** [강 — 코드북 원문 인용]
- 2003-2023 누적 코드북 원문: **2016년부터 홀수/짝수 가구에 A형/B형 설문지 배정, 조사실험 수행** — 개방형/폐쇄형 응답 차이(2017), 응답 범주 순서 효과(2019, 원자력·국가자긍심) 논문 2건 KCI 확인.
- 성격: 이슈 프레이밍이 아니라 **문항 형식 실험** — 그래도 A/B 원자료가 KGSS 데이터 안에 있어(우리가 이미 보유한 파일 계열) **형식 민감도(순서·개방/폐쇄) 대조군**으로 사용 가능. 한국인 무작위 실험이라는 점에서 서열 1차.
- KOSSDA 접근: 메타데이터·설문지 PDF는 비로그인, **데이터 파일은 회원제**(비영리 한정). 자동화엔 JS 챌린지 마찰.

## 4. KGSS 경제·복지 축 변수 (EXP-007 재료) — 판정: **후보 확보 (로컬 .sav 재검증 전제)**

**이념 신호 참고(2차 문헌 [중])**: 한국인 이념 자기평가의 주 결정요인은 전통적으로 대북·안보이고 경제 이슈는 약함(청년층 예외) → 경제축 추가는 "강한 새 신호"가 아니라 **독립 분산 추가 + 안보 지배 완화**로 작동할 것으로 기대 — EXP-007 가설과 정합. 정확한 문항별 PARTYLR 상관은 보유 .sav에서 직접 산출(실행 전 필수, $0).

| KGSS A/B형 | ✅ 형식 실험 (2016~) | 1차 — 형식 민감도 한정 | 순서·개방/폐쇄 대조군 |

**n≥20 도달 경로**: 한국 1차(한국리서치 3건 + KGSS 형식 2건) + SocSci210 최소쌍 스크리닝(910셀 중 선별) + TESS equivalence 서브셋 → **충분히 도달 가능**. 병목은 데이터가 아니라 **최소쌍 스크리닝 기준의 사전등록**(어떤 쌍을 "표현만 다름"으로 인정하나)이다.

### 채점 설계에 반영할 3원칙 (조사에서 도출)
1. **이중 트랙**: 한국 소스 = 엔진 검증(페르소나 경유), 미국 소스 = "LLM의 Δ 재현 일반 능력" 검증(페르소나 문맥 별도 설계) — 혼동 금지.
2. **"예측" 아님 "재현"**: 전 소스가 출판/공개물 — MEMORIZATION_RISK 명시, 개발 지표로만. 진짜 예측 검증은 미래 사건·봉인 셋에서만(기존 규율 그대로).
3. **비대칭 명시**: 인간=between-subjects, LLM=paired(동일 페르소나 차분) — 채점 프로토콜에 이 차이와 처리 방식을 사전 기술(ISS-011 보강).
