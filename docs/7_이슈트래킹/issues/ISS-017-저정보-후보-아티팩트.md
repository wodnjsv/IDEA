# ISS-017 — 저정보 후보 아티팩트 (군소후보 과대·순서 의존)

- **유형**: 방법론·프롬프트 · **P**: P1 · **상태**: ANALYZED (EXP-004 실증)
- **관련**: ISS-003(x/P(y) 경계) · ISS-007(제3후보) · T10(A/B 슬롯) · 오차축소 A4·B6

## 문제
위생판(B·C암)에서 무소속 송진호가 6.2~7.6% (실제 0.1%). 원인 실증: ① 모델 컷오프(2023-10)가 2025 후보를 몰라 인지도 정보가 0 → 선택지 텍스트만으로 판단, ② 순서 효과(1번 위치 12.7~15.3% vs 5번 1.3~1.8%), ③ '중도' 카드의 도피처 휴리스틱("무소속=중립"). 힌트 제거(ISS-003)가 정당한 정보(후보 인지도·샐리언스)까지 제거한 부작용. 이준석 과소(4.8 vs 8.3)도 동일 계열.

## 옵션
1. **후보 중립 프로필 제공** — 공보물 수준의 객관 사실(소속·주요 경력)을 전 후보 동일 분량으로. 쟁점: 이것은 x(사실)인가 P(y) 힌트인가 — "주요 후보" 표기 없이 사실만이면 x로 판정 가능 [제안]. 검증: T10 A/B (±프로필) + 델타 불변성
   > **실증 기각 (EXP-005 E암, 2026-07-27)**: 균등 프로필은 저정보 아티팩트를 억제하지 않고 **정당화** — 송진호 6.22→10.52, 권영국 0.25→3.75, 이준석 4.82→2.56(악화). 원인 재진단: 현실의 "저정보"는 정보 부재가 아니라 **인지도 비대칭**이며, 균등 제공은 그 비대칭을 제거해 현실에서 더 멀어짐.
2. **인지도 비대칭 모사** (A4 계열 — 객관 지표(뉴스 언급량·검색량) 기반 확률적 노출; 지지율·서열 정보는 P(y)라 사용 금지) [EXP-005 후속 제안]
3. B6 짝비교 디코딩 (오차축소 카드 — 샐리언스 문제의 구조적 처방)
4. 방치 + E1 보정 전담 — 군소후보 축은 보정 불가능(0.1%를 6%로 뽑는 건 가법 보정 밖) [기각 제안]

## 검증 계획
B2(후보 정체성 큐) 파일럿 → 이준석 <3%p 시 B6 투입. 판정지표 = 송진호 오차·이준석 재현율·이재명/김문수 불변성 (사전등록). 서브샘플 500, ~$0.5. 재플랜 v2의 4단계(타임박스)에 배정.

## 결정
- **부분 결정 (2026-08-07, 결정자: jinwoo — 세션 대화)**: **옵션 2(인지도 비대칭 모사)는 연기.** 근거: 제품 1호 과제(광명 편입 찬/반/유보)는 다자 선거 선택지 기계를 직접 요구하지 않음 — 본 이슈는 선거 백테스트 계기 문제로 강등(재플랜 v2, P5). 구현 시점은 4단계(타임박스) 재론. 그때까지 무명후보 과대는 개발 지표의 **알려진 한계로 리포트에 상시 표기**(정직 보고 원칙).
