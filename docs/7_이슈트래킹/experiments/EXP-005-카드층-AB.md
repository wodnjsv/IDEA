# EXP-005 — 카드층 A/B: 생각 카드(D)·후보 프로필(E) (사전 등록)

## 가설
1. **D암(생각 카드)**: 이념 명찰을 KGSS 신념 문장으로 바꾸면 결정론 매핑이 풀린다 — 크로스보팅 출현, 중도→김문수 회복, Step1 에코 해소. topline은 유지~개선.
2. **E암(후보 프로필)**: 공보물 수준 중립 사실을 주면 저정보 아티팩트가 준다 — 송진호 <1%, 이준석 8.3% 방향, 양강 구도는 불변(±2%p).

## 설정 (재현 정보)
- 모델·온도·k: EXP-004와 동일 (gpt-4o-mini-2024-07-18, temp=1.0, k=5 단일콜)

- 선택지 순서: B암과 동일 (persona_order 재사용 — 순서 효과 통제)
- **D암 신념 시딩 = hot-deck**: 같은 셀(권역·성·연령·학력)의 실제 KGSS 응답자 1명에게서 5문항 응답을 통째로 복사(문항 간 상관 보존). 도너 풀 3,645명(2021·2023·2025 파동), 폴백 L1 86%·L2 13%·L3 1%. 도너 PARTYLR은 진단용 저장·비렌더링
- 신념 5문항: UNIFI(통일 필요성)·NORTHWHO(북한 인식)·CONBUS(대기업 신뢰)·CONLABOR(노조 신뢰)·SATFIN(가계 만족). 이념 신호 검증: 통일 +0.36, 북한 +0.55(강한 신호), 나머지 약한 신호 — 실제 인간의 느슨한 신념-이념 결합을 모사
- E암 프로필: 직업·경력 사실 한정, 전 후보 동일 형식 (전과 등 논쟁 소지 정보 제외 — 웹 검증 2026-07-24). x/P(y) 경계 판단: 사실 정보 = x
- 비용: 2,000콜 사전 추정 **~$0.55** (실비용 결과란 기입)
