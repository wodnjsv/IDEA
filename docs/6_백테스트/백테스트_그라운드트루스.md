# 백테스트 그라운드 트루스 — 리서치 보고서

> **조사 기준일**: 2026-07-05 · **방법**: deep research (5개 검색 각도, 22개 소스, 상위 클레임 3표 적대적 교차검증)
> **목적**: 우리 LLM 합성인구 시뮬레이션의 정확도를 채점할 실측 데이터(정답지) 확보 + phase0 진단·드림학기제 일정(W1/W9-11) 매핑.
> **표기**: ✅ 3-0 검증 / ⚠️ 2-1 / ❓ 발견됐으나 미검증(후속 확인)

## 요약 — 그라운드 트루스는 세 층위

1. **선거 실측(정답지)**: 중앙선관위가 역대 선거를 **읍면동 단위까지** 무료 공개. phase0 대상 21대 대선(2025-06-03)과 W11 백테스트 대상 9회 지선(2026-06-03) 모두 확정 공개.
2. **의견 분포 앵커**: KGSS(누적 23,282명), 한국갤럽 데일리(1,000명 찬반 %), **NESDC 선거여론조사 DB(16,453건, 설문 문항 전문 공개)** — 특히 NESDC는 우리 상품 핵심인 '프레이밍 민감도'의 실제 문항 앵커.
3. **방법론 벤치마크**: ElectionSim(채점 프레임), SubPOP(공개 데이터셋), 교차국가 검증(독일 소수정당 붕괴 = 우리 제3후보 붕괴와 동형).

**공백(미검증)**: 실제 주민투표 찬반 실측치, split-ballot 프레이밍 공개데이터, 정책이슈 시계열, 경기데이터드림 행동데이터 → §5 후속.

## 2. 선거 실측 정답지 (검증 완료)

### 2.1 ✅ NEC 파일데이터 — 읍면동 정답지 (핵심)
- **`15025527`** 「국회의원선거 개표결과_20240410」: 시도명·선거구명·**법정읍면동명·투표구명**·후보자·득표수 6컬럼, **126,901행 CSV**, 중앙선관위, **KOGL(출처표시)**, 무로그인. (비례는 별도 `15144273`)

## 3. 의견 분포 앵커 (검증 완료)

- **✅ 한국갤럽 데일리 오피니언**: 전국 18세+ **1,000명**, CATI, ±3.1%p. 정책 찬반을 **point %로 공표**(예: 개헌 찬 54/반 25, 대북 54/34, 국정평가 58/32). → 의견 재현·프레이밍 채점의 **숫자 앵커**. URL: gallup.co.kr
- **✅ KGSS**(kossda.snu.ac.kr): 2003~2025 누적 **23,282명**, '지지정당'·정치성향 반복 측정. **시/도까지 무료**, 시군구/읍면동은 유료·IRB 신청(약 70만원, 2년, 공유금지). 주의: '투표'는 확정 반복문항 아님(지지정당은 확정).
- **✅ NESDC**(nesdc.go.kr) ★: 등록 선거여론조사 **16,453건**, 무가입 열람. 공직선거법상 **설문지 원문·표본·응답률·가중 전량 공개**. → **동일 이슈의 상이한 문항 워딩 → 상이한 찬반**을 직접 비교 가능 = 우리 상품 "프레이밍 민감도"의 실측 앵커. 한계: 선거여론조사 한정(순수 정책이슈는 미등록 가능), 일부 PDF 스캔.

## 4. 방법론 벤치마크 (해외, 채점 프레임)

- **✅ ElectionSim**(arXiv:2410.20746): 2020 미 대선 주 단위 **47/51 승자 적중, vote-share RMSE 0.071**. → 채점 지표 정의 템플릿(**승자적중률 + vote-share RMSE**). ⚠️ 경고: 7pp RMSE는 우리 5%p 목표 미달 + 논문도 진보 과대추정 보고 = **phase0와 동형**. ("일관된 방향성 편향" 일반화는 검증에서 0-3 기각.)
- **✅ SubPOP**(arXiv:2502.16761, ACL 2025): 3,362문항·~7만 subpop 쌍. HF `jjssuh/subpop`, 코드 GitHub **BSD-3**(원 검증의 'CC BY 4.0' 주장은 반증). GSS를 OOD split으로 = 인간-모델 갭 측정 = 백테스트.
- **✅ 교차국가 검증**(arXiv:2407.11409): GPT-3.5를 ANES(미)·GLES(독)·Zuobiao/CFPS(중)로 검증. **독일 대형정당 0.80+ 재현하나 소수정당(FDP·녹색·좌파) 유의 부진** = **우리 이준석 0%와 병렬**. ⚠️ 단 논문은 부진 원인을 독일 선거제도 복잡성으로 귀속 → '인구학적 과소대표' 해석은 유비(2-1).

## 6. phase0 진단 + 드림학기제 매핑

### W1 (정답지 수집) — 표준 파이프라인
1. **선거 정답지**: `15025528`(대선 읍면동 CSV) + `15025527`(총선) 다운로드. 사전투표는 `15040586` API. **읍면동=파일 / 구시군=API 경로 분리.** (기존 phase0의 `build_ground_truth.py` 외부경로 하드코딩 → 이 CSV 경로로 교체)
2. **의견 앵커**: 갤럽 데일리(정책 찬반 %) + KGSS 시/도(지지정당·이념) 확보.
3. **프레이밍 앵커**: NESDC에서 동일 이슈 상이 문항 쌍 수집.

### W9-11 (채점 설계) — phase0 진단 반영
phase0 raw 분석에서 **이준석 0/5135(원천 붕괴)**, **편향이 이념→투표 매핑에**, **confidence 91% 고정** 확인. 따라서 채점 지표를 **단일 topline 오차가 아니라 다층**으로:

| 지표 | 정의 | phase0 값 | 근거 |
|---|---|---|---|
| ① 전국 후보 MAE | 후보별 |실제−시뮬| 평균 | 8.4%p | ElectionSim 프레임 |
| ② 시도 승자 적중 | 17개 중 일치율 | 75% | phase0 기준② |
| ③ **제3후보 재현율** | 이준석 등 시뮬/실제 | **0%/8.34%** | 독일 소수정당 병렬 → **필수 지표** |
| ④ 하위집단 오차 | 연령×지역×성 셀별 | 미측정 | Bisbee 분산붕괴 경고 |
| ⑤ 분산 보존 | 시뮬 SD vs 실측 SD | 미측정 | topline 통과≠구조 일치 |

### W11 (6·3 지선 백테스트) — 홀드아웃
- 9회 지선(2026-06-03) 광역단체장 개표결과(info.nec.go.kr 확정)로 시뮬 채점. **학습에 안 쓴 선거 = 진짜 홀드아웃.**
- 정당-이념 매핑 명시 주입(샐리언스 붕괴 방지), 광역단체장 득표율 오차 + 순위 적중.

### 프레이밍 외적타당도 (오차축소 문서 G8)
- NESDC 동일 이슈 상이 문항 쌍의 실측 찬반차 → LLM Δ와 방향·크기 일치 채점. split-ballot 공개데이터(§5) 확보 시 강화.
