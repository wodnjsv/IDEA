## 5. 문서로 못 없애는 잔여 리스크

- **컷오프 2차 출처 의존** — Llama/Gemma 컷오프는 모델 카드·공개 문서 기반이며 1차 검증 불가. EXP-006 지식 탐침이 유일한 경험적 반증 경로
- **40 RPM은 비보증치** — NVIDIA는 모델·트래픽별로 한도가 달라진다고만 안내. 429 발생 시 리미터가 자동 감속하나 총 소요시간은 늘어남
- **n=K 배치와 K회 직렬의 표집 미세 차이** — 동일 요청 내 n샘플은 서버 구현에 따라 상관될 수 있음. 배치/직렬이 암 간에 섞이면 분산 추정이 오염되므로 **한 실험 내 모드 고정** 필요(현재 코드는 sticky 강등이라 중간 전환 가능 — 감시 대상)
- **리미터는 프로세스 로컬** — 러너를 두 개 이상 동시 실행하면 계정 한도를 초과한다. 순차 실행 규율은 코드가 아니라 사람이 지켜야 함
