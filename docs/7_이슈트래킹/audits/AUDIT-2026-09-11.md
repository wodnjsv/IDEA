# 2026-09-11 민심테스트 UI 감사

범위: `web/` 소비자용 정적 UI. 연구 엔진, 데이터, 실험 러너는 변경하지 않았다. 관련 ISS-027. 사용자 최신 요청에 따라 예시 데이터를 사용하며 실제 산출로 주장하지 않는다.

## 착수 전 독립 감사

독립 리뷰어 `design_audit`가 ISSUES, ISS-020/021, DESIGN_SOUL 및 사용자 요청을 대조했다. 핵심 기준: 모든 결과 단위에 데모 표시, 임의 질문 결과 재사용 금지, 최초 예측 고정, 투표 로컬성 명시, 모달·슬라이더 접근성 확보. 소비자 UI 범위는 기존 연구 리포트와 분리할 때 구현 가능하다고 판단했다.

## 완료 후 독립 소스 감사

동일 독립 리뷰어가 구현 코드의 동작·이슈 커버리지·회귀 위험을 검토했다. 다음 여섯 결함을 찾아 수정했다.

1. 미응답 결과 직링크에서 같은 hash를 할당해 결과로 전환되지 않음 → 동일 hash인 경우 명시적으로 재렌더.
2. 본문 바로가기의 hash가 라우터로 처리됨 → 기본 이동 차단 및 기존 main 포커스.
3. 태블릿 숨겨진 메뉴 텍스트로 접근성 이름 소실 → 모든 메뉴 링크에 aria-label.
4. 모바일 저장 목록 접근 경로 누락 → 하단 5개 메뉴 유지.
5. 저장 실패 알림이 성공 toast로 덮임 → 메모리에서만 유지되는 상태를 최종 알림에 명시.
6. 질문 입력의 포커스 표시 제거 → 입력 컨테이너에 focus-within 표시.

독립 리뷰어의 수정 후 재검토: 위 6건이 소스상 모두 수정됐으며 해당 범위의 미해결 블로커 없음.

## 실행 증거

- `node --check 민심테스트/web/dist/app.js` 성공.
- 로컬 HTTP 진입점 응답 200. 홈, 예측, 결과, 기록 화면 브라우저 실행 확인.
- 숫자 입력 65 → 키보드 ArrowRight → 66. 예시 72와 6%p 차이, 88점 표시 확인.
- 연령별→성별 전환, 찬성→반대 투표 변경, 공유 카드 모달 및 PNG 내보내기 동작 확인.
- 공유 카드 시각 확인: 질문·조건·내 예측·예시 결과·예시 범위·실제 시뮬레이션 미실행 안내 포함.
- 390×844 모바일 결과 페이지: DOM 측정 `scrollWidth=390`, 화면 밖으로 넘치는 main 요소 0개. 하단 5개 메뉴 확인.
- 새 질문 ‘반려동물 동반 출근을 허용해야 할까?’ 작성. 동일 선택지 입력 거부, 수정 후 조건 포함 초안 저장. 새로고침 후 유지, 결과 비율 생성 없음.
- WebMCP `list_demo_questions` 6개 질문과 선택지만 반환(정답 미노출), `open_prediction_question(workweek)` 예측 화면 표시, 알 수 없는 ID 거부 및 기존 상태 유지.

- 추가 회귀 검증: 기록 없는 `#/result/ai`에서 60% 제출 → 예시61%, 차이1%p/98점 표시. 본문 바로가기 후 결과 URL 유지. 모바일 저장 메뉴에서 저장한 AI 질문 노출.
- 검색 미일치 빈 상태, 검색 초기화, 기술 카테고리의 1개 카드, 최신순 AI 질문 선두 확인.
- Sites 비공개 버전 1 배포 성공. 프런트엔드만 별도 게시하며 원본 연구 데이터는 게시하지 않음.

## 한계

독립 리뷰는 소스 감사이며 브라우저 실행은 주 에이전트가 수행했다. 실제 사용자 과제 테스트, 보조기기 전수 테스트, 모든 브라우저/기기 테스트는 미실시. 점수·분포는 UI fixture이며 모델·데이터 검증 증거가 아니다. 공유 카드 고지는 일반적인 OS 크롭 유출 문제를 완전히 해결하지 않는다. 실제 서비스 전환 시 서버 정규화·검증·사용자 통계·저장 정책을 별도로 연결해야 한다.

## 게임형 리디자인 후속 감사

- 착수 전 독립 감사: design_audit가 예시 고지의 상시 노출, 예측/개인 투표 구분, 메뉴·접기 회귀 세 축을 검토. 구현 범위 충돌 없음.
- 완료 후 독립 소스 감사: 예측 고정/직링크/저장/투표/초안/공유 및 모바일 메뉴, details 집단 전환을 검토. 새 소스 결함이나 미해결 블로커 없음.
- 실행: 정적 JS 문법 검사 성공. Node VM에서 6개 질문 진입, 미응답 결과 직링크→예측→점수, 최초 예측 고정, 투표 변경 시 1표 유지, 집단 전환, 저장, 질문 초안 중복 선택지 거부/저장, 로컬 지속 상태, 카테고리 필터 통과. 첫 테스트의 실패는 테스트 대역의 hash 정규화 누락이었으며 대역 보정 후 통과.
- 로컬 HTTP 응답 200. 별도 브라우저 테스트 요청이 없어 이번 수정의 브라우저 시각 QA는 수행하지 않음. 모바일 반응형과 접근성은 소스 검토이며 실제 기기 검증은 아님. 이전 버전의 브라우저 검증을 이번 버전의 시각 검증으로 주장하지 않음.
- 실제 사용자 참여율/정확도 검증, 엔진 연결 없음.

- 후속 리디자인 비공개 배포 성공: 버전 2, 소스 `cddf062e3a84041715ad8118d5730b963fee3d23` (별도 Sites 소스 저장소). 기존 사이트 URL 및 소유자 전용 접근 범위 유지.

## Kalshi 참고 가독성 후속 감사

- 실제 Kalshi 홈페이지를 읽고 흰 배경, 정렬된 선택지 행, 얇은 경계, 카테고리 탐색 구조 확인. 타 사이트 거래 데이터나 확률 추이는 복제하지 않음.
- 착수 전 design_audit 독립 감사: 거래 의미 혼입 방지, 전제/예시 고지 유지, 모바일 검색·메뉴 및 읽기 순서 확인. 설계 블로커 없음.
- 완료 후 독립 소스 감사: 검색 중복/라우팅·카드 결과 미노출·예측/투표/초안/공유 보존 확인. 홈 검색어 초기화는 리뷰 시점 이후 반영하고 실행 검사로 확인. 다른 새 결함 없음.
- node --check 성공. Node VM 회귀 통과: 6개 질문, 미응답 결과 직링크, 최초 예측 고정, 차이와 점수, 투표 한 표 유지, 집단 전환, 저장, 초안 중복 선택지 검증/저장, 지속 상태, 필터. 추가: 검색 AI→1개 카드, 홈 복귀→검색어 빈값/6개 카드.
- 로컬 HTTP 200 및 미리보기 제공. 브라우저는 레퍼런스 확인에만 사용했으며, 제품의 실제 대비·배치·모바일 브라우저 검증은 이번 요청에서 미실시. 해당 항목은 소스 검토 범위. 사용자 가독성/참여율 실험과 실제 모델 검증 미실시.

- Kalshi 참고 수정 비공개 배포 성공: 버전 3, 별도 Sites 소스 `d303d44909ea72c5d4a30fd75213784156415325`. URL/소유자 전용 접근 범위 유지.
