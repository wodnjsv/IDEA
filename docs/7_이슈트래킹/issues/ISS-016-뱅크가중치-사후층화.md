# ISS-016 — 뱅크 가중치 의미론 (사후층화 weight_bank)

- **유형**: 방법론·코드 · **P**: P1 · **상태**: **DECIDED** (2026-07-23)
- **발견**: AUDIT-2026-07-23 공격 H · **관련**: T2, EXP-002/003, ISS-015(하위집단 셀 n≥200)

## 문제
페르소나 추출이 가중값 비례(PPS)인데 집계에서 `인구가중값`을 다시 곱하면 **이중가중 편향**이 생긴다(실측: 성비 51.2→50.2 왜곡). 또 본뱅크는 시도 플로어 200으로 소형 시도를 의도적 과대표집하므로 **무가중 집계도 오답**이 된다. 즉 "어떤 가중치로 집계하는가"가 미정의 상태였다.

## 검토한 옵션
1. **무가중 집계 유지** — v0(순수 비례)에선 옳지만 플로어 층화에서 깨짐. [기각]
2. **인구가중값 재가중** — PPS와 결합 시 이중가중. [기각 — 실측 반증]
3. **weight_bank 신설(제안)** — 추출 설계에서 유도: 비례 PPS=1, 플로어 층화=시도 인구비/표본비, 전수=센서스 가중값 승계. 시도 마진이 정의상 정확 복원됨(검증 0.0%p). [채택 제안 — 근거 [강]: 표준 사후층화 논리 + v1 실측]

## 구현
`src/engine/bank.py` build_bank() — 트랙·모드별 weight_bank 산출, 페르소나 레코드에 저장. `scripts/validate_bank.py` 가중 집계 전환. **후속 규칙: 모든 뱅크 기반 집계(LLM 응답 집계 포함)는 weight_bank를 사용한다** — T4 채점 하네스에 반영 필요.

## 검증
v1 재검증: 전국 가중 마진 최대 1.09%p·시도 0.0%p, 광명 전수 0.0%p (AUDIT-2026-07-23 §3).
