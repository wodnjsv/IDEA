## 🎯 현재 방향 (2026년 7월 기준)

- **집중**: **여론조사 대행** — 전통적 전화/ARS 여론조사를 합성 인구 시뮬레이션으로 대체.
  - ⛔ 상권 분석(B2B, 소상공인/상권 A/B)은 **후순위·보류**.
- **타겟 (B2G)**: **경기도의회 의원** 대상 정책 여론 시뮬레이션 자문.
- **1호 유스케이스**: **광명시 서울 편입 이슈** 여론 시뮬레이션.
- **법적 포지셔닝**: 선거 여론을 대중에 "공표"하면 공직선거법 리스크(제108조의2, 최대 징역 5년).
  → **내부 전략/정책 자문용 워게임 시뮬레이터**로 포지셔닝 (전략문서 §7 참조).
  → 광명시 서울편입은 '선거'가 아닌 **'정책 이슈'**라 선거 여론조사 규제에서 상대적으로 자유로움.
- **🔑 의원 피드백 (2026-07)**: 편입 논의 당시 여론조사가 결정적이었으나 문항 프레이밍으로 결과 유도가 가능했다는 지적. **신뢰도 있는 LLM 여론조사 결과가 유의미하면 문제 재제기의 동력**이 될 수 있다는 의견 → 1호 유스케이스의 수요 실체. (상세: [서울편입 보고서 §5](1_서울편입/서울편입_논의_리서치보고서.md))
- **🔑 제품 포지셔닝 — "결과가 아니라 과정을 판다"**: 여론조사 결과에 정답은 없다 → 투명한 방법론 + **조건(프레이밍)별 반응 실험**을 판매. "조건 X 포함 시 편입 과반, 제거 시 급감 ⇒ X가 정책 핵심 변수"식의 **조건 민감도 분석**이 핵심 상품. 전통 조사는 문항 변형마다 수천만 원, 우리는 한계비용 수천 원으로 무제한 반복.
- **드림학기제 (2026-2, 12학점, 창업형)**: 16주 개발 로드맵 확정 — 사실상 제품 개발 마스터플랜. **광명시의회 실무진 데모 미팅 확정** (W15 실증). ([5_드림학기제](#5_-드림학기제) 참조)
