# EXP-011 — '살' 채우기의 지역 전이 검증: 시도 숨기기 총연습 (사전등록 초안)

- **상태**: **사전등록 초안** — 결정 D1~D4 승인: jinwoo, 2026-09-14. 0단계(통계, $0)는 도너 데이터 확보 즉시 착수, 1단계(LLM)는 0단계 게이트 통과 조합으로.
- **관련**: ISS-025(살 증강 방식 재검토 — 본 실험이 판정체) · ISS-022(실험 예외 승인, 2026-09-14) · ISS-023(분포 채널 표준) · EXP-008(뼈대만 예측 z=.10) · EXP-010(하류 채널) · `docs/2_전략기획/질문지고정_뼈대데이터_요청목록_v0.md`
- **결정 체인**: D1 (C) LLM 증강 암 포함(실험 예외) · D2 봉인 지역 경기·부산·전북 · D3 도너 = KGSS + 통계청 사회조사 블록 · D4 예산 ~$15, 1주 **+ 1단계에 SSR 채널 교차 포함**(jinwoo 추가 지시, 2026-09-14 — 상한 ~$20로 조정)

## 질문 (전부 가설 — 심판 명기)

광명 파이프라인 B단계("센서스 뼈대에 실존 도너의 350문항 살을 붙이기")는 광명에서 검증 불가(광명 350문항 정답 부재). 대신 **정답이 있는 시도를 통째로 숨겨 같은 절차를 총연습**한다.

- **H1 전이 가능성**: 뼈대 셀 매칭 도너 복사가 "전국 평균 붙이기"(바보 기준선)보다 봉인 지역의 문항 분포를 유의하게 잘 맞힌다. 심판: 문항별 TVD 평균, 3지역 모두 기준선 대비 부트스트랩 95% CI 분리. 실패 = 셀 전이 무의미 → 뼈대 기반 합성 재검토.
- **H2 결합·분산 보존**: 도너 통복사·블록 혼합이 문항별 대치("평균 인간")보다 문항 간 상관행렬 거리가 작고 셀 내 분산 보존율 ≥ 70%. 심판: 상관행렬 Frobenius 거리·분산비, 판별기 AUROC(문항별 대치·LLM 암은 ≤ 0.65).
- **H3 LLM 증강의 위치 (ISS-025 판정)**: (C)암이 도너 복사 대비 마진·결합·분산·하류 중 하나라도 유의하게 낫나. 심판: 같은 4지표. 이기면 ISS-022 supersede 안건, 지면 기각 근거.
- **H4 하류 동등성(B→C 연결)**: 가짜 살 페르소나가 진짜 살 페르소나와 분포 채널에서 같은 응답 분포·델타를 내나. 심판: 지역별 "가짜 300 vs 진짜 300" 분포 TVD ≤ 0.05, 워딩 델타 차 ≤ 3%p(페르소나 부트스트랩 CI).
- **부속 — 문항별 전이 지도**: 어떤 문항(영역)이 지역을 넘어 전이되고 어떤 것이 지역색인지 — 광명 질문 영역별 위험 경보기 + CIA 위반의 전형적 규모.

## 설계

### 0단계 — 통계 ($0, 2~3일)
- **봉인**: KGSS 4웨이브(2018·21·23·25) + 통계청 사회조사(최근 2주기) 응답자 중 시도 ∈ {경기, 부산, 전북}를 각각 통째로 봉인(정답지). 봉인 시도별로 독립 실행(다른 두 시도는 도너 풀에 남음).
- **뼈대**: 봉인 시도의 센서스 2% 성인 마진에 맞춰 500명 합성(`engine.bank` 빌더, 시드 고정).
- **살 채우기 암**(각 뼈대에 적용):
  | 암 | 방식 |
  |---|---|
  | A 도너 통복사 | 셀 사다리(성×연령10×학력×수도권×혼인 → 폴백, 셀당 도너 ≥30 강제) 내 무작위 도너 1명의 전 문항 복사. 다중 대치 m=5 |
  | A′ 블록 혼합 | 영역 블록(정치·사회자본 / 노동 / 가족 / 생활·건강 / 사회조사 블록)마다 같은 셀의 다른 도너 |
  | B 문항별 대치 | 릿지(EXP-008 규격) — "평균 인간" 대조군 |
  | C LLM 증강 | (C1) Nemotron-Korea 봉인 시도 페르소나 → 분포 발화로 350답 생성 / (C2) 우리 뼈대 → 동일. temp 0, 순서 무작위화. **실험 예외**(ISS-022) |
- **문항 선별 축**: 전체 vs 정규화 섀넌 엔트로피 상위 50%(Kinzinger 2026 처방).
- **측정**(봉인 실측 대비): ① 문항 TVD 평균(+바보 기준선) ② 상관행렬 거리 ③ 셀 내 분산비 ④ 판별기 AUROC ⑤ 문항별 전이 지도.

### 1단계 — LLM 하류 (gpt-4o-mini, 채널 2종 교차, ~$15)
- 0단계 게이트(H1·H2) 통과 조합 최대 3개 × 봉인 시도 3곳.
- 각 시도에서 "가짜 살 300명"(합성) vs "진짜 살 300명"(봉인 실측 응답자, 같은 뼈대 분포로 재가중) → 앵커 문항(총선 구도 A/B 문구) + 지역색 강한 문항 2개(전이 지도에서 선정).
- **채널 2종**: ⓑ 분포 발화 + 순서 무작위화(주 판정) · ⓒ SSR(선택지 비노출 서술 → 임베딩 앵커 측정기; 최소대립 문항은 증강 앵커 — EXP-010 사전분석 2 규칙). H4 판정은 채널별로 각각 보고, 두 채널이 엇갈리면 그 자체를 결과로 기록(측정기 의존성 증거).
- 프로필 형태: 350답 원문 나열(영역별 정렬). LLM 서사 층은 **미포함**(문헌상 원문 > 서사 — ISS-025). 예산 여유 시 서사 유/무 소규모 암 추가 가능(D4 상한 내).
- 콜 상한: 3지역 × 2판 × 300 × 2문구 × 3문항 × 2채널 × 조합 ≤3 ≈ 64,800콜 → 조합 수·문항 수로 $15 내 조정(풀 프로필 ~7k tok 지배). 채점 임베딩 ~$0.5.

### 동결 규칙
- 봉인 지역 실측은 0단계 채점 전까지 어떤 산출에도 사용 금지(도너 풀·튜닝 포함).
- 셀 정의·폴백 임계·엔트로피 컷·게이트 수치는 본 카드 기준, 실행 후 변경 금지(실행 불능 판명 시 개정으로 기록).
- (C)암 생성 모델과 1단계 시뮬 모델은 **다른 계열**(순환 차단): C 생성 = llama-3.2-90b(무료), 시뮬 = gpt-4o-mini.
- 재현: 시드 20260914, 모델 스냅샷·컷오프·프롬프트 버전·비용 기록.
