# ISS-045: EXP-011 엔트로피 문항 선정의 인구 변수 정규식 누락 — REGION·MARITAL이 태도 문항 순위에 섞임

- **상태**: ANALYZED
- **유형**: 코드 | 방법론
- **심각도**: P2 (EXP-011 문항 선정과 EXP-019 문항 우주 정의 전 해결)
- **발견**: 2026-09-26. EXP-019 설계 중 발견했고(`EXP-019:109`), 주 루프가 코드와 산출 파일을 대조해 확인했다. 선행 기록은 2026-09-23 팔로업 리뷰 N-05(c)이며, 카드는 없었다. Claude 단일 모델 결과다.
- **관련**: `scripts/exp011_pre_entropy.py:23-24`, `data/kgss_item_entropy.csv`, EXP-011(지역색 문항 fold 선정, 봉인 변수 REGION), EXP-019 §2-3, ISS-043

## 문제 (Issue)
`exp011_pre_entropy.py:24`는 인구 변수를 라벨 정규식으로 거른다. 정규식은 `몇 세|만 나이|성별|최종 학력|교육 수준|혼인 상태|태어|출생|가구원|거주|…`이다.
- 실제 KGSS 라벨은 **'응답자 혼인상태'**(붙여 씀)와 **'지역'**이라서 이 정규식에 걸리지 않는다.
- 결과: `data/kgss_item_entropy.csv`에 **REGION(63행, 327개 문항 중 62위)**과 **MARITAL(271행)**이 태도 문항처럼 순위에 들어 있다(2026-09-26 grep으로 확인).
- **REGION은 EXP-011의 봉인·보류 변수다.** 이 파일로 지역색 문항을 고르면 봉인 변수가 문항 후보가 되어 누출·혼입이 생긴다.
- 이 필터는 "정규식 금지, 명시 목록" 원칙을 어긴 사례로 EXP-019 §2-3-2에 전례로 기록됐다.

## 분석 (Analysis)
| 옵션 | 내용 | 근거 등급 |
|---|---|---|
| A | 인구·관리·지리 변수를 **변수명 명시 목록**으로 제외하고(EXP-019 §2-3-2 목록 재사용), 엔트로피 파일을 재생성한다. 재생성은 산출물이지 지표 실험이 아님 — 다만 파일 버전을 올리고 이전 파일은 보존 | [강] |
| B | 엔트로피 순위를 문항 선정에 쓰지 않는다(EXP-019는 이미 사용하지 않기로 함, `EXP-019:139`) | [중] |

## 결정 (Decision)
미결 — 인간 결정 대기. 제안: EXP-011을 유지한다면 A, EXP-019로 대체한다면 B와 함께 해당 파일에 "사용 금지 — ISS-045" 표시를 append한다.
