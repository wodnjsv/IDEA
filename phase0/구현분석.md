## B. 파이프라인 (run→analyze)

```
Nemotron-Personas-Korea (HF, 1M×7)
 ① shuffle(seed=42)→앞 50,000행
 ② stratified_sample: 권역 인구비율 배분 × (권역내 age5×sex2=10셀 균등) → 1,027명

 ⑤ regex r"\{.*?\}" JSON 파싱

```

**채점 기준**: ① 모든 후보 오차 ≤5%p, ② 시도 1위 ≥80%(17개 중 14) 일치.

## C. 실제 결과 정밀 진단 (raw 재집계)

| 후보 | 실제 | 시뮬(유효표) | 오차 |
|---|---|---|---|
| 이재명 | 49.42% | 70.42% | **+21.0%p** |
| 김문수 | 41.15% | 29.58% | −11.6%p |
| 이준석 | 8.34% | **0.00%** | −8.3%p |

**verdict: FAIL** (avg 8.4%p, 시도적중 75%).

**신규 발견 3가지:**
1. **편향은 "이념 진단"이 아니라 "이념→투표 매핑"에 있다.** Step1 자가진단은 중도 56.8% / **보수 25.1% / 진보 18.0%**(보수>진보!). 그런데 투표는 63% 이재명. 이재명 표의 71%가 "중도" 자가진단, 중도의 ~78%가 이재명으로 쏠림. → 실제 중도는 반반. **매핑 보정이 핵심.**
2. **이준석 0%는 집계 아티팩트 아님 — raw 5,135샘플에서 선택 0회.** 그리고 프롬프트가 제3후보를 직접 억눌렀음(§D4). 자책골.
3. **confidence 91.3%가 값 "4"로 고정** → 엔트로피/confidence 부동층 분류 완전 무용(폐기 확정).

## D. 구현 이슈·버그

1. **프롬프트 정답 오염**: `[한국 정치 컨텍스트-통계적 사실]`로 지역·세대 성향 직접 주입 + `"swing이라고 제3당 고르지 마세요"`·`"양당 90%"`로 제3후보 억압. → PLAN 원칙3(답 외우지 않게) 위반 + 이준석 0%의 유력 원인.
2. **`build_ground_truth.py` 외부 경로 하드코딩** (`/sessions/trusting-zen-gates/...`) → Windows에서 안 돌아감. 정답지 재생성하려면 `docs/4_참고자료/데이터/…csv`(또는 백테스트 문서의 읍면동 CSV `15025528`)로 교체 필요.
3. **docstring/help 불일치**: "100명×20회=2,000"이라 쓰였으나 실제 1,000×5=5,000.
4. **`raw_responses`의 `demographic.sex`·`district` 인코딩 손상**(surrogate). 분석이 `province`만 써서 결과는 무사(latent bug).
5. **점추정 파이프라인**: 페르소나당 5회를 최빈값으로 뭉갬 → 분포(우리가 팔 상품)를 죽임.
6. **층화 결함**: 권역 내부 age×sex 균등(실제 인구구조 무시), 전북 표본 0.
7. **레거시 `run_experiment.py`** 방치.

## E. 처방 우선순위 (오차축소 문서·백테스트 문서 연동)

- **0단(공짜)**: 프롬프트 탈편향(정답 힌트·제3후보 억압 제거), 선택지 순서 랜덤화, 부동층 DK옵션, 전북 커버리지 수리 → 21%p를 (아티팩트 vs 진짜 편향)으로 재분해.
- **매핑 보정**: 보정은 "이념 분포"가 아니라 **"이념 조건부 투표확률"** 축에 — 구현은 E1 PPI/D3 affine(오차축소 §4가 "갤럽 영점조준" 원안을 기각하고 대체한 경로. 어휘 통일: 2026-07-18).
- **파이프라인**: 점추정→분포 출력으로 재설계.
- **채점**: 제3후보 재현율·하위집단 오차·분산 보존을 필수 지표화(백테스트 문서 §6).
- **정답지 세분화**: 시도 → **읍면동 CSV**(`15025528`)로 업그레이드.
