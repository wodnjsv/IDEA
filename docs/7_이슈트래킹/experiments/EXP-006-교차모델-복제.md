# EXP-006 — 교차모델 복제: 유료(gpt-4o-mini) ↔ 무료(NVIDIA NIM) 등가성 (사전 등록)

- **상태**: 사전 등록 (프로브 후 실행) · **등록일**: 2026-07-27
- **관련**: ISS-019(백엔드 이중화) · ISS-012(컷오프) · ISS-011(paired) · EXP-004/005 후속

## 왜 필요한가
EXP-005의 D·E 판정은 gpt-4o-mini B암과의 paired 비교로 정의돼 있다. 백엔드를 무료로 바꾸는 순간 그 비교는 **모델 효과와 카드층 효과가 교란**된다. 두 갈래 중 하나를 택해야 한다: ① 무료 모델로 B·D·E를 **전부 다시** 돌려 내부적으로 paired를 복원, ② 모델 차이 자체를 측정해 등가성을 확인. 본 실험은 ①을 수행하면서 ②를 부산물로 얻는다.

## 설계
- 표본: `subsample_ids_1000.json` (EXP-004·005와 **동일 1,000명**, 동일 선택지 순서 — persona_order 재사용)
- 암: **B(대조)·D(생각 카드)·E(후보 프로필)** 3암을 무료 모델로 전량 재수집
- 대조군: 기존 gpt-4o-mini B·D·E (`raw_{B,D,E}.jsonl`, 이미 수집 완료)
- 온도 1.0, K=5 — EXP-004 규격 고정. n=K 미지원이면 K콜 직렬(요청 수 ×5, 로그에 n모드 기록)
- 비용 $0 / 벽시계는 RPM 병목: 3,000요청(n지원) ≈ 1.4시간, 15,000요청(미지원) ≈ 7.1시간 @35 RPM

## 사전 등록 지표 (변경 금지)
1. **topline 등가**: 무료-B vs 유료-B 후보별 득표율 차 — |Δ| ≤ 3%p면 "등가", 3~8%p "부분 등가(수준 재보정 필요)", >8%p "비등가"
2. **처치효과 부호 일치**: (D−B)와 (E−B)의 부호가 두 모델에서 같은가. **제품이 파는 것은 수준이 아니라 조건 민감도이므로, 부호·크기 일치가 topline 일치보다 상위 판정이다.**
3. **아티팩트 재현**: Step1 에코율·결정론 매핑·송진호 과대선택이 무료 모델에서도 나타나는가 (모델 고유 결함 vs 프롬프트 구조 결함의 분리)
4. **위생 지표**: JSON 파싱 실패율 ≤ 2%, 한국어 응답률 ≥ 99%, 429 재시도로 인한 유실 0

## 사후 지식 프로브 (컷오프 반증 — ISS-012 보강)
채점 전, 페르소나 없이 모델에 직접 묻는다: "2025년 6월 3일 제21대 대통령선거 당선자는 누구입니까? 모르면 모른다고 답하세요." ×20회.
- 정답률이 우연 수준(≤20%)이면 컷오프 주장과 정합
- 유의하게 높으면 **모델카드 컷오프와 무관하게 MEMORIZATION_RISK 라벨을 부여**하고 백테스트 성능 주장에서 제외한다. (문서상 컷오프를 신뢰하지 않는 실측 게이트)
