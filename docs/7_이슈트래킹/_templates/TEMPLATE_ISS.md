# ISS-NNN: <한 줄 제목 — 문제를 명사구로>

- **상태**: OPEN | ANALYZED | DECIDED | IMPLEMENTED | VERIFIED | CLOSED-WONTFIX | SUPERSEDED(by ISS-xxx)
- **유형**: 방법론 | 설계 | 데이터 | 코드 | 법률·윤리 | 사업
- **심각도**: P1(막힘/제품사활) | P2(같은 마일스톤 내 해결) | P3(후순위)
- **발견**: YYYY-MM-DD, 출처(대화/실험/리뷰/논문)
- **관련**: ISS-xxx, EXP-xxx, 관련 문서·코드 경로

## 문제 (Issue)
무엇이 왜 문제인가. **증거(수치·인용·재현 경로) 필수.** 추측이면 추측이라고 표기.

## 분석 (Analysis)
원인 분해. 검토한 옵션들:

| 옵션 | 내용 | 장점 | 단점 | 근거 등급 |
|---|---|---|---|---|
| A | | | | [강/중/약/추측] |
| B | | | | |

참고 문헌·문서 링크.

## 결정 (Decision)
무엇을 하기로 했나 + 왜(기각 사유 포함). 결정자·날짜.
> 이 섹션은 DECIDED 이후 append-only. 번복은 새 이슈로 supersede.

## 구현 (Implementation)
어떤 코드/문서로 반영. 커밋 해시·파일 경로·완료 기준.

## 검증 (Verification)
어떻게 검증했고 결과 수치는. 게이트 통과 여부. 미검증 잔여물 명시.
