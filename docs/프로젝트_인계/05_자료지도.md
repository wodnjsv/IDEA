## 2. 전략과 문헌이 연결되는 방식

초기 [한국형 Aaru 전략](<../2_전략기획/한국형 Aaru 구축 및 고도화 전략.md>)은 한국형 합성 인구, 정치·지역 맥락, 규제·사업 기회를 폭넓게 제안했다. [Aaru 한계 보고서](../2_전략기획/Aaru_한계_종합분석보고서.md)는 데이터·아키텍처·인과성·검증의 네 층을 제안하지만 이것이 현재 코드에 모두 구현된 것은 아니다.

[오차축소 비교](../2_전략기획/오차축소_방법론_비교분석.md)는 그 초기 처방을 반박하고 좁힌 문서다. ORC·네거티브 제약·출력 넛징 등 기존 아이디어를 효과 근거와 조건 민감도 보존 기준으로 다시 분류했다. 방법론 사다리는 이 문서, 태스크·예산·주차는 구현계획이 정본이다.

[분포 추출 조사](../2_전략기획/분포추출_방법론_조사_v0.md)는 강제선택 실패 뒤 EXP-010 채널 비교로 가는 문헌 입력이다. 문헌 당시 SSR 우선 권고와 자체 LLM 채점자 SSR 실패는 시점과 방법이 다르다. 조사 문서를 최신 실험 결과보다 우선하지 않는다.

[질문지·뼈대 요청목록](../2_전략기획/질문지고정_뼈대데이터_요청목록_v0.md)은 KGSS의 핵심 108문항과 회전 모듈, 광명 정책 분야의 공백을 정리한다. 지역 개발·행정구역·주거·교통 등은 KGSS 일반 성향만으로 충분히 설명하기 어려워 지역 실측 자료 확보가 별도 경로다. 이 문서의 '있을 가능성/미확인' 항목을 이미 뱅크에 있는 필드로 바꾸어 쓰지 않는다.

[경쟁사 분석](../2_전략기획/경쟁사_인텔리시아_분석_v0.md)은 소비재 B2B와 정책 B2G의 차별화, 공개 검증·위양성·조건 델타를 제안한다. 회사 발표 숫자는 독립 성능 검증이 아니며 공개 정보 부재를 경쟁사 기능 부재의 증명으로 읽지 않는다. 이번 정리는 경쟁사 사이트·논문을 새로 확인한 최신 시장 조사 보고서가 아니다.

## 3. 사업·발표 문서의 사용 범위

사업 기획에는 B2G 연 라이선스·SaaS·API, 창업지원·지원금 활용, 시장 목표가 담겨 있다. 이것들은 목표와 가설이며 체결 계약·매출·개발 완료를 입증하지 않는다. README의 실증 미팅 관련 표현도 당시 문서 기록으로만 보존한다.

9/16 발표 근거 검증은 특히 다음 과장을 지적했다: 서로 모집단이 다른 김포 조사들을 질문 문구만 다른 동일 실험처럼 비교하는 것, 인간 조사 편향이 AI에서 소멸했다고 하는 것, 일부 집계 일치를 개인 정확도 또는 전국 정확도로 바꾸는 것, 경쟁사·국가의 방법 독점을 단정하는 것. 이 인계서는 그 주장을 반복하지 않고 상세 근거 문서로 안내한다.

원 신청서의 ORC·갤럽 영점조준·소비 70% 목표는 이후 정본의 기각·대체·데이터 조건부 범위 조정과 함께 읽는다. 주차보고의 표·시간·성과는 해당 보고의 기재 내용이며 이번 분석에서 사람별 투입시간이나 계약 사실을 독립 확인하지 않았다.

## 4. 로컬에만 있는 산출물

`output/`에는 사업화계획·일정 이미지, 포지셔닝 발표자료, 정책 UI 시안, 홍보영상·음성, 근거 이미지, 생성 이미지 폴더가 있다. `outputs/references/`는 각주 근거 시각화, `.pptx-build/`는 발표 빌드 산출물이다. 이번 분석 기준에서 Git 미추적이며 연구 코드·정본의 일부로 간주하지 않는다. 해당 파일을 삭제·이동·커밋하지 않았다.

원자료 `.sav`, MDIS 이용안내·코드집, 드림학기 PDF의 일부 로컬 사본도 미추적이다. 파일 목록/기존 Markdown 설명을 참고했으며 모든 PDF·HWP·XLSX·이미지·영상의 전문 내용과 화면을 새로 검증하지 않았다. 사업 산출물 자체를 수정할 때는 그 원본을 별도 열어 확인해야 한다.

## 5. 다음 작업에서 근거를 찾는 요령

- 성능 수치: EXP 카드 최신 결과 → 해당 감사 → 저장 집계 → 필요할 때 승인된 재채점 순서. 요약 그래프만 보고 성공을 판단하지 않는다.
- 인간 결정: ISS 결정 섹션의 결정자·날짜 → 개정/예외 범위. ANALYZED 제안은 승인으로 승격하지 않는다.
- 현재 코드: 관련 runner/score 소스와 입출력 경로 → 환경·원자료 가용성. 문서 명령을 바로 실행하지 않는다.
- 어느 시점의 설계였는지: 아래 Git 기준점과 `git log -- <파일>`로 확인한다.
- 법률·경쟁사·논문 최신 주장: 해당 보고서의 날짜를 먼저 읽고 외부 재검증을 별도 수행한다.
