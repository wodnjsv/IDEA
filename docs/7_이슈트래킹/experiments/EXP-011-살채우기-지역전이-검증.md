## §0. 이 실험이 답하는 것과 답하지 않는 것 (범위 선언)

광명 파이프라인: 센서스 뼈대 → 실존 응답자의 태도 답안("살") 부착 → LLM 분포 발화. 광명에는 살의 정답이 없으므로 **정답이 있는 권역을 통째로 숨겨 같은 절차를 총연습**한다.

| 답한다 | 답하지 않는다 (다른 카드 몫) |
|---|---|
| 셀 매칭 도너 복사가 **권역 수준**에서 지역 태도 분포를 전이하는가 (H1) | 시군구(광명 28만) 수준 국지성 — 후속 "광명 마진 대조"(경기도 사회조사 원자료 확보 후) |
| 실존 인물 단위 복사가 "평균 인간"보다 결합·분산을 보존하는가 (H2) | LLM이 살을 **새 정책 질문**(서울편입)에 올바르게 쓰는가 — EXP-010 계열 + EXP-013 |
| LLM 증강 살이 도너 복사보다 나은가 — ISS-025 판정 (H3) | 인간 응답 대비 정확성(H4는 입력 대체 가능성만) · 개인 재현 |
| 가짜 살이 진짜 살을 **지정 모델·과제에서 대체 가능**한가, 결합 인물은 A 대비 달라지는가 (H4·H4b) | 광명 고유성 |
| 프로필 규격 기본값(선별·m·셀 폭·도너 거리) — 어블레이션 | 프로필 두께의 하류 효과(후속) |

**통과 시 허용 문구**: "해당 권역·웨이브·108문항 집합에서 살 채우기 전이 성립(권역 수준)". "광명에서 된다"는 허용 안 됨. 현재 KGSS 자료는 문항 선별·결합 설계에 이미 접촉했으므로 KGSS 인구 결과는 **"개발 자료의 권역 제외 평가"**, 사회조사 인구는 **미접촉 확인 자료** 역할.
**v2 범위 변경(승인 필요)**: ① 1단계에 **사회조사 도너 인구 하류 문항** 추가(복지·안전 — 광명 질문이 사는 영역) ② 1단계 LLM 어블레이션 B3·B5·B6 **보류**, B2는 셔플 대조로 흡수 ③ 결과별 **결정 트리**(§5) 신설. 예산 상한 $20 불변.

## §1. 가설 (전부 가설 — 심판 명기)

- **H1 전이**: A의 문항 TVD 평균이 **인구구성 보정 기준선 B0′**(봉인 권역의 셀 구성으로 재가중한 전국 분포 — 도너 자료만)보다 작다. 심판: 문항별 paired TVD 개선량의 부트스트랩(도너·봉인 응답자·웨이브 층 재표집) 95% CI 하한 > 0 **및** 점개선 ≥ .02, 권역별 3값 판정(통과/실패 입증/미결). 바보 기준선 B0(전국 복사)·절대 TVD 평균·영역별 최대오차는 보고(게이트 아님). 전라(503명)는 사전 판정력 계산 미달 시 미결 허용.
- **H2 결합·분산**: A의 상관행렬 거리(순서형 Spearman·명목 Cramér's V, 문항 수 정규화)가 B(릿지)·B′(PMM 확률적 대치)보다 유의하게 작고, 셀 내 분산비 ∈ [.7, 1.3]. 판별기(로지스틱 + GBM, fold 내 튜닝, 도너 복제본 동일 fold) AUROC 95% 상한 ≤ .65 — **전 합성 암 동일 적용**(A 포함).
- **H3 LLM 증강(ISS-025)**: 주분석 문항 세트 = 108 전체(엔트로피 50%는 탐색). C1/C2가 A 대비 4지표 중 하나라도 Holm(2암×4지표×3권역=24) 후 유의 우위이고 나머지 지표가 비열등(TVD +.02, 상관거리 +10%, 분산비 ±.1, AUROC +.05 이내). 승 → ISS-022 재상정, 전패 → 기각 강화.
- **H4 입력 대체 가능성**: 권역·채널마다 가짜 살 300 vs 진짜 살 300(재가중)의 분포 TVD ≤ .05 **및** 델타 차 ≤ 3%p(TOST, 90% CI ⊂ 마진), **추가 조건** 가짜 살이 뼈대만 대조 대비 진짜 살 쪽으로 유의 이동. 채택 규칙: 표준 채널(분포 발화)에서 **3권역 중 ≥ 2 통과**(참차이 0 시 통과확률 ≈ .92). SSR 결과 병기, 엇갈림은 결과로 기록. 읽기 여부는 개인별 변화·조건부 셔플로 보고. 인간 정확성은 주장하지 않음.
- **H4b A 대비 변화**: A″ vs A 동일 마진, 3분 판정 — 동등 / 실질 차이 / 미결. "해악"이 아니라 "변화"(정확성 판정은 다리 조사 확보 후). 핵심 하위집단(성×연령대) 병기.
- **부속**: 문항별 전이 지도(광명 질문 영역별 위험 경보기).

## §5. 결정 트리 (권역 단위 3값 → 파이프라인)
1. **H1**(권역별 통과/실패/미결). 3권역 전부 실패 → 셀 전이 무의미 → **1단계 취소**, 광명 실측(경기도 사회조사·자체 조사)으로 전환. ≥2 통과 → 진행. 1 통과 + 미결 혼합 → 진행하되 결론은 "부분".
2. **H3**(0단계): 승 → ISS-022/025 재상정(인간 결정). 패 → 기각 강화. 1과 독립.
3. **H2**: 통과 → A 유지. 실패(B/B′ 동등 이상) → 문항별 대치 후보. 단 4의 H4가 A에서만 통과하면 A 유지.
4. **H4**(권역×채널): 표준 채널 ≥2/3 통과 + 뼈대만 대비 이동 → **도너 복사 채택(권역 수준)**, 전이 지도 지역색 영역 "위험" 표시 의무. 뼈대만 ≈ 진짜 살 ≈ 가짜 살 → LLM이 살을 안 읽음 → 채널·프롬프트 재설계(EXP-010 계열). 가짜 살 ≠ 진짜 살 → 살 제작 재검토, 실측 확장 우선. 미결 → 재검정력 후 재실행 여부 인간 결정. SSR과 엇갈림 → 표준 채널 기준 결정 + 불일치 공개.
5. **H4b**: 동등 → 결합 인물 허용(다중 도메인 질문). 실질 차이 → 도메인별 별도 인구만. 미결 → 보수적으로 별도 인구.
6. **사회조사 하류**: H4 동일 규칙, 단 델타 미검정. 실패 시 복지·안전 영역은 "살 대체 미검증" 표시.
