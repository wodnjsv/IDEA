## 축 2 — 이슈·게이트를 실제로 커버하는가

- ISS-022 실험 예외: C1/C2 생성 모델(llama)과 시뮬 모델(gpt) 분리로 순환 차단 — ✔. 단 **엔트로피 선별·매칭 규칙을 LLM 산출로 튜닝하지 않음** 명시 필요(0단계는 LLM 무관).
- ISS-003: 도너 살은 실측 x이므로 통과. C암 프롬프트에 권역 실측 분포 노출 금지 — 프롬프트 검토 항목으로 추가.
- ISS-011 paired: 1단계 가짜/진짜는 **다른 인물**이라 paired 아님(집단 대 집단) — 카드에 "비페어드 집단 비교, 부트스트랩 CI" 명시 ✔(이미 기재).
- ISS-014: $20 상한 내 ✔. 1단계 콜 상한 계산(64,800)은 상한이고 실제는 조합·문항 수로 절단 — 발사 전 정확 콜 수 기입 필요.
- ISS-023: 분포 발화 + 순서 무작위화 ✔, SSR 측정기는 임베딩(최소대립은 증강) ✔.
- 게이트 수치: H1 "유의 우위" 는 효과 크기 없이 유의성만 — 표본(500 뼈대)에서 미세 우위도 유의할 수 있음 → **효과 크기 하한(TVD 개선 ≥ 0.02)** 추가 권고.

## 축 3 — 새 문제·모순을 유발하지 않는가

- 개정 2(도메인별 도너 인구)와 어블레이션 A3/B2(결합 인물 대조)는 모순 아님 — 후자는 대조군. ✔
- 사전 체크 7의 결론("결합 16% 보존")을 1단계 H4b가 재검하는 구조 — 순환 아님(지표 다름: 통계 vs 하류).
- 문서 정합: 카드 상단 "D2 경기·부산·전북"과 개정 1 "권역" 병존 — 상단에 개정 참조 각주 필요(경미).
- 위험: 봉인 실측 응답자 300명이 H4 "진짜 살" 판과 동시에 0단계 정답지 → 같은 사람이 두 단계에 쓰임. 0단계 채점 후 1단계 사용은 허용(정답지 재사용은 지정 개발셋 규율과 동일)이나, **1단계 결과로 0단계 규격을 되돌리지 않음**을 동결 규칙에 명시.

## 결론

설계는 착수 가능. **필수 수정 3건**(뼈대 PPS 재추출 · 봉인 누출 assert · 엔트로피 척도 층화)과 **권고 2건**(H1 효과 크기 하한 · 콜 수 확정)을 개정 3으로 반영한 뒤 데이터 확보 즉시 0단계 착수. 완료 후 결과 감사 1회 예정.
