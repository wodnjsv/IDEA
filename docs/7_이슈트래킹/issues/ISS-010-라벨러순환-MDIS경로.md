# ISS-010: 페르소나 합성 재설계 — 라벨러 순환 차단 + MDIS 직접 샘플링 경로

- **상태**: DECIDED
- **유형**: 방법론 | 데이터
- **심각도**: P1
- **발견**: 2026-07-18, 적대적 감사(엔지니어링 F4 + 방법론 F1·F13, 정찰 감사의 Dynamo-K 상세)
- **관련**: ISS-001(마진 순환성 — 본 카드는 그 실행층), 구현계획_v1 T2

## 문제
(1) **라벨러 순환**: ISS-001 옵션 B(서사→이념 라벨링)의 라벨러가 응답 생성기와 같은 편향 계열이면 층화변수가 오측정된다. 실측 증거가 자기 데이터에 있음 — phase0 자가진단 중도 56.8%(실측 ~30%대 대비 20%p+ 과대). 오분류 행렬 M≠I이면 마진을 갤럽에 맞춰도 조건부 결합(이념×서사)이 오염을 상속하고, 라벨 편향과 매핑 편향이 같은 내부 표상에서 나와 합성된다. (2) **교차 마진의 통계적 빈약**: 갤럽 공표는 one-way marginal뿐(제664호 PDF 실측 확정 — 교차표 없음). KGSS로 권역5×연령5×이념3 셀을 만들면 셀당 ~15명/파동, SE ±13~18%p — 5%p 목표보다 크다. "권역 이념 분포 ±오차 내" 검증은 노이즈에 정합시키는 검증이 된다.

## 결정 (2026-07-18, 대표 승인)
1. **T2의 1차 경로를 MDIS 2% 직접 샘플링으로 변경**(IPF는 MDIS 미확보 시 폴백). 신념 시딩은 KGSS 조건부 P(성향|연령·성·지역·학력) + 계단식 fallback(셀<5→지역→전국).
2. **이념 라벨을 쓰는 모든 경로에 인간 검증 게이트**: 서사 200~300건 인간 이중코딩 → κ 및 오분류행렬 M̂ 보고 → M̂⁻¹ 보정(또는 라벨러 교체) 후에만 구성비 사용. 라벨러는 응답 모델과 다른 계열 + temperature=0 + 루브릭 고정.
3. **마진은 점추정이 아니라 분포로**: 갤럽 wave 부트스트랩(또는 3-4주 이동평균+SE)로 구성비 불확실성을 최종 CI에 전파. 소스 우선순위 사전 고정(이념=갤럽, 검증=KGSS).
