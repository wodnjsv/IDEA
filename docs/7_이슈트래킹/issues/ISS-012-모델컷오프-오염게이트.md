# ISS-012: 모델 지식 컷오프 오염 게이트 — 산문이 아니라 어서션으로

- **상태**: DECIDED
- **유형**: 코드 | 방법론
- **심각도**: P1
- **발견**: 2026-07-18, 적대적 감사(엔지니어링 F3 + 방법론 F8 부속)
- **관련**: 구현계획_v1 T4·모델 정책, EXP 템플릿

## 문제
"모델 버전 고정"이 문서 산문(G7)에만 있고 코드 게이트가 없다. 컷오프 ≥2025-06 모델이면 2025 대선 백테스트가 암기 테스트가 되고, ≥2026-06이면 지선 봉인 백테스트도 붕괴한다. 모델 교체는 가정이 아니라 계획(EXAONE·Qwen 앙상블, 오픈 트랙)이며, gpt-4o-mini는 2026년 현재 레거시(퇴출 진행)라 **강제 마이그레이션 = 오염이 기본 경로**다. 면접 대본의 "모델이 결과를 외운 건 아닙니다" 주장도 특정 스냅샷(컷오프 2023-10)에만 참인데 조건이 박제돼 있지 않다.

## 결정 (2026-07-18, 대표 승인)
1. **T4 채점 하네스에 하드 게이트**: 레지스트리의 `election_date` × EXP 카드 필수 필드 `model_cutoff_date`(오픈모델은 웨이트 릴리스일)로 `assert cutoff < election_date`. 위반 시 채점은 가능하되 결과에 **MEMORIZATION_RISK 라벨 강제 부착**(백테스트 성과로 인용 금지).
2. **모델×선거 컷오프 감사표** 상설(T4 산출물).
3. **모델 고정**: `gpt-4o-mini-2024-07-18`(컷오프 2023-10). 폴백 모델은 **컷오프 < 2025-06 확인 후** 지정.
4. TEMPLATE_EXP에 `컷오프` 필드 추가(반영 완료).
