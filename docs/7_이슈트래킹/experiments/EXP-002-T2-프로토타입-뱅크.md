# EXP-002 — T2 프로토타입 페르소나 뱅크 (전국·광명 500명)

- **상태**: 완료 (경량 양식 — LLM 호출 없는 데이터 빌드·검증 런)
- **일자**: 2026-07-22
- **관련**: T2(구현계획_v1) · ISS-002(레지스트리) · ISS-010(이념 라벨 게이트) · T2_페르소나_스키마_설계_v0

## 가설
센서스 2% 실레코드 스켈레톤 + 실측 조건부 추첨(지역별고용·가금복·KGSS)으로, 주변분포가 모집단과 ±1.5%p 수준으로 일치하고 성향 분포가 붕괴하지 않는 페르소나 뱅크를 n=500에서 만들 수 있다.

## 설정
- 데이터: `data/registry.json` 5종 (sha256 = data_manifest.md와 동일)
- 코드: `src/engine/{registry,harmonize,tables,bank}.py` + `scripts/build_bank.py`
- 파라미터: seed=42, n=500/트랙, 폴백 임계 n≥30(급여·소득)/n≥5(KGSS, T2 명세), KGSS 최근 3파동(2021·2023·2025)
- 비용: **$0 / API 0콜** (ISS-014 게이트 해당 없음)

## 결과
- 전국판: 성·연령·학력 최대 편차 1.5%p, 시도 최대 0.4%p
- 광명: 최대 편차 3.5%p(40대 — n=500 표집 노이즈 ≈2σ)
- 성향(전국): 진보 31.4 / 중도 40.0 / 보수 27.0 / DK 1.6 — 붕괴 없음
- 광명 급여 추첨의 98%가 광명 자체 셀(L1)에서 성립
- 상세: `data/banks/validation_v0.json` · 리포트: `docs/4_참고자료/데이터/T2_뱅크_검증리포트_v0.md`

## 판정
**성공(프로토타입 기준)** — 단 ① 코드 미감사(적대적 감사 전 '완료' 아님), ② 이념 라벨은 ISS-010 게이트 전 개발용, ③ 한계 6건은 리포트 §6 참조. 본뱅크(수천 명) 확장과 감사가 다음 단계.
