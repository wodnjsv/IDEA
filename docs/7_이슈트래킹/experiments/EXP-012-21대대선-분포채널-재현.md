## 가설 (심판 명기)
- **H1 잔여 편향 축소**: EXP-004의 +9.07%p 잔여는 강제 선택이 중도 카드를 한쪽으로 몰아 생긴 매핑 결정론의 산물 → 분포 채널에서 |이재명 유효표 − 49.42| < 9.07 (부트스트랩 95% CI 상한 기준).
- **H2 결정론 완화**: 중도 카드의 김문수 점유율이 EXP-004(≈0%)에서 > 10%로, 진보 카드→이재명·보수 카드→김문수 점유가 100%에서 이탈(각 < 95%).
- **H3 저정보 아티팩트**: 송진호 < 2%(EXP-004 6.2~7.6%), 이준석 [4, 14]%(실제 8.34).
- **H4 이념 라벨 의존**: 라벨 제거 판(D2)에서도 H1이 성립하면 "라벨 없이 인구속성만으로 수준 근사" — 성립 못 하면 라벨(개발용)이 수준 재현의 필수 입력.
- 부속: 시도 1위 적중(≥13/17), 후보별 MAE(< 5.94 = EXP-004 B암), 기권·DK 질량(실제 투표율 79.4% → 기권 ~21%).

## 설정 (동결)
- 인물: EXP-004 동일 부분표본 1,000명(`data/t3/subsample_ids_1000.json`, 전국 뱅크 v1, weight_bank 집계).
- 암: **D1** 카드 원본(이념 라벨 포함, EXP-004 C암과 paired 대조) / **D2** 이념 문장 제거 카드.
- 채널: 분포 발화 — "이 인물이 100번 투표한다면 각 선택지 비율" JSON, temperature 0, **선택지 순서 페르소나별 무작위**(ISS-011 paired 규약: EXP-004와 동일 `persona_order` 시드). 선택지 = 후보 5 + 투표하지 않음 + 밝히고 싶지 않음(EXP-004 C암과 동일).
