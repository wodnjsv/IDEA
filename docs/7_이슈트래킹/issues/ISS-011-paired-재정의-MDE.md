# ISS-011: paired 설계 재정의 — "동일 시드" 메커니즘은 허구, MDE 사전 계산 의무

- **상태**: DECIDED
- **유형**: 방법론
- **심각도**: P1
- **발견**: 2026-07-18, 적대적 감사(엔지니어링 F2 + 방법론 F5 — 독립 수렴)
- **관련**: ISS-006, 오차축소 문서 §4bis(정정 대상), 구현계획_v1 T6

## 문제
오차축소 §4bis의 "동일 페르소나·**동일 시드**에 조건 X 유/무를 짝지어 차분" 규칙에서 시드의 기여는 0이다: (a) 조건 유/무는 프롬프트가 달라 토큰 시퀀스가 첫 분기부터 발산 — 서로 다른 프롬프트 간 공통난수 페어링은 seed로 성립 불가, (b) OpenAI seed는 best-effort(system_fingerprint 변경 시 무효), (c) 만약 결정론이 성립하면 k회 반복이 동일 출력 = 분포 채널과 정면 충돌. 분산 소거는 전적으로 "동일 페르소나" 효과다. 또한 **검정력 계산이 0건**: 셀 200명·k=5 기준 SE(Δ̄)≈2.35%p → MDE≈6.6%p로, 하위집단 수준에서 통상 프레이밍 효과(3~8%p)의 하단을 검출 못 한다.

## 결정 (2026-07-18, 대표 승인)
1. **규칙 재정의**: paired = 동일 페르소나 집합 + 동일 k + **페르소나 수준 차분**(Δᵢ = p̂ᵢ,X − p̂ᵢ,¬X). "동일 시드" 문구는 오차축소 §4bis에서 삭제(정정 완료). 시드는 로깅만, 결정론 주장 금지. 재현성의 정본은 raw jsonl 캐시+sha256.
2. **MDE 표 사전 계산 의무**: phase0 raw(페르소나당 5샘플)로 σ²_within·σ²_δ를 $0에 추정 → (셀 크기 × k) MDE 표 작성, 목표 MDE 사전 등록. 프레이밍 실험은 MDE 표 없이 발주 금지.
3. **Δ 채널 최적화**: Δ 추정 한정으로 D2 logprob 병용 우선 검토(조건부 분포 직접 → MC 항 소멸; first-token 편향은 차분에서 부분 상쇄 — 이것도 검증 항목). paired 런 간 선택지 순서는 동일 고정(독립 랜덤화 시 Δ에 차등 노이즈).
